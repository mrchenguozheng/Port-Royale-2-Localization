# 发行语言清单（src/release-languages.txt）
#
# **语言集已冻结（2026-11-23）：当前发行 11 门 + 预览 1 门（pt-BR）。**
# 新增语言先按 docs/新语言.md 解冻；预览语言写 preview-languages.txt，
# 不要混进本文件。逐语言身份见 docs/语言矩阵.md。
#
# 一行一个语言代码；`#` 起为注释，逗号或空格分隔同样有效。
# 这里定义的是**语言全集**（CI 按它准备字体）。打包成几个 zip 由
# src/release-bundles.toml 决定：同一份字体能共用的语言进一个包，
# de / es / fr / it 合成 latin，其余各出一包。分组里的语言必须都在本清单里。
#
# 只有列在这里、并且 src/packs/<lang>.toml、src/translations/<lang>.toml、
# src/font-map.ini [<lang>] 三样齐全的语言，才会进 release.ps1 与 CI 的发行包。
#
# 字体模式不需要在这里标注：release.ps1 默认 -Fonts auto，按 font-map.ini
# 该语言的四项映射判断——全 none 的是 config（只带映射，用原版字体），
# 其余是 noto（带实际字体）。de / es / fr / it 属于前者；zh / ja / ko / ru / pl
# 属于后者——pl 只换三个标题槽位（原版标题字体缺 ą ć ę ł ń ś ź ż），正文仍用
# 原版 ARIAL，所以整门语言算 noto、带三个 PR2PlDisplay 文件。
#
# fr 的译文是英文原文键位下的法语：3548 条里 3279 条与 GOG 法语版
# （fr.gog_1.1.2.42）原文逐字相同，其余为补齐与修订；重音字符原版拉丁字体
# 已覆盖，因此按 config 出包。
#
# it 的译文在英文原文键位下：3548 条里 2892 条为意语（主池 12 批与 00/01/02
# 三批全部推完），1 条原样保留，其余 655 条与 en 原文逐字相同——城镇地名、
# 船长与开发者人名、IDM 标识符、纯图标签、占位串与符号集。de / fr 在这 655
# 条上同样保留英文（596 / 603 条同文），属同一口径，因此按完整语言出包。
# 意语用字全在原版拉丁 ARIAL.TTF 覆盖内（1223 码位、缺字 0），按 config 出包。
#
