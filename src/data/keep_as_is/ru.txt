# 一行一条：id<TAB>理由。理由取值：key=按键名、label=界面键名、
# id=脚本/资源标识、credit=职员表、save-name=存档文件名（必须纯 ASCII）。
#
# save-name 的判据与其余不同：值不必等于英文，但不许出现非 ASCII 字符 ——
# PR2.exe 只导入 ANSI 版文件 API，非 ASCII 文件名写出去就是乱码，读回来弹「存档无效」。
# 各语言共用的条目（职员表、场景存档名、存档名模板）在 _common.txt，本文件只写本语言独有的。
#

# 译成「Удалить」之类的反而对不上键帽（现有译文里的 CTRL / Shift / TAB 也是这么写的）。
