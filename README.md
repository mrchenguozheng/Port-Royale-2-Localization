# Port Royale 2 Localization

《Port Royale 2》的本地化项目：**用外挂语言包替换界面文本，原版 `PR2.exe` 全程不改。**

Steam 版 `PR2.exe` 带 Valve CEG 完整性校验，改 exe 哪怕一个字节都会
启动即报 `Application load error 3:0000065432`。所以走运行时注入：
启动器把 DLL 注入游戏进程，DLL 接管引擎的取字调用，把语言包里的译文送进去。

---

## 快速开始

需要 Visual Studio（C++ 桌面开发组件）+ Python 3.11 且带 tkinter。

```
start.bat
```

它只打开本地化工具窗口，**不自动编译**。窗口分三段，段号就是步骤：

1. **构建** —— 首次要点「构建注入器」拿到 DLL 与启动器；勾选语言点「构建所选语言」
2. **部署** —— 选游戏目录，点「复制到游戏目录」
3. **启动** —— 「启动游戏（已注入）」；只想改配置不想进游戏就用「保存语言设置」

之后用游戏目录里的 `PR2Launcher.exe` 启动
（**不要直接跑 `PR2.exe`**，那样不会加载语言包）。
想换语言在窗口的「启动语言」下拉里选 —— 下拉本身不写盘；
点上面两个按钮时，语言**确有变化**才写进 `locale.ini`，
没变化就一个字节都不动。

改译文只需第 1 段的后一个按钮（0.5 秒），不用重编 C++（4.5 秒）。
按钮细节见[构建与安装](docs/构建与安装.md)。

## 仓库结构

```
Port Royale 2 Localization/
├─ start.bat                  日常入口：只开窗口
├─ src/
│  ├─ translations/         译文人工维护源（唯一）
│  │  ├─ zh.toml
│  │  └─ references/        en.gog_1.1.2.3.toml / fr.gog_1.1.2.42.toml，只读参考原文
│  ├─ injector/             注入组件源码（纯 C++）
│  ├─ tools/                语言包与译文处理脚本（Python）
│  └─ locale.ini            语言选择模板
├─ build/                   产物，可整个删掉重建
├─ glossary/                术语对照表（中文 zh.md，加语言后是 <语言>.md）
├─ docs/
└─ README.md
```

`start.bat` 放在仓库根，是因为它面向的是「拿到这个仓库的人」，
而不是「要改源码的人」—— 放在根目录，双击的路径最短，
也不会让人以为它跟 `src\` 里那几个构建脚本是一类东西。

| 文件 | 角色 |
|---|---|
| `PR2Launcher.exe` | 启动器。挂起方式启动 `PR2.exe`，注入 DLL 后恢复执行 |
| `PR2TextSource.dll` | 主逻辑。hook 引擎取字的三条路径，把译文替换进去 |
| `PR2Packs\` | 语言包目录。`<语言>.txt` + `locale.ini`，可直接改文本 |

## 加一种语言

三步，不需要碰 C++：

1. `python src\tools\new_lang.py --new-lang <代码>`
   —— 复制一份 `references\en.gog_1.1.2.3.toml` 为 `translations\<代码>.toml`
2. 逐条把每行右边的英文改成译文（没改的会显示英文），
   然后跑 `start.bat`，勾选新语言 → 构建 → 复制到游戏目录
3. 在窗口的「启动语言」下拉里选它，然后点「保存语言设置」
   —— 这时才写进 `locale.ini`

条目不必写全 —— 没写的自动显示英文。详细说明见
[译文与语言包](docs/译文与语言包.md#加一种语言)。

## 已知限制

- ⛔ **对 Steam 版尚未生效，原因待查。** 目前只验证过 GOG 版能用。
  Steam 版 `PR2.exe` 带 Valve CEG 完整性校验（13 处标记），
  本项目的注入方案**不修改 exe**，理论上不该受影响，但实测没有生效，
  且原因尚未定位。**用 Steam 版前请先在 GOG 版上验证。**
  待查方向：CEG 的自校验时机是否早于注入点、`A2dLib-2.20A.dll`
  在 Steam 版的存放位置是否不同、hook 的固定偏移是否对不上。
  查清后会更新此处。
- **中文条目整条不显示是分词问题，不是标签问题。** 引擎按空格切词，
  整串汉字超宽会被整条丢弃，只能逐条在游戏里实测。
- **hook 目标与游戏版本绑定。** 代码按固定偏移取 `A2dLib-2.20A.dll`
  的函数，换游戏版本需要改偏移，否则整体不生效。
