# 运行契约

这一页是**发行包内布局、启动行为、宿主挂载、界面语言选择的唯一口径**。
其他文档只解释背景或操作步骤，遇到冲突以本页和代码为准，不要再各写一份。

## 支持环境

- 操作系统：**Windows 10 / Windows 11**（64 位系统跑 32 位游戏）。
- **不支持 Windows 7**：没有在 Win7 上验证过，也不承诺 Rust 运行时与系统 API 的兼容性。
  早期「避开 PowerShell 2.0」的动机不再作为支持 Win7 的理由。
- 已验证游戏版本：GOG 英文 `1.1.2.3`、Steam 英文 `1.1.2.3`、GOG 法语 `1.1.2.42`。
  零售版、其他补丁版不在支持范围。
- 玩家侧不需要 Python、Rust、PowerShell 或任何脚本运行权限。

## 发行包布局

```text
PR2Localization.exe          启动器（挂载 + 拉起游戏）
PR2LocalizationGUI.exe       GUI 入口
PR2LocalizationCore.dll      hook 与文本替换
PR2Localization/
  host/Ascaron.Logging-2.6.dll   宿主代理（解压不覆盖根目录原版）
  packs/<语言>.txt               语言包（本包语言并集）
  packs/locale.default.ini       本包默认语言
  packs/overrides/               空目录，玩家自己的覆盖位
  fonts/*.ttf                    本包实际字体（可为空）
  fonts/font-map.default.ini     四个逻辑字体的映射
  ui/ui.default.ini              本包默认界面文案
  logs/                          运行时日志
README.txt / manifest.json / RUNTIME-VERSION
```

`PR2Localization/host-backup/`、`PR2Localization/host-mount.json` 与
`Ascaron.Logging-2.6.orig.dll` 是**运行时生成**的，不在发行包里。

## 界面语言

- 源码只有 `src/injector-rs/ui/ui.<lang>.ini` 九份（`zh/ja/ko/ru/pl/de/es/fr/it`）。
  **没有源码级的 `ui.default.ini`**：简体中文就是 `ui.zh.ini`。
- 构建时 `build_injector.ps1` 把 `ui.zh.ini` 复制成 `build/runtime/PR2Localization/ui/ui.default.ini`，
  作为开发与运行时的默认文件；仓库里不再保存第二份中文副本。
- 发行包**只放一份** `ui/ui.default.ini`，内容是该分组默认语言的文案：

  | 包 | 默认界面 |
  |---|---|
  | `PR2-zh` | 中文 |
  | `PR2-ja` | 日语 |
  | `PR2-ko` | 韩语 |
  | `PR2-ru` | 俄语 |
  | `PR2-pl` | 波兰语 |
  | `PR2-latin` | 德语（组内 de/es/fr/it 共用一份包） |

- 启动器只读 `ui.default.ini`；玩家自己的 `ui.ini` 按 key 覆盖。
- latin 包里切到 es/fr/it **不会**切换启动器界面：一次安装只有一份默认文案，
  界面在启动时加载，不按游戏 locale 重载。
- 九种界面译文由 AI 起草、按 key 与占位符做过一致性校验，但**没有母语审校**。
  这只影响启动器文案，不影响游戏内语言包。发现措辞问题请在项目 Issue 反馈。

## 宿主挂载

原版 `PR2.exe` 静态导入 `Ascaron.Logging-2.6.dll`，导出只有 `Log`。代理接管 `Log`，
在工作线程加载同目录 `PR2LocalizationCore.dll`。

唯一实现是 `src/injector-rs/pr2_common/src/host.rs`：

1. 校验根目录 DLL：`11,776 B` 且 SHA-256
   `0568EC654E147B6D80F60B779843F020A9C8A7C4E53AE0BC364EC6937024D160`；
2. 原版状态：写 `.orig.dll` 与 `host-backup\` 两份备份，再原子换入代理；
3. 已是本工具代理：要求可验证备份，且根目录 SHA 等于代理 SHA 或清单 `proxy_sha256`；
4. 未知 DLL、代理源等于原版、备份损坏：停止，不覆盖；
5. 每步写 `PR2Localization/logs/host.log`。

入口只有三个，语义相同：

- `PR2Localization.exe` 启动前自动 `ensure_host`；
- `PR2Localization.exe --mount` 只挂载，不启动；
- `PR2Localization.exe --restore` / GUI「还原原版」只还原，不启动。

部署工具链（`pr2ctl`）**不复制这套算法**：复制完文件后调用游戏目录里的
`PR2Localization.exe --mount`；卸载前调用 `--restore`。Python 侧只保留
`has_host` 与 `detect_edition` 两个只读判断。

## 语言包与 locale

- 活动文件 `PR2Localization/packs/locale.ini` 优先；不存在时读
  `locale.default.ini`。活动文件里 `language=` 为空表示玩家明确清空，
  不拿默认值补齐；运行时把空值当「回到内置 `zh`」，不等于原版英文。
- 发行包只带 `locale.default.ini`，部署/解压不覆盖活动 `locale.ini`。
- `packs/overrides/<语言>.txt` 是玩家本机覆盖，不进包，启动器不统计条数。
- 语言包头 `# pack-meta` 记录 `alias` / `min_runtime` / `version` / `entries` /
  `untranslated` / `scope` / `digest`；这些由编译期生成，不手写。

## 版本

`release.ps1 -Version` 是唯一来源：编进 exe（`--version` 与 GUI 副标题）、语言包包头，
并写进 `dist/release.json`。运行时版本另由 `pr2_common/src/lib.rs` 的
`RUNTIME_VERSION` 与包根 `RUNTIME-VERSION` 表示，两者必须一致。
