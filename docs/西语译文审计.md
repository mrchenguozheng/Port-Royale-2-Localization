## 残留 593 条的分类

- 111 条剥掉标签后没有字母：纯标签串（`<gs:TEXTFLUSS_KEINEHOEHE><g:INTEXT_…>`）、纯数字、
  `+++EMPTY+++` 一类占位。
- 442 条是首字母大写形式的专名或标识符：城镇名、姓氏池（英/法/荷/西四组，含
  `le Brun`、`van Dyck`、`de Witt` 这类带前置词的形式）、海盗与剧情人名、开发与发行人员名单、
  `IDM_CONTEST_01_2004_LOG_*` 序列、`QA`、`dummy`、`Port Royale 2`、`F10`–`F12`。
- 36 条含数字，同上，属标识符与键位标签。
- 4 条是 `dummy` / `normal` 这类测试词。

其中约 12 条是西语与英文同形词，按“不硬改”保留：`No`、`Total`、`Balance`、`Normal`、
`Ok`、`Error`、`Hospital`、`Insert`、`Enter`、`Hardware`、`ESC`、`F1`–`F12`。

月份缩写 `May`、`Jun`、`Jul`、`Mar`、`Feb`、`Sep`、`Oct`、`Nov` 与英文同形是
`glossary/terms.toml` 规定的无点形态，不算漏译。

## 口径

- 专名保留源名；真实历史人名、地名用西语正形（`León`、`García`、`María`、`Sofía`、
  `Cristóbal Pinto`）。
- 零售西语 `src/orig/es.retail-1.0.0.toml` 只用于术语与歧义判断，不作母本。它把人名池整池
  换成另一套名字（`Leon→Giovanni`、`Don Mortadello→Andries Dirksen`），池里混有意大利名、
  荷兰名，还混进过德语整句（`Verhältnis zu Spanien: Feindlich (Kaperbrief)`），说明不是干净的
  官方母本。
- 语气：通篇非正式 `tú`；贵族、总督类正式对白用 `usted`。按钮 `Aceptar`/`Cargar`/`Gráficos`
  /`Cerrar`/`Cancelar`。
- UI 名称用 «» 引号。状态词统一 `«Auge»`/`«Recesión»`/`«Recuperación»`。
- 术语：`Ship's Boy`→`Grumete`、`Boatswain`→`Contramaestre`、`Dutch`→`neerlandés`、
  `New Spain`→`Nueva España`、`Grand Mogul`→`Gran Mogol`；`town` 在教程与长文里统一
  `ciudad`，不再混用 `villa`；百位数写 `1.000`。
- 地名：`Providence`→`Providencia`，`New Providence`→`Nueva Providencia`，`Nassau` 保留。
- 键位：`LMB`/`RMB`/`CTRL`/`TAB`/`F5`/`ESC` 保留原样；可读键名本土化
  （`Mayús`、`Bloq Mayús`、`Teclas de dirección`）。
- `scenario000`–`scenario005` 这类内部占位名按零售西语的真实章节名处理
  （`Aprendizaje 1`–`Aprendizaje 4`、`Cerco al poder británico`、`Nacimiento`）；`Pos 1`→`Inicio`
  有法语 `Origine` 互证。

## 验收

```powershell
# 占位符与标签
python -c "import sys,tomllib;sys.path.insert(0,'shared/core');import validate as v;en=tomllib.load(open('src/orig/en.gog_1.1.2.3.toml','rb'));es=tomllib.load(open('src/translations/es.toml','rb'));print([(k,r) for k,val in es.items() if k!='ctx' for r in v.check_text(val,en.get(k),'es')])"

# 术语
python src/tools/terms_check.py --lang es --limit 100

# 整包
python src/tools/pack/compile_pack.py --lang es --strict --no-fonts
```
