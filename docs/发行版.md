# 发行版

> 本页只保留发行 zip 的固定项、`manifest.json` 指针和发版前人工验收。
> 支持环境、启动、locale、版本号与构建命令分别以[运行契约](运行契约.md)、
> [发行规范](发行规范.md)、[构建与安装](构建与安装.md)为准，不再各写一份。

## 1. 一个 zip 里有什么

一个发行分组一个 zip，同时面向 GOG 与 Steam。运行时布局见[运行契约](运行契约.md)；
发行层额外固定：

- `README.txt`：第 1 行语言与适用版本，第 3 行译文标记；
- `RUNTIME-VERSION`：纯整数，用于语言包兼容检查；
- `manifest.json`：发布清单，见[发行规范 §4](发行规范.md#4-包内固定项)；
- `PR2Localization/host/Ascaron.Logging-2.6.dll`：宿主代理，只在 `host/`，不落根目录；
- `PR2Localization/docs/OFL.txt` / `NOTO-SOURCES.txt`：字体许可与来源，只在带字体的包出现。

包里**不带** `VERSION.dll`、不带任何 `.ps1`；根目录也不放同名宿主 DLL，挂载由启动器完成。

当前 7 个分组，每组一个 zip：

| 分组 | 语言 |
|---|---|
| `zh` | `zh` |
| `zh-hant` | `zh-TW`、`zh-HK` |
| `ja` | `ja` |
| `ko` | `ko` |
| `ru` | `ru` |
| `pl` | `pl`（带三个标题字体） |
| `latin` | `de`、`es`、`fr`、`it`、`pt-BR` |

## 4. 发版前验证

1. 解压到干净的游戏副本；
2. 两版都双击 `PR2LocalizationGUI.exe`，选语言后「以所选语言启动」：GOG 直启 `PR2.exe`，
   Steam 走 `steam://rungameid/12470`；根目录 DLL 应变成代理大小；
3. 检查 `PR2Localization\logs\runtime.log` 首行有 `pack '<语言>' ... N entries, M overrides`，
   `host.log` 有挂载记录；
4. 再用 `PR2Localization.exe --lang=<语言>` 直接启动（仅 GOG；Steam 不带 `--lang`，带上会报错退出）；
5. 点 GUI「还原原版」或 `--restore`，确认根目录 DLL 回到 11,776 B、`host-mount.json` 消失；
   再点一次应提示「已经是原版，不需要还原」；
6. 检查界面文本、字体、原版启动；
7. 确认 `README.txt` 支持版本是 **GOG 英文 1.1.2.3 / Steam 英文 1.1.2.3 / GOG 法语 1.1.2.42**；
8. 核对版本三处一致：`PR2Localization.exe --version`、语言包头 `# pack-meta version=`、
   GUI 副标题与语言列表；
9. 核对 `entries` 等于包内数据行数，`digest` 是 12 位小写十六进制，`README.txt` 的
   「语言包变化」与 `manifest.json` 的 `translations[].delta` 说法一致。

## 5. GitHub Actions

仓库有两个工作流：

- `.github/workflows/ci.yml`：`dev` / `main` 的 push、Pull Request 和手动触发；跑
  `python check.py`，再 `python build.py --target all`。
- `.github/workflows/release.yml`：推送 `v<数字>` 版本 tag 自动构建，也可手动触发；
  手动触发只上传 workflow artifact，tag 触发额外创建 **draft** GitHub Release。

Release 在 `windows-latest` 上执行，依赖 Python 3.12 + `fonttools`、Rust stable +
`i686-pc-windows-msvc`、MSVC 链接器 / Windows SDK；15 个 Noto 静态字体已入库，CI 只检查、
不下载、不读系统字体。出包命令与分组来自 `src/release-bundles.toml`，一次生成 7 个包：

```powershell
$bundles = $env:BUNDLES -split ','
python release.py --version $env:VERSION --bundle $bundles --no-pause
```

`SOURCE_DATE_EPOCH` 设为 tag 对应提交时间后，重建包与本地逐字节一致。手动运行只留
artifact；推普通 `vX.Y.Z` tag 才会生成 draft Release，正式发布由人工在 GitHub 选择。
