# 发行版

## 支持的游戏版本

**GOG 英文版 `1.1.2.3` 已实测；Steam 英文版 `1.1.2.3` 已实测（宿主 DLL 代理，
中文界面）。** GOG 法语和其他版本不在支持范围内，不要用本发行包在这些版本上部署。
以后是否支持见[待定事项](待定.md)。

## 版本号

首个正式版：`v1.0.0`。未完成干净 GOG 副本验收时用 `v0.9.0`。

| 版本 | 用途 |
|---|---|
| `v0.9.0` | RC |
| `v1.0.0` | 首次正式公开 |
| `v1.0.x` | 修复、文档、字体小修 |
| `v1.1.0` | 新语言包或明显功能 |
| `v1.2.0` | 新游戏版本（Steam / GOG 法语等） |
| `v2.0.0` | 语言包格式或运行时契约不兼容 |

发行版本与 `PR2_RUNTIME_VERSION` 独立。

打 tag 前重新生成，并创建/推送 tag：

```powershell
.\release.ps1 -Version v1.0.0 -Tag -Push
```

只想先在本地出包、暂不推 tag：

```powershell
.\release.ps1 -Version v1.0.0
```

## 目标

玩家按自己持有的游戏入口下载对应 zip，解压到游戏目录即可使用。GOG 和 Steam 分成两个包：GOG 用启动器注入，Steam 用宿主 DLL 代理。

GOG 版：

```
PR2-zh-gog-v1.0.0.zip
├─ PR2Localization.exe
├─ PR2LocalizationGUI.exe      ← GOG 图形界面入口：选语言启动
├─ PR2LocalizationCore.dll
├─ PR2Localization/
│  ├─ packs/
│  │  ├─ zh.txt
│  │  └─ locale.default.ini   ← 默认语言；用户 locale.ini 优先，包内不放活动文件
│  ├─ fonts/
│  │  ├─ font-map.default.ini
│  │  ├─ NotoSansSC-Regular.ttf
│  │  ├─ NotoSerifSC-Black.ttf
│  │  └─ NotoSerifSC-Bold.ttf
│  ├─ ui/
│  │  ├─ zh.ini
│  │  ├─ en.ini
│  │  └─ ja.ini
│  └─ logs/                 ← 运行时生成
├─ README.txt
├─ NOTO-SOURCES.txt       ← 字体来源说明（不放进 fonts/）
├─ RUNTIME-VERSION        ← 运行时版本，用于语言包兼容检查
└─ OFL.txt
```

GOG 版**不包含 `VERSION.dll`**：GOG 的 `PR2.exe` 不加载同目录代理，这个文件对 GOG 没有作用。

Steam 版在上面同样的布局之外，在根目录额外多两个文件：

```
PR2-zh-steam-v1.0.0.zip
├─ Ascaron.Logging-2.6.dll       ← 宿主代理，PR2.exe 静态导入它
├─ PR2HostMount.ps1              ← 校验、备份、挂载、还原
├─ PR2Localization.exe
├─ PR2LocalizationGUI.exe
├─ PR2LocalizationCore.dll
└─ PR2Localization/ ...          ← 与 GOG 版相同
```

Steam 的挂载脚本只替换 `Ascaron.Logging-2.6.dll`。它会校验原版的 `11,776 B` 和
SHA-256 `0568EC654E147B6D80F60B779843F020A9C8A7C4E53AE0BC364EC6937024D160`；
通过后备份为 `Ascaron.Logging-2.6.orig.dll` 和
`PR2Localization\host-backup\Ascaron.Logging-2.6.dll`，再换代理。大小或哈希不对时
停止，不覆盖未知文件。

`PR2Localization/fonts/` 放实际字体文件（默认保留 Noto 原始文件名）和
`font-map.default.ini`，不按语言单开子目录，也不放说明文件；游戏会扫描这个目录。
四个游戏逻辑名由默认映射指向这些实际文件，两个逻辑名可指向同一文件。
要自定义时新建或编辑同目录的 `font-map.ini`，运行时优先读取；发行包不含这个文件名，
因此解压升级不会覆盖手工配置。同一次安装只放一个语言的字体。字体来源说明统一放在包根 `NOTO-SOURCES.txt`。

GOG 的正式入口是启动器：双击 `PR2LocalizationGUI.exe` → 列表里选语言 → 「以所选语言启动」；
「启动原版」直接进英文。GOG 不要直接双击 `PR2.exe`：加载器会把 `VERSION.dll`
解析到 `C:\Windows\SysWOW64\VERSION.dll`，同目录代理不会进入游戏进程。
GUI 只是调用 `PR2Localization.exe --lang=…`，由它注入 `PR2LocalizationCore.dll`；
DLL 通过路径重定向让游戏读取 `PR2Localization/fonts/`，不覆盖根目录原版字体。
DLL 会按 `locale.ini`（没有活动文件时按 `locale.default.ini`）选择语言，并用 `font-map.ini`
（不存在时用 `font-map.default.ini`）的语言节选择具体字体文件。活动 `locale.ini` 存在但
`language=` 为空时也会保留这个空值，不自动回退默认语言。发行包不含活动 `locale.ini`，
解压升级不会覆盖玩家已选语言；`packs\overrides\` 是用户本机覆盖，部署/升级不会删除。

Steam 版：解压后在游戏根目录运行
`powershell -ExecutionPolicy Bypass -File .\PR2HostMount.ps1 -Action Mount`，
再从 Steam 正常启动。代理由 `PR2.exe` 静态导入的 `Ascaron.Logging-2.6.dll` 加载，
并加载同目录 `PR2LocalizationCore.dll`；需要临时指定语言时，也可以用
`PR2LocalizationGUI.exe`。还原时运行同一脚本的 `-Action Restore`。
GUI 界面为单列分层布局，按系统 DPI 缩放；语言包、启动和结束进程的按钮分组显示。
如果游戏退出时卡死，点「结束游戏进程」：它只结束本目录启动的 `PR2.exe`，
会先弹确认，不会误杀 Steam 或其他目录的游戏副本。

语言包自己带显示名和 GUI 语言：

```toml
# src/packs/zh.toml
alias = "简体中文"
gui = "zh"
```

编译后写进语言包开头：

```
# pack-meta alias=简体中文
# pack-meta gui=zh
```

游戏会忽略 `#` 注释；GUI 读取它们后：

- 列表显示 `alias`；
- 切换到该语言包时，界面文字换成 `gui` 对应的 `PR2Localization/ui/<gui>.ini`。

没有 `# pack-meta` 的语言包，列表直接显示语言代码；不再支持外部别名覆盖。

GUI 启动成功后会直接把所选语言写回活动配置：

```ini
# PR2Localization/packs/locale.ini
language=zh
```

发行包只带 `PR2Localization/packs/locale.default.ini`；已有 `locale.ini` 时 GUI 和运行时都以它为准。
下次打开启动器会默认选它；GOG 仍从 `PR2LocalizationGUI.exe` 进入，不要直接双击 `PR2.exe`。

显示名只来自语言包 `# pack-meta alias`；界面语言来自 `# pack-meta gui`。
没有 `gui` 元数据时跟随 Windows UI 语言，再回退英文。

语言包可以声明最低运行时版本：

```
# pack-meta min_runtime=1
```

`min_runtime` 高于当前运行时版本时，GUI/启动器会拒绝启动并提示更新，
避免“旧 DLL + 新语言包”静默不翻译。

不包含游戏本体、`.cpr`、地图、音乐等游戏资源。

## 字体

发行版**不缝合**，直接把完整 Noto 字体以原始文件名放进 `fonts`：

| 游戏逻辑名 | 映射到的实际文件 |
|---|---|
| `ARIAL.TTF` | `NotoSansSC-Regular.ttf` / `NotoSansJP-Regular.ttf` |
| `ELGRECO_.TTF` | `NotoSerifSC-Black.ttf` / `NotoSerifJP-Black.ttf` |
| `Tiepolo_black.ttf` | `NotoSerifSC-Black.ttf` / `NotoSerifJP-Black.ttf` |
| `Tiepolo_bold.ttf` | `NotoSerifSC-Bold.ttf` / `NotoSerifJP-Bold.ttf` |

- **不裁剪**：保留完整字符集；
- VF 会实例化成静态字重；
- 字体使用 SIL OFL 1.1，发行包附 `OFL.txt`；
- 获取渠道：
  - Google Fonts：Noto Sans SC / Noto Serif SC / Noto Sans JP / Noto Serif JP
  - <https://fonts.google.com/noto>
  - <https://openfontlicense.org/>

字体较大（中文一套约 50 MB，zip 约 32 MB）。这是“不裁剪”的代价。

包内保留实际 Noto 文件名，**不再把文件改名为 `ARIAL.TTF` 等游戏逻辑名**；
`ELGRECO_.TTF` 和 `Tiepolo_black.ttf` 可以映射到同一个
`NotoSerifSC-Black.ttf`，因此默认包是 3 个实际 TTF 加 1 个 `font-map.default.ini`。

如果本机已经有静态的 `NotoSansSC-Regular`、`NotoSerifSC-Bold`、`NotoSerifSC-Black`
等文件，生成过程只是复制，**不需要 fontTools**。只有源文件是
`*-VF.ttf` 可变字体时，才需要 fontTools 把它实例化成静态字重。

默认 `--fonts noto` 在 `PR2Localization\fonts\` 平铺这些实际字体文件，
并附带 `font-map.default.ini`；映射缺失或文件不存在时回退根目录原版。

`--fonts config` 只把 `src/font-map.ini` 复制为
`PR2Localization\fonts\font-map.default.ini`，不携带 TTF。映射值只接受
`PR2Localization\fonts\` 内的实际文件名，不读 `%WINDIR%\Fonts`；使用这种包
必须自己把映射中写明的字体文件放进 `fonts`，否则 GUI 会提示字体缺失。
用户自定义时写同目录的 `font-map.ini`，它优先于默认文件，解压升级不会覆盖它。

### 字体缓存

生成结果缓存在：

```
build/cache/noto/
```

缓存键包含源字体内容 SHA-256、字重、目标文件名、fontTools 版本和缓存版本：
源字体或参数变化才会重算。第二次打包同一语言会直接用缓存。

强制重算：

```powershell
python src\tools\font\make_noto_fonts.py --lang zh --out <目录> --no-cache
```

换缓存目录：

```powershell
python src\tools\font\make_noto_fonts.py --lang zh --out <目录> --cache-dir D:\font-cache
```

`make_release.py` 默认复用缓存；强制重算：

```powershell
python src\tools\pack\make_release.py --lang zh --edition gog --version v1.0.0
python src\tools\pack\make_release.py --lang zh --edition steam --version v1.0.0 --no-font-cache
```

缝合字体（`subset_fonts.py`）另有一套 `.stitch.json` 缓存，按用字集合、
donor 字体和版本判断，不重复缝合。

## 字体缺失时

### 程序怎么判断

本地化启动时检查：

```
<游戏目录>\PR2Localization\fonts\
├─ font-map.default.ini
├─ NotoSansSC-Regular.ttf
├─ NotoSerifSC-Black.ttf
└─ NotoSerifSC-Bold.ttf
```

启动器检查的是当前映射（`font-map.ini` 存在时优先，否则 `font-map.default.ini`）
的四个逻辑名是否都能映射到 `fonts` 内真实存在的文件；
四个缺任意一个，就算“字体不完整”。两个逻辑名可以指向同一个实际文件。

### 程序怎么处理

**GUI（`PR2LocalizationGUI.exe`）**

弹窗：

> `PR2Localization\fonts\ 缺少字体 TTF。仍然启动会使用原版拉丁字体，中文可能缺字。仍要启动吗？`

- 选“是”：继续启动；
- 选“否”：取消。

**启动器（`PR2Localization.exe`）**

即使绕过 GUI，也会再次检查：

- 字体完整：设置 `PR2_FONT_DIR=<语言>`，重定向到 `PR2Localization\fonts\`；
- 字体不完整：不设置重定向，回退到 `fonts\` 根目录的原版字体，并在控制台打印：

```
[PR2Loc] PR2Localization\fonts 字体不完整，回退到原版根目录字体
```

这时游戏能启动，但中文很可能显示空白；只有原版拉丁字符正常。

### 用户应该怎么处理

1. **检查目录和映射**
   确认游戏目录下确实有：

   ```
   PR2Localization\fonts\font-map.default.ini
   PR2Localization\fonts\NotoSansSC-Regular.ttf
   PR2Localization\fonts\NotoSerifSC-Black.ttf
   PR2Localization\fonts\NotoSerifSC-Bold.ttf
   ```

   并确认当前映射（`font-map.ini` 存在时优先，否则 `font-map.default.ini`）的四个逻辑名指向上面的实际文件。

2. **重新解压字体**
   从发行 zip 里解压 `PR2Localization\fonts\` 整个目录；只复制语言包
   `PR2Localization\packs\<语言>.txt` 是不够的。

3. **不要放到根目录**
   原版字体留在 `fonts\` 根目录，本地化字体必须放
   `PR2Localization\fonts\`，实际字体文件和 `font-map.default.ini` 平铺，不建语言子目录。

4. **检查杀毒软件**
   字体文件较大，偶尔会被隔离；恢复后重新启动。

5. **确认语言代码一致**
   `PR2Localization\packs\<语言>.txt`、`PR2Localization\fonts\`、`locale.ini`（或
   `locale.default.ini`）的 `language=` 必须是同一个代码（如都是 `zh`）。

6. **仍要启动**
   可以选择继续，但只能看到原版拉丁字体；中文缺失不是游戏坏了。

### 原版字体

原版四个 TTF 留在 `fonts\` 根目录，不会被本地化覆盖。
启动器第一次替换前还会备份到 `PR2Localization\fonts\_original\`（SHA-256 校验）；
`PR2Localization.exe --vanilla` 使用根目录原版。

## 生成

### 1. 一键出包

需要 Rust（rustup）、`i686-pc-windows-msvc` target、Python 3.11+ 和 PowerShell 7：

```powershell
rustup target add i686-pc-windows-msvc
Set-Location <仓库目录>
.\release.ps1 -Version v1.0.0
```

默认流程：

1. 调 `build.ps1 -Target Injector` 构建运行时；
2. 从 `src\translations\*.toml` 发现语言；
3. 对每个语言分别调 `make_release.py --edition gog` 和 `--edition steam`，
   编译语言包、生成 Noto 字体、组装两个 zip。

输出：

```
dist\PR2-zh-gog-v1.0.0.zip
dist\PR2-zh-steam-v1.0.0.zip
dist\PR2-ja-gog-v1.0.0.zip
dist\PR2-ja-steam-v1.0.0.zip
```

只打一个语言：

```powershell
.\release.ps1 -Version v1.0.0 -Lang zh
```

只打 GOG 或只打 Steam：

```powershell
.\release.ps1 -Version v1.0.0 -Edition gog
.\release.ps1 -Version v1.0.0 -Edition steam
```

已经有 `build\runtime` 时，跳过注入器：

```powershell
.\release.ps1 -Version v1.0.0 -SkipInjector
```

默认用 Noto 字体；只做本地流程测试、不想生成大字体包时：

```powershell
.\release.ps1 -Version v0.0.0-test -Fonts none -SkipInjector
```

生成“只带映射、不打包字体”的包：

```powershell
.\release.ps1 -Version v0.0.0-config -Fonts config -SkipInjector
```

`-Fonts config` 不复制任何 TTF，只把 `src\font-map.ini` 复制为
`PR2Localization\fonts\font-map.default.ini`。映射值只接受 `PR2Localization\fonts\`
内的实际文件名；使用这种包时必须自己把映射中写明的字体文件放进 `fonts`，
否则 GUI 会提示字体缺失。

默认 `-Fonts noto` 把实际 Noto 文件平铺进 `PR2Localization\fonts\`，
同时附带 `font-map.default.ini`；用户自定义写 `font-map.ini`，运行时优先读取。

`make_release.py` 会自动：

- 编译语言包；
- 生成 Noto 字体（默认 `--fonts noto`）；`--fonts config` 时不生成字体；
- 复制运行时、`PR2Localization/ui/`、`PR2Localization/packs/` 和字体/字体映射；
- GOG 版不复制宿主 DLL；Steam 版复制 `Ascaron.Logging-2.6.dll` 和 `PR2HostMount.ps1`；
- 写入 `RUNTIME-VERSION` 和支持版本说明；
- 打包 `README.txt`；Noto/缝合包才附带 `OFL.txt`。

第一次生成 VF 静态字重需要：

```powershell
python -m pip install fonttools
```

字体结果缓存在 `build\cache\noto\`，之后打包会直接复用。
强制重算：

```powershell
.\release.ps1 -Version v1.0.0 -NoFontCache
```

低层排障时仍可直接调用：

```powershell
python src\tools\pack\make_release.py --lang zh --edition gog --version v1.0.0
python src\tools\pack\make_release.py --lang zh --edition steam --version v1.0.0
```

### 3. 打包方式

当前仍采用**一个语言 + 一个入口一个 bundle**（运行时 + 语言包 + 字体在一个 zip 里）。
GOG 包解压即用，不含宿主 DLL；Steam 包解压后先运行 `PR2HostMount.ps1 -Action Mount`
（校验原版大小/SHA-256、备份、替换），再从 Steam 启动。

Runtime + Language 拆分包保留为以后方案，暂不启用；等语言数量明显增加或
运行时需要频繁单独更新时再评估。

### 4. 发版前验证

1. 解压到干净的游戏副本；
2. GOG 双击 `PR2LocalizationGUI.exe`，选语言后「以所选语言启动」；Steam 先在游戏根目录运行
   `PR2HostMount.ps1 -Action Mount`，再从 Steam 启动；
3. 检查 `PR2Localization\logs\runtime.log` 首行有 `pack '<语言>' ... overrides`；
4. 再用 `PR2Localization.exe --lang=<语言>` 直接启动，检查命令行入口；
5. 检查界面文本、字体、原版启动；
6. 确认 `README.txt` 支持版本是 **GOG 英文 1.1.2.3 已实测 / Steam 英文 1.1.2.3 已实测（宿主 DLL）**。

只生成 Noto 字体，不跑缝合：

```powershell
python src\tools\font\make_noto_fonts.py --lang zh --out build\runtime\PR2Localization\fonts
```

### 其他语言

在 `src/tools/font/make_noto_fonts.py` 的 `LANGS` 里加映射，例如：

```python
"ko": {
    "sans": ("NotoSansKR", 400),
    "serif": ("NotoSerifKR", (700, 900)),
    "label": "Korean",
},
```

字体命名规则需与本机安装一致；没有对应 Noto 字体时先在 Google Fonts 下载安装。

## 进阶：裁剪与缝合

两者都不属于发行版默认流程：

- **裁剪**：`fontsubset.py` 按用字缩小字体；
- **缝合**：`subset_fonts.py` 把原版拉丁字体和 donor 缝合，保留原版字形。

缝合字体是衍生作品，**只能自用，不要放进公开 release**。
`make_release.py --fonts stitch` 只用于私有包。

## GitHub Actions

仓库有两个工作流：

- `.github/workflows/ci.yml`：`dev` / `main` 的 push、Pull Request 和手动触发。
  跑 `.\check.ps1`，再用 `.\build.ps1 -Target All` 编译 Rust、宿主代理和 zh/ja 语言包。
- `.github/workflows/release.yml`：`release-v*` tag 或手动触发。
  手动触发只上传 workflow artifact；tag 触发会额外发布 GitHub Release。

Release 工作流在 `windows-latest` 上执行，依赖：

- Python 3.12 + `fonttools`；
- Rust stable + `i686-pc-windows-msvc`；
- MSVC 链接器 / Windows SDK（Rust `i686-pc-windows-msvc` target 需要；项目不含 C++ 源码）；
- Google Fonts 的 Noto Sans/Serif SC/JP 可变字体，下载到
  `%LOCALAPPDATA%\Microsoft\Windows\Fonts`，由 `make_noto_fonts.py` 实例化成静态字重。

核心出包命令：

```powershell
.\release.ps1 -Version $env:VERSION -Edition all -Lang @('zh','ja') -NoPause
```

一次生成四个包：

```text
dist/PR2-zh-gog-$env:VERSION.zip
dist/PR2-zh-steam-$env:VERSION.zip
dist/PR2-ja-gog-$env:VERSION.zip
dist/PR2-ja-steam-$env:VERSION.zip
```
