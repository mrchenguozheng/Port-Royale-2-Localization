# 发行版

## 支持的游戏版本

**GOG 英文版 `1.1.2.3` 已实测；Steam 英文版 `1.1.2.3` 为实验性支持，
`VERSION.dll` 代理加载链已构建，待进游戏验证。** GOG 法语和其他版本不在支持范围内，
不要用本发行包在这些版本上部署。以后是否支持见[待定事项](待定.md)。

## 版本号

首个正式版：`v1.0.0`。未完成干净 GOG 副本验收时用 `v0.9.0`。

| 版本 | 用途 |
|---|---|
| `v0.9.0` | RC |
| `v1.0.0` | 首次正式公开 |
| `v1.0.x` | 修复、文档、字体小修 |
| `v1.1.0` | 新语言包或明显功能 |
| `v1.2.0` | 新游戏版本（Steam / GOG 法语等） |
| `v2.0.0` | 语言包格式或运行时契约不兼容 |

发行版本与 `PR2_RUNTIME_VERSION` 独立。

打 tag 前重新生成，并创建/推送 tag：

```powershell
.\release.ps1 -Version v1.0.0 -Tag -Push
```

只想先在本地出包、暂不推 tag：

```powershell
.\release.ps1 -Version v1.0.0
```

## 目标

玩家下载一个语言包，解压到游戏目录即可使用：

```
PR2-zh-v1.0.0.zip
├─ VERSION.dll              ← Steam 实验性代理宿主（GOG 不使用）
├─ PR2Launcher.exe
├─ PR2LauncherGUI.exe      ← GOG 图形界面入口：选语言启动
├─ PR2TextSource.dll
├─ ui/
│  ├─ zh.ini
│  ├─ en.ini
│  └─ ja.ini
├─ PR2Packs/
│  ├─ zh.txt
│  └─ locale.ini
├─ fonts/
│  └─ zh/
│     ├─ ARIAL.TTF
│     ├─ ELGRECO_.TTF
│     ├─ Tiepolo_black.ttf
│     └─ Tiepolo_bold.ttf
├─ README.txt
├─ NOTO-SOURCES.txt       ← 字体来源说明（不放进 fonts/）
├─ RUNTIME-VERSION        ← 运行时版本，用于语言包兼容检查
└─ OFL.txt
```

`fonts/<语言>/` 只放四个 TTF，不放说明文件；游戏会扫描这个目录。
字体来源说明统一放在包根 `NOTO-SOURCES.txt`。

GOG 的正式入口是启动器：双击 `PR2LauncherGUI.exe` → 列表里选语言 → 「以所选语言启动」；
「启动原版」直接进英文。GOG 不要直接双击 `PR2.exe`：加载器会把 `VERSION.dll`
解析到 `C:\Windows\SysWOW64\VERSION.dll`，同目录代理不会进入游戏进程。
GUI 只是调用 `PR2Launcher.exe --lang=…`，由它注入 `PR2TextSource.dll`；
DLL 通过路径重定向让游戏读取 `fonts/<语言>/`，不覆盖根目录原版字体。
DLL 会按 `locale.ini` 选择语言，并在 `fonts/<语言>/` 存在时使用该字体目录。

Steam 仍保留 `VERSION.dll` 代理作为实验性自然加载路径；代理冲突或需要指定语言时，
同样用 `PR2LauncherGUI.exe` 注入。GUI 界面为单列分层布局，按系统 DPI 缩放；
语言包、启动和结束进程的按钮分组显示。
如果游戏退出时卡死，点「结束游戏进程」：它只结束本目录启动的 `PR2.exe`，
会先弹确认，不会误杀 Steam 或其他目录的游戏副本。

语言包自己带显示名和 GUI 语言：

```toml
# src/packs/zh.toml
alias = "简体中文"
gui = "zh"
```

编译后写进语言包开头：

```
# pack-meta alias=简体中文
# pack-meta gui=zh
```

游戏会忽略 `#` 注释；GUI 读取它们后：

- 列表显示 `alias`；
- 切换到该语言包时，界面文字换成 `gui` 对应的 `ui/<gui>.ini`。

没有 `# pack-meta` 的语言包，列表直接显示语言代码；不再支持外部别名覆盖。

GUI 启动成功后会直接把所选语言写回：

```ini
# PR2Packs/locale.ini
language=zh
```

下次打开读取它，直接双击 `PR2.exe` 也使用同一语言。

显示名只来自语言包 `# pack-meta alias`；界面语言来自 `# pack-meta gui`。
没有 `gui` 元数据时跟随 Windows UI 语言，再回退英文。

语言包可以声明最低运行时版本：

```
# pack-meta min_runtime=1
```

`min_runtime` 高于当前运行时版本时，GUI/启动器会拒绝启动并提示更新，
避免“旧 DLL + 新语言包”静默不翻译。

不包含游戏本体、`.cpr`、地图、音乐等游戏资源。

## 字体

发行版**不缝合**，直接用完整的 Noto 字体替换：

| 游戏文件 | 字体 |
|---|---|
| `ARIAL.TTF` | Noto Sans SC/JP Regular |
| `ELGRECO_.TTF` | Noto Serif SC/JP Black |
| `Tiepolo_black.ttf` | Noto Serif SC/JP Black |
| `Tiepolo_bold.ttf` | Noto Serif SC/JP Bold |

- **不裁剪**：保留完整字符集；
- VF 会实例化成静态字重；
- 字体使用 SIL OFL 1.1，发行包附 `OFL.txt`；
- 获取渠道：
  - Google Fonts：Noto Sans SC / Noto Serif SC / Noto Sans JP / Noto Serif JP
  - <https://fonts.google.com/noto>
  - <https://openfontlicense.org/>

字体较大（中文一套约 50 MB，zip 约 32 MB）。这是“不裁剪”的代价。

发行包保留四个独立的 TTF，**不做“同字形文件别名/硬链接”去重**：
以后可能给不同游戏文件名配不同字体或字重，去重会把这种灵活性锁死。

如果本机已经有静态的 `NotoSansSC-Regular`、`NotoSerifSC-Bold`、`NotoSerifSC-Black`
等文件，生成过程只是复制并改名，**不需要 fontTools**。只有源文件是
`*-VF.ttf` 可变字体时，才需要 fontTools 把它实例化成静态字重。

### 字体缓存

生成结果缓存在：

```
build/cache/noto/
```

缓存键包含源字体内容 SHA-256、字重、目标文件名、fontTools 版本和缓存版本：
源字体或参数变化才会重算。第二次打包同一语言会直接用缓存。

强制重算：

```powershell
python src\tools\font\make_noto_fonts.py --lang zh --out <目录> --no-cache
```

换缓存目录：

```powershell
python src\tools\font\make_noto_fonts.py --lang zh --out <目录> --cache-dir D:\font-cache
```

`make_release.py` 默认复用缓存；强制重算：

```powershell
python src\tools\pack\make_release.py --lang zh --version v1.0.0 --no-font-cache
```

缝合字体（`subset_fonts.py`）另有一套 `.stitch.json` 缓存，按用字集合、
donor 字体和版本判断，不重复缝合。

## 字体缺失时

### 程序怎么判断

本地化启动时检查：

```
<游戏目录>\fonts\<语言>\
├─ ARIAL.TTF
├─ ELGRECO_.TTF
├─ Tiepolo_black.ttf
└─ Tiepolo_bold.ttf
```

四个文件缺任意一个，就算“字体不完整”。

### 程序怎么处理

**GUI（`PR2LauncherGUI.exe`）**

弹窗：

> `fonts\zh\ 缺少字体 TTF。仍然启动会使用原版拉丁字体，中文可能缺字。仍要启动吗？`

- 选“是”：继续启动；
- 选“否”：取消。

**启动器（`PR2Launcher.exe`）**

即使绕过 GUI，也会再次检查：

- 字体完整：设置 `PR2_FONT_DIR=<语言>`，重定向到 `fonts\<语言>\`；
- 字体不完整：不设置重定向，回退到 `fonts\` 根目录的原版字体，并在控制台打印：

```
[PR2Launch] fonts\zh\ 字体不完整，回退到原版根目录字体
```

这时游戏能启动，但中文很可能显示空白；只有原版拉丁字符正常。

### 用户应该怎么处理

1. **检查目录**
   确认游戏目录下确实有：

   ```
   fonts\zh\ARIAL.TTF
   fonts\zh\ELGRECO_.TTF
   fonts\zh\Tiepolo_black.ttf
   fonts\zh\Tiepolo_bold.ttf
   ```

2. **重新解压字体**
   从发行 zip 里解压 `fonts\<语言>\` 整个目录；只复制语言包
   `PR2Packs\<语言>.txt` 是不够的。

3. **不要放到根目录**
   原版字体留在 `fonts\` 根目录，本地化字体必须放
   `fonts\<语言>\` 子目录。

4. **检查杀毒软件**
   字体文件较大，偶尔会被隔离；恢复后重新启动。

5. **确认语言代码一致**
   `PR2Packs\<语言>.txt`、`fonts\<语言>\`、`locale.ini` 的 `language=`
   必须是同一个代码（如都是 `zh`）。

6. **仍要启动**
   可以选择继续，但只能看到原版拉丁字体；中文缺失不是游戏坏了。

### 原版字体

原版四个 TTF 留在 `fonts\` 根目录，不会被本地化覆盖。
启动器第一次替换前还会备份到 `fonts\_original\`（SHA-256 校验）；
`PR2Launcher.exe --vanilla` 使用根目录原版。

## 生成

### 1. 一键出包

需要 Rust（rustup）、`i686-pc-windows-msvc` target、Python 3.11+ 和 PowerShell 7：

```powershell
rustup target add i686-pc-windows-msvc
Set-Location <仓库目录>
.\release.ps1 -Version v1.0.0
```

默认流程：

1. 调 `build.ps1 -Target Injector` 构建运行时；
2. 从 `src\translations\*.toml` 发现语言；
3. 调 `make_release.py` 编译语言包、生成 Noto 字体、组装 zip。

输出：

```
dist\PR2-zh-v1.0.0.zip
dist\PR2-ja-v1.0.0.zip
```

只打一个语言：

```powershell
.\release.ps1 -Version v1.0.0 -Lang zh
```

已经有 `build\runtime` 时，跳过注入器：

```powershell
.\release.ps1 -Version v1.0.0 -SkipInjector
```

默认用 Noto 字体；只做本地流程测试、不想生成大字体包时：

```powershell
.\release.ps1 -Version v0.0.0-test -Fonts none -SkipInjector
```

`make_release.py` 会自动：

- 编译语言包；
- 生成 Noto 字体（默认 `--fonts noto`）；
- 复制运行时、`ui/`、`PR2Packs/` 和字体；
- 写入 `RUNTIME-VERSION` 和支持版本说明；
- 打包 `README.txt`、`OFL.txt`、`NOTO-SOURCES.txt`。

第一次生成 VF 静态字重需要：

```powershell
python -m pip install fonttools
```

字体结果缓存在 `build\cache\noto\`，之后打包会直接复用。
强制重算：

```powershell
.\release.ps1 -Version v1.0.0 -NoFontCache
```

低层排障时仍可直接调用：

```powershell
python src\tools\pack\make_release.py --lang zh --version v1.0.0
```

### 3. 打包方式

当前仍采用**一语言一个 bundle**（运行时 + 语言包 + 字体在一个 zip 里），
普通玩家解压即用。

Runtime + Language 拆分包保留为以后方案，暂不启用；等语言数量明显增加或
运行时需要频繁单独更新时再评估。

### 4. 发版前验证

1. 解压到干净的游戏副本；
2. GOG 双击 `PR2LauncherGUI.exe`，选语言后「以所选语言启动」；Steam 从 Steam 启动；
3. 检查 `PR2TextSource.log` 首行有 `pack '<语言>' ... overrides`；
4. 再用 `PR2Launcher.exe --lang=<语言>` 直接启动，检查命令行入口；
5. 检查界面文本、字体、原版启动；
6. 确认 `README.txt` 支持版本是 **GOG 英文 1.1.2.3 已实测 / Steam 英文实验性**。

只生成 Noto 字体，不跑缝合：

```powershell
python src\tools\font\make_noto_fonts.py --lang zh --out dist\PR2-zh-v1.0.0\fonts
```

### 其他语言

在 `src/tools/font/make_noto_fonts.py` 的 `LANGS` 里加映射，例如：

```python
"ko": {
    "sans": ("NotoSansKR", 400),
    "serif": ("NotoSerifKR", (700, 900)),
    "label": "Korean",
},
```

字体命名规则需与本机安装一致；没有对应 Noto 字体时先在 Google Fonts 下载安装。

## 进阶：裁剪与缝合

两者都不属于发行版默认流程：

- **裁剪**：`fontsubset.py` 按用字缩小字体；
- **缝合**：`subset_fonts.py` 把原版拉丁字体和 donor 缝合，保留原版字形。

缝合字体是衍生作品，**只能自用，不要放进公开 release**。
`make_release.py --fonts stitch` 只用于私有包。

## GitHub Actions

tag 触发，按语言出包：

```yaml
on:
  push:
    tags: ['release-v*']

jobs:
  release:
    runs-on: windows-latest
    strategy:
      matrix:
        lang: [zh, ja]
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: '3.12' }
      - run: pip install fonttools
      - name: Add 32-bit Rust target
        run: rustup target add i686-pc-windows-msvc
      - name: Derive version
        shell: pwsh
        run: |
          $v = "${{ github.ref_name }}".Replace("release-", "")
          "VERSION=$v" >> $env:GITHUB_ENV
      - name: Build runtime
        run: .\build.ps1 -Target Injector -NoPause
      - name: Build release zip
        run: .\release.ps1 -Version $env:VERSION -Lang ${{ matrix.lang }} -SkipInjector -NoPause
      - uses: softprops/action-gh-release@v2
        with:
          files: dist/*.zip
```

`release.ps1` 默认会先构建注入器；CI 里已经单独构建过，所以加 `-SkipInjector`。
Noto 字体在 runner 上可用（或提前下载到固定路径）。
