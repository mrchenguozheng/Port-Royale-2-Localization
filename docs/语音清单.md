## 与文本表的对应关系（待办）

- 语言包只有 `hash = 文本`，语音文件只有基名，**两者之间没有现成索引**；
- `PR2.exe` 里有语音路径与内部 ID 名的字符串池（如 `music/voice/0b_En.mp3` 附近是 `ID_NPC_VICEROY_ANNEX_TAKEN_ADD`、`ID_QST_WELCOME_*`、`ID_NPC_WIFE_DAUGHTER_ANGRY_01`），但这些 ID **算不出**语言包的 hash（试过 crc32/djb2/fnv/sdbm/murmur3 等 ~40 种算法，0 命中）；
- 因此要建立「语音 ↔ hash」映射，只能把音频转写成文字，再和英/法原文做模糊匹配；
- 33 篇历史长文（`0xd4cd…`）与 `Hist_Text_00..32` 数量正好相等，可以先用时长×长度排序做一次对齐验证，作为交叉证据。

## 目前的卡点

沙箱里没有任何语音识别工具，且 PyPI 不可达、Windows 自带识别器在沙箱内被拒绝访问（`E_ACCESSDENIED`）。已确认本机可用：

- `ffmpeg`（已能转 16k 单声道 wav）；
- `%USERPROFILE%\.cache\whisper` 里已有 `base.pt` 与 `large-v3.pt` 模型；
- Python 3.11（`py -3.11`）与 `uv` 可用，但**没有安装 whisper 包**。

所以需要你在沙箱外装一次 whisper（模型不用重下）。
