## 当前契约

**运行包内布局、宿主挂载、界面语言与支持环境以[运行契约](运行契约.md)为唯一口径**，
这里不重复细节。只留三条跨文档的索引：

- 发行口径见[发行规范](发行规范.md)：版本号、发行语言集、分组、tag 与门禁；
  `dist/` 只留 zip、`SHA256SUMS.txt` 与 `release.json`。
- 字体只做映射，实际字体与映射规则见[字体与分发](字体与分发.md)；语言包格式见
  [译文与语言包](译文与语言包.md)。
- 支持环境是 **Windows 10 / 11**，不支持 Windows 7；界面译文没有母语审校，
  披露与反馈入口在根 [README](../README.md)。

旧的 `launcher.ini`、`lang/aliases.ini` 已移除；旧语言包不再兼容。

在线画廊只发布 `screenshots.html` 与 `assets/screenshots/`：`.github/workflows/pages.yml` 把 HTML 复制成站点首页后上传，`docs/` 下的 Markdown 不进入站点，因此不会出现 `.md` 链接 404。地址是 `https://mrchenguozheng.github.io/Port-Royale-2-Localization/`；`docs/screenshots.html` 是本地源文件，Pages 上的根路径由工作流生成。图注、注记和手写段落都改 `docs/screenshots.json`，版式改 `src/tools/docs/screenshots_template.html`，然后运行 `python src/tools/docs/build_screenshots.py --thumbs`；`--check` 会同时核对 HTML、Markdown 与缩略图。
