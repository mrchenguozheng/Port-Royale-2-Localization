# 新语言协作流程

面向“只会翻译和校对、不写代码”的译者，以及负责构建/发行的维护者。
以韩语 `ko` 为例，其他语言同理。

> 当前只支持 GOG 英文版 `1.1.2.3`。新语言也必须在这个版本上验收。

## 分工

| 事情 | 译者 | 维护者 |
|---|---|---|
| 翻译、校对、术语、语气 | ✅ | 可参与 |
| 游戏内验收 | ✅ | ✅ |
| `src/live/<代码>.toml` | ✅ | 可代做 |
| `src/packs/<代码>.toml` | 不需要 | ✅ |
| `ui/<代码>.ini` | ✅ | 可代做 |
| 字体映射 / Noto KR | 不需要 | ✅ |
| 编译语言包 | 可选 | ✅ |
| 构建/发行 zip | ❌ | ✅ |
| 支持版本 / 兼容性 | ❌ | ✅ |

原则：**译者只对译文和界面文本负责，其余由维护者收口。**

## 译者：两种工作方式

### 方式 A：直接使用工作台

需要 Python 3.11+，但不需要 Visual Studio（注入器已有构建产物时）。

```bat
start.bat
```

打开「译文编辑」：

1. 在语言下拉里新增 `ko`，或用维护者建好的语言；
2. 逐条翻译并保存（写入 `src/live/ko.toml`）；
3. 没翻译的条目会自动显示英文，不必一次完成。

### 方式 B：文件交换

维护者提供：

```
src/live/ko.toml
ui/ko.ini
```

译者用任意 UTF-8 文本编辑器修改后返回。维护者负责校验、构建、打包和测试。

## 译者不能改的东西

- `hash =` 左边的 id；
- `%1`、`%2` 等占位符；
- `@D$...$` 这类脚本变量；
- `<n>`、`<c>`、`<f:...>` 等标签；
- `build/` 下的产物（会被重新生成覆盖）。

## 维护者：建立语言

### 1. 建译文骨架

```bat
python src\tools\pack\new_lang.py --new-lang ko --from en
```

生成：

```
src/live/ko.toml
src/tools/font/fontstitch/presets/ko.toml
```

`ko.toml` 从英文原文复制，未改的条目就是英文，方便逐条替换。

### 2. 加语言元数据

`src/packs/ko.toml`：

```toml
alias = "한국어"
gui = "ko"
min_runtime = 1
```

没有它，GUI 会显示代码 `ko`，界面语言回退英文。

### 3. 加启动器界面

复制 `ui/en.ini` 为 `ui/ko.ini`，交给译者翻译。
GUI 会根据 `gui = "ko"` 加载它。

### 4. 加韩文字体映射

在 `src/tools/font/make_noto_fonts.py` 的 `LANGS` 里加：

```python
"ko": {
    "sans": ("NotoSansKR", 400),
    "serif": ("NotoSerifKR", (700, 900)),
    "label": "Korean",
},
```

确认本机安装 Noto Sans KR / Noto Serif KR。

### 5. 构建语言包和字体

```bat
python src\tools\pack\compile_pack.py --lang ko
python src\tools\font\make_noto_fonts.py --lang ko --out <目录>
```

### 6. 生成发行包

```bat
python src\tools\pack\make_release.py --lang ko --version v1.1.0
```

新语言属于功能增加，通常用 `v1.1.0`。

## 验收

在 GOG 英文版干净副本里：

1. 解压 `PR2-ko-*.zip`；
2. 双击 `PR2LauncherGUI.exe`；
3. 选 `한국어`；
4. 检查：
   - 韩文是否显示；
   - 是否有缺字（尤其标题字体）；
   - 长文本/按钮是否截断；
   - 占位符、换行是否正常；
   - 切换语言、原版启动是否正常。

发现问题时，优先记录：

- 条目 hash；
- 界面位置；
- 截图；
- 是缺字、截断还是译文问题。

## 交付给译者前的检查

- 语言代码已确定（如 `ko`）；
- `ko.toml` 已生成，条数 3548；
- `ui/ko.ini` 存在；
- 字体方案已确定；
- 支持版本明确是 GOG 英文版。
