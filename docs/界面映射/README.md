# 界面映射（总览）

记录“哪句话出现在哪个界面”。这一主题按界面分卷存放，**不要再写回单个大文件**。

**键与界面位置和语言无关**：游戏按 key 取串，同一 key 在每个语言包里是不同的文本，
但“这一屏画的是哪几个 key”对所有语言都一样。所以各卷按“界面 → 键”记，
语言列只作对照；采集时用的是德语排查包，中文列直接取 `zh.toml`，
没有逐条实机核实过（中文界面要用 `zh-debug` 再走一遍）。

采集方法见 `docs/德语校对流程.md` 第 8 节。反查（看到 `[XXXX]` 想知道是哪条）用
`build/qa/de_index.csv` 按标记尾数 grep，或查 `build/debug/<lang>-debug/<lang>.txt`（带全标记的中间产物）。

## 本目录同时是排查包的“已查清清单”

重编 `<lang>-debug` 时，`debug_pack.py` 会扫描**本目录下全部 `.md`**（含本文件）：
凡是一行里既有 `[XXXX]`、又有 `0x…` 键，对应条目就不再带标记；整段声明按下面三种写法处理。

- 逐条：同一行既有 `[XXXX]` 又有 `0x` 键 —— 这一条已实机确认。
- 按类别整体清除：`` `0xfc51xxxx` ``（名表 131 条）、`` `0xcf57xxxx` ``（姓表 103 条），写在“姓名”那节。
- 整体保留：`` `0xfc512ea5` `` —— 名表段开头那条不是人名，是 Miles Sound System 的版权声明。

顺手记一条，下次重编那几行就恢复成正常文本；没记的继续带标记，不会误清。产物目录里的 `cleared.txt` 是每次实际清掉的键清单。
**推断行必须把标记列写成 `—`**（见 `09-推断-连续键区.md`），否则会被误当成已确认。

现状：3548 条里已清 885 条（其中一部分是按类别整体清除的），带标记 2663 条。

写新内容时按界面归卷：菜单/剧本 → 01，自由模式与姓名 → 02，设置页 → 03，顶栏与开场 → 04，
城镇与地图 → 05，船只 → 06，各种窗口面板 → 07，编年史/国家/统计 → 08，推断 → 09；
跨卷的界面在总览这里列一行指向两卷即可，不要为了“完整”把几卷合并。
