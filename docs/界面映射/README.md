# 界面映射（总览）

记录“哪句话出现在哪个界面”。这一主题按界面分卷存放，**不要再写回单个大文件**。

**键与界面位置和语言无关**：游戏按 key 取串，同一 key 在每个语言包里是不同的文本，
但“这一屏画的是哪几个 key”对所有语言都一样。所以各卷按“界面 → 键”记，
语言列只作对照；采集时用的是德语排查包，中文列直接取 `zh.toml`，
没有逐条实机核实过（中文界面要用 `zh-debug` 再走一遍）。

采集方法见 `docs/archive/德语校对流程.md` 第 8 节。反查（看到 `[XXXX]` 想知道是哪条）用
`build/qa/de_index.csv` 按标记尾数 grep，或查 `build/debug/<lang>-debug/<lang>.txt`（带全标记的中间产物）。

## 排查包的“已查清清单”

`debug_pack.py` 默认只读
[`src/data/ui_mapping/cleared.txt`](../../src/data/ui_mapping/cleared.txt)，
不再扫描本目录的 Markdown。数据文件支持三种写法：

- 逐条：`0x… = [XXXX]` —— 这一条已确认。
- 按类别整体清除：`整体清除：0xfc51xxxx`（名表 131 条）、`整体清除：0xcf57xxxx`（姓表 103 条）。
- 整段保留：`整体保留：0x…` —— 落在整段清除范围内、但确实不该算确认的例外；当前为空。

新增确认改数据文件；本目录各卷只写“哪句话在哪个界面”和证据，不作为运行输入。
推断行仍必须把标记列写成 `—`，不要写成 `[XXXX]`。

现状：基准表 3548 条全部落键；并集排查包 3590 条（多出的 42 条是 GOG 法语版差异），
带标记 0 条（以 `debug_pack.py --lang zh` 的产物为准）。
数据文件从本目录旧卷一次性抽取，迁移日期 2026-11-24；逐键数 3323，另有两个类别前缀。

写新内容时按界面归卷：菜单/剧本 → 01，自由模式与姓名 → 02，设置页 → 03，顶栏与开场 → 04，

## 自查坑：键比较的写法（2026-11-16）

判断某条键是否已在册，必须用 `("0x" + k[2:].upper())`——前缀小写、尾数大写，
与 `load_cleared()` 入库的格式一致。写成 `k.upper()`（前缀也被抬成 `0X`）会与入库键永不相等，
结果是**已清的键一律显示为「带标记」**。本日一次探查就因此把六条早已在册的键当成待清，
直到对照计数没变化才发现。凡要确认「还剩哪些」，跑一遍 `debug_pack.py --lang zh` 看总数，
不要只看逐键查询。
