# 界面映射 · 纯图形键与照抄条（不需要实机的那一类）

这一卷收的不是「哪个界面用哪条键」，而是**不需要上屏也能判定**的几类：没有字的图形／控制键、
资源名与内部 ID、专名、功能键名、纯符号。它们的共同点是内容里没有可译的文字——
译文只能是原样照抄，所以不存在「译错」，上屏也只会告诉我们图标画在哪，对译名没有帮助。

判据只有一条：**把值里的 `<…>` 标签剥掉、再去掉专名与占位符，还剩不剩需要翻译的词**。
剩不下 → 本卷判为已查清，直接清掉标记；剩得下的（格式串、英文头衔、键名缩写）留在卷末，继续带标记。

清标记的动作就是「在下面表里写出标记」：本目录是排查包的已查清清单，重编即生效。
