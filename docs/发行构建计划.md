# 发行包自动构建计划

目标：把现有四种语言（zh / ja / es / ru）做成可重复、一键出包的分层产物，明确哪些
文件必须绑在一起、哪些能单独下载，以及要不要提供全量包。

## 现状

- `src\tools\pack\make_release.py` 一次只做一个语言一个入口：
  `--lang <语言> --edition gog|steam --fonts noto|config|none --out dist`，
  产出 `dist\PR2-<lang>-<edition>-<version>\` 与同名 zip，包内已有
  `manifest.json`（逐文件 SHA-256 + 目标版本）并由 `release_manifest.verify_*` 校验。
- `dist\` 里目前只有中文两个包：`PR2-zh-gog-v1.0.0.zip`（22.7 MB）、
  `PR2-zh-steam-v1.0.0.zip`（22.8 MB）。日/西/俄从未出过包。
- 缺口：没有多语言聚合、没有「只含运行时」的核心包、没有字体与文案分离、
  没有跨语言的统一入口脚本，也没有 CI 门禁。

## 体积实测（决定分层的依据）

| 组成 | 内容 | 原始大小 | 备注 |
| --- | --- | --- | --- |
| 运行时 | `PR2Localization.exe`、`PR2LocalizationCore.dll`、`PR2LocalizationGUI.exe`、`RUNTIME-VERSION` | ≈ 0.48 MB | 与语言无关，四种语言共用 |
| 语言包 | `packs\<lang>.txt` | 每种 ≈ 0.32 MB | 3548 条，纯文本 |
| 界面语言 | `ui\<lang>.ini` | 每种 < 0.01 MB | 启动器界面 |
| 字体（zh） | NotoSansSC-Regular + NotoSerifSC-Black + NotoSerifSC-Bold | 38.4 MB | 官方静态 TTF，未改造 |
| 字体（ja） | NotoSansJP-Regular + NotoSerifJP-Black + NotoSerifJP-Bold | 21.2 MB（5.47 + 7.70 + 7.70） | Sans 来自用户提供的静态包；Serif 由本机 `C:\WINDOWS\Fonts\NotoSerifJP-VF.ttf` 实例化（wght 700/900），见下方风险 |
| 字体（ru） | `PR2Cyr*` 四个 | 1.7 MB | 自建，体积小 |
| 字体（es） | 无 | 0 | 直接用根目录原版拉丁字体 |

结论：**体积几乎全部来自字体**（zh 38.4 MB，ja 21.2 MB，ru 1.7 MB），文案和运行时加起来
不到 2 MB。分层必须围绕字体做，否则任何人都要为不用的语言付 20–40 MB。

## 产物设计（三档 + 全量）

| 产物 | 命名 | 内容 | 用途 |
| --- | --- | --- | --- |
| 核心包 | `PR2-core-<edition>-v<ver>.zip` | 运行时 + 四种语言包 + `ui\` + `font-map.default.ini`（四节齐全）+ README/OFL + manifest | 已在用中文/俄语的用户只更新运行时和文案；西语用户直接可用（es 不需要字体） |
| 字体包 | `PR2-fonts-<lang>-<edition>-v<ver>.zip` | 只含 `PR2Localization\fonts\` 下该语言的实际字体 + `font-map.default.ini` + OFL + 简短说明 | 单独下载，体积极小（ru 1.7 MB）；zh/ja 是大头 |
| 语言包 | `PR2-lang-<lang>-v<ver>.zip` | 只含 `packs\<lang>.txt` + `ui\<lang>.ini` | 换语言或改译文时几十 KB 级更新，不必重下字体 |
| 全量包 | `PR2-all-<edition>-v<ver>.zip` | 核心包 + 四种语言包 + zh/ja/ru 全部字体 | 懒人版；解压后改 `locale.ini` 即可切语言，不用再下字体 |

现有「单语言全包」（`PR2-<lang>-<edition>-v<ver>`）保留，等于「核心包 + 该语言字体」，
但不是默认：它让同一份运行时和四种文案重复出现在每个包里。

全量包要不要提供：**要**，理由是多语言字体文件名互不冲突（`NotoSansSC*` /
`NotoSansJP*` / `PR2Cyr*`），`font-map.default.ini` 已有 `[zh] [ja] [es] [ru]` 四节，
解压后只改 `locale.ini` 就能换语言，确实能做到「下一次、随便切」。代价是 zh+ja
两个 CJK 字体一起放进来，zip 会到 45 MB 上下。所以全量包定位成可选项，默认仍按语言分发。

## 必须绑在一起 / 可以独立下载

必须同包（缺一不可，拆开就会坏）：

- 运行时三件（exe / Core.dll / GUI.exe）与 `RUNTIME-VERSION`：DLL 与 exe 有版本对应关系，不能各自升级；
- `font-map.default.ini` 与实际字体：映射里写的是文件名，缺文件启动器会报「字体缺失」；
- `packs\locale.default.ini` 与至少一种 `packs\<lang>.txt`：默认语言指向不存在的包会回落英文；
- `manifest.json`：跟着它描述的那个包走，不单独分发；
- `OFL.txt`：只要包里有字体就必须带（OFL 1.1 要求随附许可文本）。

可以独立下载：

- 各语言 `packs\<lang>.txt` 与 `ui\<lang>.ini`：纯文本，单独替换不影响字体和运行时；
- 各语言字体包：`PR2Localization\fonts\` 下文件名唯一，可增量安装；
- `NOTO-SOURCES.txt`（来源说明）：属于文档，可单列，但正式包建议照旧带上。

## 各语言的特殊处理

- `es`：字体全部 `none`，包体只有运行时 + 0.32 MB 文案。核心包天然包含它，所以
  **西语不需要单独的字体包**，这一点要在产物矩阵里显式标注，避免误生成空包。
- `ru`：四个 `PR2Cyr*` 与四个逻辑名一对一，字体包只有 1.7 MB；`font-map` 的 `[ru]`
  节带注释说明 0.88 有意偏差。
- `zh`：三份 Noto SC 未改造，38.4 MB，是 zip 体积的主要来源。
- `ja`：与 zh 同构，但本机缺 Noto Sans/Serif JP 静态文件；构建脚本必须在缺失时
  明确报错并指出放哪个目录（`make_noto_fonts.find_font` 的搜索路径），不能静默产出
  「没有字体的日文包」。

## 构建流水线

新增入口 `src\tools\pack\build_all.py`，一次跑完，供人和 CI 共用：

```text
python src\tools\pack\build_all.py --targets core,langs,fonts,full,per-lang \
       --editions gog,steam --out dist
```

步骤：

1. **前置检查**
   - `python src\tools\config_check.py`
   - `python -m unittest discover -s tests -q`
   - 确认 `build\runtime\PR2Localization\` 下 exe / Core.dll / GUI.exe 已构建（缺则提示先构建 Rust 注入器）。
2. **编译语言包**：对 `zh ja es ru` 依次 `compile_pack --lang <lang> --strict --no-fonts`，
   断言条目数 3548、占位未翻译 0、警告 0。
3. **构建字体**：`build_artifacts.build_fonts(langs, cache=True)`；ru 走 `build_cyr_fonts`，
   zh/ja 走 `make_noto_fonts`。构建后对每种语言做缺字检查（用字表 × 映射后的四个字体，
   缺字必须为 0；es 检查原版字体，允许 `²³€` 这三个符号测试字符缺失，因为英文原版同样缺）。
4. **装配**：按上面的产物矩阵复制文件到 `dist\PR2-<target>-...\`，目标之间共用同一份
   `build\runtime` 与 `font-map.default.ini` 源，不各自重新生成。
5. **写清单**：`release_manifest.write_release_manifest` 生成 `manifest.json`，随后
   `verify_release_manifest` 校验；全量包需要扩展该模块，让它接受「多语言 + 多字体」的
   语言字段（当前签名是单语言）。
6. **打包**：`zipfile.ZIP_DEFLATED, compresslevel=9`，命名见上表；全量包建议对 ttf 用
   `ZIP_STORED`（字体本身已压缩，重压只浪费时间）。
7. **产出索引**：写 `dist\INDEX.json`，列出每个产物的语言、入口、版本、字节数、SHA-256，
   供发布页直接读取。

## 门禁（缺一条即失败）

- `manifest.json` 校验通过，且包内每个文件都能在清单里找到（含 exe 目标版本与 SHA）；
- 包内 `font-map.default.ini` 的四个逻辑名，在该包所带字体范围内全部可解析；`none` 合法；
- 语言包的条目数 = 基准 3548；
- 有字体的包必须带 `OFL.txt`；CONTENT 里出现 Liberation Sans / Noto 衍生字体时，
  README 的字体段与许可段要写对来源（当前按语言分支已经这样做）；
- `PR2Localization\fonts\` 里不允许出现非字体文件（游戏会扫描该目录）；
- 不允许出现 `.ttc` 与 `-VF.ttf`（运行时会拒）。

## 版本与命名

- 版本号单一来源：`RUNTIME-VERSION`；`build_all.py` 从它读版本，所有产物同版本号。
- 目录/zip 名固定为 `PR2-<target>-<edition>-v<ver>`，其中 `<target>` ∈
  `core` / `fonts-zh` / `fonts-ja` / `fonts-ru` / `lang-zh` / `lang-ja` / `lang-es` /
  `lang-ru` / `all` / 单语言包名（`zh`/`ja`/`es`/`ru`）。
- 入口只区分 `gog` / `steam`：Steam 包带 `PR2HostMount.ps1` 与宿主 DLL，GOG 包刻意不带
  `VERSION.dll`。

## 风险与边界

- **多语言共存的前提**是文件名唯一。以后若某种语言也改用 `PR2CyrBody` 这类通用名，
  全量包会互相覆盖；新增语言时必须检查 `fonts\` 内文件名不重名。
- **README 里「同一次安装只放一个语言」要改**：全量包里多个语言共存是正常状态，
  切换方式是改 `locale.ini`；单语言包仍保持原说明。
- **ja 实际构建结果**：Sans Regular 5.47 MB + Serif Black 7.70 MB + Serif Bold 7.70 MB = 21.2 MB。
  日文用字 1606 个，Sans 缺 0；Serif 缺 1 个 `岸`——源文件
  `C:\WINDOWS\Fonts\NotoSerifJP-VF.ttf`（Version 2.02;241114204555;**non-release**）本身就没有这个字，
  与我们的流程无关。`岸` 目前只出现在正文（对话、百科）里，走 Sans，不进标题，所以现状无可见影响；
  正式发布前应换成官方 release 版 Noto Serif JP 静态文件。
- **本机缺 Noto JP 源**：已解决一半——Sans 静态文件在 `build\cache\noto-src\`；Serif 仍依赖系统里的
  non-release VF。构建机必须提供 Serif 的静态文件（`NotoSerifJP-Bold.ttf` / `-Black.ttf`），
  否则产物只能靠实例化，且可能带缺字。
- **不做的**：自动上传、自动 push、代码签名、增量差分更新；这些都超出「本地一键出包」的范围。

## 实施顺序

1. `build_all.py` 骨架 + 产物矩阵 + 单语言包改为「核心 + 该语言字体」的装配函数；
2. 核心包与语言包（体积小，先跑通）；
3. 字体包（zh / ru 先跑，ja 等源文件到位）；
4. 全量包 + `INDEX.json` + `release_manifest` 多语言支持；
5. 把 1–4 接进测试与文档（`docs\字体与分发.md`、`docs\新语言.md`）。
