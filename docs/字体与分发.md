# 字体与分发限制

## 结论

**字体只做映射，不做缝合。**

游戏请求四个固定逻辑名，磁盘上放什么字体由 `font-map` 决定；发行版直接把完整的
Noto 字体（或俄语自建字体）以原始文件名放进 `PR2Localization\fonts\`，再附一份
`font-map.default.ini`，可以随包分发（见 [`发行版.md`](发行版.md)）。

早期为了“保留原版字形”做过“原版拉丁字体 + 商业/系统 donor 缝合”的路径。
这套实现（原 `subset_fonts.py` / `fontstitch/` / `presets/`）已从仓库移除：
缝合产物是衍生作品，许可上只能自用，也没有继续维护的价值。现在没有
`--fonts stitch`、没有 fonts presets，构建链只剩 Noto（含俄语特例）与不打包字体两种。

`build/runtime/PR2Localization/fonts/<语言>/` 是构建暂存目录：按语言分别生成，
部署/打包时平铺到 `PR2Localization\fonts\` 这一层，不按语言单开子目录。

- 中文、日文、韩文：Noto Sans / Noto Serif 静态字重（SIL OFL 1.1）；
- 俄语：四个自建文件（`src\tools\font\build_cyr_fonts.py` 生成，均平铺在
  `PR2Localization\fonts\`，与游戏请求的四个逻辑名一一对应）：
  - 正文 `ARIAL.TTF` → `PR2CyrBody-Regular.ttf`：Noto Sans 轮廓按原版 ARIAL 的度量
    缩放（目标取俄语用字上的实测值：平均 advance 0.578、cap 0.716、纵向 0.905 / -0.212），
    与 Arial 只差 2% 字宽，自带西里尔，OFL 可分发；不依赖系统里另外装一款西里尔字体；
  - `Tiepolo_black.ttf` → `PR2CyrDisplay-Black.ttf`、
    `Tiepolo_bold.ttf` → `PR2CyrDisplay-Bold.ttf`：Noto Serif 轮廓按原版度量缩放
    （纵向 sy=0.86 对齐 cap height 0.614，横向压到原版平均 advance 0.517 / 0.496
    **再乘 0.88**），纵向度量写回 Tiepolo 的 hhea/typo 0.791/-0.292、win 0.869/0.856
    与 0.295；
  - `ELGRECO_.TTF` → `PR2CyrDisplay-Head.ttf`：ELGRECO 是窄而高的花体
    （avg 0.343 / cap 0.724），单独一份，sy=1.014、sx≈0.516，纵向度量 0.833/-0.250、
    win 0.928/0.308。

  0.88 是有意的偏差：俄语 UI 串比英文长，按原版宽度实机验证过会撑出木板挂牌。
  去掉 hinting，族名改为 `PR2 Cyrillic Display *`。

## 已经做的限制

- `.gitignore` 忽略 `assets/fonts/original/` 和 `build/runtime/fonts/`；
- 部署脚本只复制 `.ttf` 到游戏目录的 `PR2Localization\fonts\`，不按语言单开子目录，也不会把说明文件带进字体目录；
- 仓库不提交任何字体文件，只提交字体生成脚本与映射模板。

## 原版字体的用途

`extract_fonts.py` 仍保留：它把游戏内置 TTF 从 `pr2_loca.cpr` 导出到
`assets/fonts/original/`（不入库），用于**测量原版字体度量**——判断译文会不会
被木板挂牌裁切、断行是否合理（见 [`新语言.md`](新语言.md) §4.5）。它不再喂任何缝合管线。

```bash
python src/tools/font/extract_fonts.py --game-dir "<游戏目录>" --out assets/fonts/original
```

## 配置文件名映射（不强迫改字体名）

游戏请求的是四个固定逻辑名，但磁盘上的字体可以保留自己的文件名。
发行包在 `PR2Localization\fonts\font-map.default.ini` 提供默认映射；用户要自定义时，
新建或编辑同目录的 `font-map.ini`，**只写需要覆盖的逻辑名**。运行时以默认文件为基础，
再按项叠加用户文件；这样解压覆盖发行包时只替换 `font-map.default.ini`，不会覆盖
已经手工修改的 `font-map.ini`。

```ini
[zh]
ARIAL.TTF=NotoSansSC-Regular.ttf
ELGRECO_.TTF=NotoSerifSC-Black.ttf
Tiepolo_black.ttf=NotoSerifSC-Black.ttf
Tiepolo_bold.ttf=NotoSerifSC-Bold.ttf
```

映射值只写文件名，文件必须位于 `PR2Localization\fonts\`；不会读取系统字体目录，
也不接受该目录之外的路径、`.ttc` 集合或 `-VF.ttf` 可变字体。两个逻辑名可以指向
同一个文件；`[fonts]` 是全局默认，`[zh]` / `[ja]` 覆盖它。运行时按
“用户项 → 默认项 → 原版根目录”回退；用户只覆盖部分逻辑名时，其余项仍用默认值。
要显式禁用某一项，写 `ARIAL.TTF=none` 或 `ARIAL.TTF=-`。映射缺失或文件不存在时
不会把缺字体当成成功。

`font-map.default.ini` 的模板在 `src/font-map.ini`。默认 `--fonts noto` 会把
`NotoSansSC-Regular.ttf`、`NotoSerifSC-Black.ttf`、`NotoSerifSC-Bold.ttf`
（日文对应 JP、韩文对应 KR）平铺到 `PR2Localization\fonts\`，再附带默认映射文件。
`--fonts config` 只带默认映射文件，不含字体；使用这种包时必须自己把映射里写明的
实际字体文件放进 `PR2Localization\fonts\`，否则 GUI 会提示字体缺失。

## 相关文件

- `src/tools/font/make_noto_fonts.py`：下载并落盘 Noto 静态字重（映射的实际文件来源）；
- `src/tools/font/build_cyr_fonts.py`：俄语四个自建字体；
- `src/tools/font/extract_fonts.py`：导出原版字体（仅用于度量测量）；
- `src/tools/font/squeeze_fonts.py`：按原版度量压缩字形的辅助脚本；
- `docs/构建与安装.md`：构建流程里的字体说明。
