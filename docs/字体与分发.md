# 字体与分发限制

## 结论

**缝合出来的字体只允许本机自用，不要分发。**

`build/fonts/*.ttf` 是用 fontstitch 生成的衍生作品：

- base 是游戏原版拉丁字体（Ascaron / Port Royale 2）；
- donor 是系统或商业字体：微软雅黑、华文中宋、思源宋体、钟齐志莽、
  Noto Sans JP 等；
- **哪个语言参与缝合由 `presets.toml` 决定**：这个文件不进仓库，由 `presets.example.toml` 复制而来；目前只配置了 `[zh]`，
  所以只缝中文；`ja` 等没有配置的语言不会被缝进字体。

这些字体本身的许可通常**不允许修改后再分发**；把缝合结果上传、打包、
放进发布物或提交进仓库，都可能违反许可。

## 已经做的限制

- `.gitignore` 忽略 `assets/fonts/original/` 和 `build/fonts/`；
- `subset_fonts.py` 在输出目录生成 `不要分发.txt`；
- 部署脚本只复制四个 `.ttf` 到游戏目录，不会把说明文件带进游戏；
- 仓库里只提交缝合代码与 presets，不提交任何字体文件。

## 别人要用怎么办

让对方在自己的机器上准备：

1. 从自己的游戏里导出原版字体：
   ```bash
   python src/tools/font/extract_fonts.py --game-dir "<游戏目录>" --out assets/fonts/original
   ```
2. 把 `src/tools/font/fontstitch/presets.example.toml` 复制成 `presets.toml`，安装/准备自己的 donor（或改 donor_file）；
3. 检查前置条件并生成：

```bash
python src/tools/font/subset_fonts.py --check
python src/tools/font/subset_fonts.py
```

做别的语言时还需要加 `[<语言>]` presets 段，完整清单见
[`新语言字体配置.md`](新语言字体配置.md)。

## 相关文件

- `src/tools/font/subset_fonts.py`：缝合入口；
- `src/tools/font/fontstitch/`：缝合引擎与 donor 预设；
- `docs/构建与安装.md`：构建流程里的字体说明。
