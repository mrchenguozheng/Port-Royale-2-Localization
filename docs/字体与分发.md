# 字体与分发限制

## 结论

**缝合出来的字体只允许本机自用，不要分发。**

发行版默认**不缝合**：直接用完整的 Noto 字体替换游戏四个字体，可以随包分发
（见 [`发行版.md`](发行版.md)）。下面说的是可选的缝合路径。

`build/runtime/PR2Localization/fonts/<语言>/*.ttf` 是用 fontstitch 生成的衍生作品：

- base 是游戏原版拉丁字体（Ascaron / Port Royale 2）；
- donor 是系统或商业字体：微软雅黑、华文中宋、思源宋体、钟齐志莽、
  Noto Serif JP 等；
- **每个语言一份 `presets/<语言>.toml`**：该目录不进仓库，由
  `presets.example.toml` 复制而来；目前有 `zh` 和 `ja`，各自独立。

这些字体本身的许可通常**不允许修改后再分发**；把缝合结果上传、打包、
放进发布物或提交进仓库，都可能违反许可。

## 已经做的限制

- `.gitignore` 忽略 `assets/fonts/original/` 和 `build/runtime/fonts/`；
- `subset_fonts.py` 在输出目录生成 `不要分发.txt`；
- 部署脚本只复制四个 `.ttf` 到游戏目录的 `PR2Localization\fonts\<语言>\`，不会把说明文件带进字体目录；
- 仓库里只提交缝合代码与 presets，不提交任何字体文件。

## 别人要用怎么办

让对方在自己的机器上准备：

1. 从自己的游戏里导出原版字体：
   ```bash
   python src/tools/font/extract_fonts.py --game-dir "<游戏目录>" --out assets/fonts/original
   ```
2. 为每个语言准备 `src/tools/font/fontstitch/presets/<语言>.toml`
   （可从 `presets.example.toml` 复制），安装/准备自己的 donor；
3. 检查前置条件并生成：

```bash
python src/tools/font/subset_fonts.py --check
python src/tools/font/subset_fonts.py --all
```

每个语言输出到 `build/runtime/PR2Localization/fonts/<语言>/`，部署时复制到游戏目录的
`fonts/<语言>/`，不覆盖根目录原版。
完整清单见 [`新语言字体配置.md`](新语言字体配置.md)。

## 配置文件映射（不打包字体）

可以完全不分发字体文件，改用 `PR2Localization\fonts\font-map.ini` 把游戏的四个
逻辑字体名映射到玩家系统里的字体：

```ini
[zh]
ARIAL.TTF=%WINDIR%\Fonts\NotoSansSC-Regular.ttf|%WINDIR%\Fonts\NotoSansSC-VF.ttf
ELGRECO_.TTF=%WINDIR%\Fonts\NotoSerifSC-Black.ttf|%WINDIR%\Fonts\NotoSerifSC-VF.ttf
Tiepolo_black.ttf=%WINDIR%\Fonts\NotoSerifSC-Black.ttf|%WINDIR%\Fonts\NotoSerifSC-VF.ttf
Tiepolo_bold.ttf=%WINDIR%\Fonts\NotoSerifSC-Bold.ttf|%WINDIR%\Fonts\NotoSerifSC-VF.ttf
```

非拉丁系默认使用 Noto 对应字体：简体中文用 Noto Sans/Serif SC，日文用
Noto Sans/Serif JP；优先静态字重文件，没有静态文件时才退回 `-VF.ttf`。
不使用 `.ttc` 集合；解析器会跳过 `.ttc` 候选。

`[fonts]` 是全局默认，`[zh]` / `[ja]` 覆盖它；值支持绝对路径、相对游戏根目录、
`%WINDIR%` 和 `|` 候选。运行时按“配置 → 内置字体 → 原版根目录”回退。

这样不需要复制、改名或重新打包字体。代价是系统字体不保证存在，尤其是精简
Windows 或没有中日语言包的机器；发行包应同时说明如何修改映射，不能把缺字体
当成成功。`font-map.ini` 的模板在 `src/font-map.ini`，发行时用
`--fonts config`（或 `release.ps1 -Fonts config`）生成不含 TTF 的包。
