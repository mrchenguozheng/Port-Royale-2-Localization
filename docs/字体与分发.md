# 字体与分发限制

## 结论

**字体只做映射，不做缝合。**

游戏请求四个固定逻辑名，磁盘上放什么字体由 `font-map` 决定；发行版直接把完整的
Noto 字体（或俄语自建字体）以原始文件名放进 `PR2Localization\fonts\`，再附一份
`font-map.default.ini`，可以随包分发（见 [`发行版.md`](发行版.md)）。

早期为了“保留原版字形”做过“原版拉丁字体 + 商业/系统 donor 缝合”的路径。
这套实现（原 `subset_fonts.py` / `fontstitch/` / `presets/`）已从仓库移除：
缝合产物是衍生作品，许可上只能自用，也没有继续维护的价值。现在没有
`--fonts stitch`、没有 fonts presets，构建链只剩 Noto（含俄语特例）与不打包字体两种。

`build/runtime/PR2Localization/fonts/<语言>/` 是构建暂存目录：按语言分别生成，
部署/打包时平铺到 `PR2Localization\fonts\` 这一层，不按语言单开子目录。

- 中文、韩文：Noto Sans / Noto Serif 静态字重（SIL OFL 1.1），不压字形；
- 日文：Noto Sans JP / Noto Serif JP 静态字重（SIL OFL 1.1）；发行打包时只压标题：
  - 正文 `NotoSansJP-Regular.ttf` 原样复制，不做横向压缩；
  - 标题 `NotoSerifJP-Black.ttf`、`NotoSerifJP-Bold.ttf` 用
    `src\tools\font\squeeze_fonts.py` 横向压到 0.78。标题栏字框比正文更窄，
    0.9 会把「知られている海賊」首尾字切掉；
  文件名、内部名和垂直度量都不动，`font-map` 不需要改。
- 俄语：四个自建文件（`src\tools\font\build_cyr_fonts.py` 生成，均平铺在
  `PR2Localization\fonts\`，与游戏请求的四个逻辑名一一对应）：
  - 正文 `ARIAL.TTF` → `PR2CyrBody-Regular.ttf`：Noto Sans 轮廓按原版 ARIAL 的度量
    缩放（目标取俄语用字上的实测值：平均 advance 0.578、cap 0.716、纵向 0.905 / -0.212），
    与 Arial 只差 2% 字宽，自带西里尔，OFL 可分发；不依赖系统里另外装一款西里尔字体；
  - `Tiepolo_black.ttf` → `PR2CyrDisplay-Black.ttf`、
    `Tiepolo_bold.ttf` → `PR2CyrDisplay-Bold.ttf`：Noto Serif 轮廓按原版度量缩放
    （纵向 sy=0.86 对齐 cap height 0.614，横向压到原版平均 advance 0.517 / 0.496
    **再乘 0.88**），纵向度量写回 Tiepolo 的 hhea/typo 0.791/-0.292、win 0.869/0.856
    与 0.295；
  - `ELGRECO_.TTF` → `PR2CyrDisplay-Head.ttf`：ELGRECO 是窄而高的花体
    （avg 0.343 / cap 0.724），单独一份，sy=1.014、sx≈0.516，纵向度量 0.833/-0.250、
    win 0.928/0.308。

  0.88 是有意的偏差：俄语 UI 串比英文长，按原版宽度实机验证过会撑出木板挂牌。
  去掉 hinting，族名改为 `PR2 Cyrillic Display *`。
- 波兰语：正文**不换**，只换三个标题槽位（`src\tools\font\build_lat_fonts.py` 生成）：
  - 实测原版 cmap：`ARIAL.TTF` 有 1186 个码位，波兰语 18 个字母全覆盖，
    所以 `ARIAL.TTF=none` 回落根目录原版字体；
  - `ELGRECO_.TTF` / `Tiepolo_black.ttf` / `Tiepolo_bold.ttf` 各只收 223 个字形，
    缺 ą ć ę ł ń ś ź ż 与大写 16 个（`ó` 在 Latin-1 里，反而有），
    三个槽位分别指向 `PR2PlDisplay-Head/Black/Bold.ttf`；
  - 缩放取原版同槽位的度量（Head avg 0.343 / cap 0.724、Black 0.517 / 0.614、
    Bold 0.496 / 0.614，纵向度量照抄俄语那三份的原版值），
    **不压 SLOT_SQUEEZE**：波兰语串长与英德同量级，不需要为宽度牺牲字形比例。

## 已经做的限制

- `.gitignore` 忽略 `assets/fonts/original/` 和 `build/runtime/fonts/`；
- 部署脚本只复制 `.ttf` 到游戏目录的 `PR2Localization\fonts\`，不按语言单开子目录；字体目录只放 TTF 与映射，游戏会按 `fonts\*.*` 枚举，许可文本 `OFL.txt` 和来源说明 `NOTO-SOURCES.txt` 都放 `PR2Localization\docs\`；
- 仓库不提交任何字体文件，只提交字体生成脚本与映射模板。

## 原版字体的用途

`extract_fonts.py` 仍保留：它把游戏内置 TTF 从 `pr2_loca.cpr` 导出到
`assets/fonts/original/`（不入库），用于**测量原版字体度量**——判断译文会不会
被木板挂牌裁切、断行是否合理（见 [`新语言.md`](新语言.md) §4.5）。它不再喂任何缝合管线。

```bash
python src/tools/font/extract_fonts.py --game-dir "<游戏目录>" --out assets/fonts/original
```

## 配置文件名映射（不强迫改字体名）

游戏请求的是四个固定逻辑名，但磁盘上的字体可以保留自己的文件名。
发行包在 `PR2Localization\fonts\font-map.default.ini` 提供默认映射；用户要自定义时，
新建或编辑同目录的 `font-map.ini`，**只写需要覆盖的逻辑名**。运行时以默认文件为基础，
再按项叠加用户文件；这样解压覆盖发行包时只替换 `font-map.default.ini`，不会覆盖
已经手工修改的 `font-map.ini`。

```ini
[zh]
ARIAL.TTF=NotoSansSC-Regular.ttf
ELGRECO_.TTF=NotoSerifSC-Black.ttf
Tiepolo_black.ttf=NotoSerifSC-Black.ttf
Tiepolo_bold.ttf=NotoSerifSC-Bold.ttf
```

映射值只写文件名，文件必须位于 `PR2Localization\fonts\`；不会读取系统字体目录，
也不接受该目录之外的路径、`.ttc` 集合或 `-VF.ttf` 可变字体。两个逻辑名可以指向
同一个文件；`[fonts]` 是全局默认，`[zh]` / `[ja]` 覆盖它。运行时按
“用户项 → 默认项 → 原版根目录”回退；用户只覆盖部分逻辑名时，其余项仍用默认值。
要显式禁用某一项，写 `ARIAL.TTF=none` 或 `ARIAL.TTF=-`。映射缺失或文件不存在时
不会把缺字体当成成功。

`font-map.default.ini` 的模板在 `src/font-map.ini`。默认 `--fonts noto` 会把
`NotoSansSC-Regular.ttf`、`NotoSerifSC-Black.ttf`、`NotoSerifSC-Bold.ttf`
（日文对应 JP、韩文对应 KR）平铺到 `PR2Localization\fonts\`，再附带默认映射文件，
许可文本与来源说明放在 `PR2Localization\docs\`。
`--fonts config` 只带默认映射文件，不含字体、也不带 `OFL.txt`；使用这种包时必须自己把映射里写明的
实际字体文件放进 `PR2Localization\fonts\`，否则 GUI 会提示字体缺失。

## 字体源与兜底（构建侧）

构建需要的 Noto 源字体不入库：`src/fonts-sources.toml` 只记「文件名 → 下载地址 →
需要的字重 → 最小体积」，实际文件按下面的顺序找（`src/tools/font/font_sources.py`）：

1. `PR2_FONT_DIRS`（环境变量，设置后只查它，分号分隔）；
2. `assets\fonts\noto\`：入库兜底目录，允许手工放静态文件，默认空；
3. `build\cache\noto-src\`：下载缓存，不入库，CI 用 `actions/cache` 持久；
4. `%WINDIR%\Fonts`；
5. `%LOCALAPPDATA%\Microsoft\Windows\Fonts`。

前两处都是「项目内」，所以 GitHub runner 上没有装 Noto 时会自动落到项目内；
顺序又把项目内排在系统前面，本机与 CI 用同一份文件，同 commit 重建能逐字节一致。

缺文件时：

```
python src\tools\font\fetch_noto_fonts.py --langs zh,ja            # 只核对，缺则 exit 1
python src\tools\font\fetch_noto_fonts.py --langs zh,ja --fetch    # 缺什么下载什么
```

`--fetch` 从清单里的固定地址下载可变字体，按 `axis.wght` 实例化成静态文件
（`NotoSansSC-Regular.ttf` 这类静态名，正是 `font-map.ini` 映射的名字），落盘前
验体积与字体魔数。大文件（17–24MB 的 CJK 变量字体）在弱网下会断流，所以下载
带 `Range` 续传与 5 次重试，并只在原始文件旁留 `.ok` 标记后才允许复用；
同一 URL 的多个字重只下一次原件。

判定已经收紧：`compile_pack.py` 里字体生成失败会让整包构建返回 1（以前是打一行
「字体检查跳过」继续出包）；只有显式 `--no-fonts` 才跳过字体。CI 在 setup-python
之后、`Python deps` 与一切重活之前跑一次 `--fetch --no-system`，字体缺失会在
20 秒内失败，而不是等两分钟到 build 阶段。

## 字体共用与合包

同一个发行 zip 里的语言共用一处 `PR2Localization\fonts\` 与一份
`font-map.default.ini`，所以「字体能不能共用」直接决定哪些语言能进一个包
（`src/release-bundles.toml`）：

- `de` / `es` / `fr` / `it`：四项映射全 `none`，包里没有字体文件，四门共用同一份
  空字体集 → 合成 `latin` 一包（0.85 MB，原来是四份各 0.5 MB 左右）；
- `zh` / `ja` / `ko` / `ru`：各带一套文件名不同的字体（`NotoSerifSC-*` /
  `NotoSerifJP-*` / `NotoSerifKR-*` / `PR2CyrDisplay-*`），合成一包不会省体积，
  还会让字体目录里同时躺几套 20MB 级文件，所以各出一包。
- `pl`：`ARIAL.TTF` 不换（原版 1186 码位覆盖波兰语 18 个字母），三个标题槽位换成
  `PR2PlDisplay-Head/Black/Bold`（原版标题字体只有 223 个字形，缺 `ą ć ę ł ń ś ź ż`）
  → 整门判为 `noto`，带三个约 1 MB 级的文件，单出 `pl` 一包。

出包时会核对：组内语言字体模式必须一致（混着就拒绝）；组内同名 TTF 若内容不同
（SHA-256 不等）直接失败，不允许后写的一份盖掉前一份。运行时没有变化——
语言包仍是 `packs/<lang>.txt`，启动器扫目录列出组内语言供切换。

## 相关文件

- `src/fonts-sources.toml`：Noto 源字体清单（地址 / 字重 / 最小体积）；
- `src/release-bundles.toml`：发行分组（同一份字体能共用的语言进一个 zip）；
- `src/tools/font/font_sources.py`：统一的字体目录解析与缺失报错；
- `src/tools/font/fetch_noto_fonts.py`：按清单核对 / 下载 / 实例化；
- `assets/fonts/noto/README.md`：入库兜底目录的用法；
- `src/tools/font/make_noto_fonts.py`：下载并落盘 Noto 静态字重（映射的实际文件来源）；
- `src/tools/font/build_cyr_fonts.py`：俄语四个自建字体；
- `src/tools/font/build_lat_fonts.py`：拉丁扩展 A 语言（pl）的三个标题字体，正文沿用原版；
- `src/tools/font/extract_fonts.py`：导出原版字体（仅用于度量测量）；
- `src/tools/font/squeeze_fonts.py`：按原版度量压缩字形的辅助脚本；
- `docs/构建与安装.md`：构建流程里的字体说明。
