# 字体与分发限制

## 结论

**缝合出来的字体只允许本机自用，不要分发。**

发行版默认**不缝合**：直接把完整的 Noto 字体以原始文件名放进 `PR2Localization\fonts\`，
由 `font-map.ini` 映射游戏请求的四个逻辑名，可以随包分发
（见 [`发行版.md`](发行版.md)）。下面说的是可选的缝合路径。

`build/runtime/PR2Localization/fonts/` 是用 fontstitch 生成的衍生作品目录；
构建时可按语言暂存，部署/打包时平铺到这一层，不按语言单开子目录。

- base 是游戏原版拉丁字体（Ascaron / Port Royale 2）；
- donor 是系统或商业字体：微软雅黑、华文中宋、思源宋体、钟齐志莽、
  Noto Serif JP 等；
- **每个语言一份 `presets/<语言>.toml`**：该目录不进仓库，由
  `presets.example.toml` 复制而来；目前有 `zh` 和 `ja`，各自独立。

这些字体本身的许可通常**不允许修改后再分发**；把缝合结果上传、打包、
放进发布物或提交进仓库，都可能违反许可。

## 已经做的限制

- `.gitignore` 忽略 `assets/fonts/original/` 和 `build/runtime/fonts/`；
- `subset_fonts.py` 在输出目录生成 `不要分发.txt`；
- 部署脚本只复制 `.ttf` 到游戏目录的 `PR2Localization\fonts\`，不按语言单开子目录，也不会把说明文件带进字体目录；
- 仓库里只提交缝合代码与 presets，不提交任何字体文件。

## 别人要用怎么办

让对方在自己的机器上准备：

1. 从自己的游戏里导出原版字体：
   ```bash
   python src/tools/font/extract_fonts.py --game-dir "<游戏目录>" --out assets/fonts/original
   ```
2. 为每个语言准备 `src/tools/font/fontstitch/presets/<语言>.toml`
   （可从 `presets.example.toml` 复制），安装/准备自己的 donor；
3. 检查前置条件并生成：

```bash
python src/tools/font/subset_fonts.py --check
python src/tools/font/subset_fonts.py --all
```

每个语言先输出到构建暂存目录，部署时把该语言的缝合 TTF 平铺到游戏目录的
`PR2Localization\fonts\`，不覆盖根目录原版；同一次安装只放一个语言的字体。
完整清单见 [`新语言字体配置.md`](新语言字体配置.md)。

## 配置文件名映射（不强迫改字体名）

游戏请求的是四个固定逻辑名，但磁盘上的字体可以保留自己的文件名。
`PR2Localization\fonts\font-map.ini` 把这四个名字映射到 `fonts` 目录内的实际文件：

```ini
[zh]
ARIAL.TTF=NotoSansSC-Regular.ttf
ELGRECO_.TTF=NotoSerifSC-Black.ttf
Tiepolo_black.ttf=NotoSerifSC-Black.ttf
Tiepolo_bold.ttf=NotoSerifSC-Bold.ttf
```

映射值只写文件名，文件必须位于 `PR2Localization\fonts\`；不会读取系统字体目录，
也不接受该目录之外的路径、`.ttc` 集合或 `-VF.ttf` 可变字体。两个逻辑名可以指向
同一个文件；`[fonts]` 是全局默认，`[zh]` / `[ja]` 覆盖它。运行时按
“配置映射 → 该映射文件的实际路径 → 原版根目录”回退；映射缺失或文件不存在时
不会把缺字体当成成功。

`font-map.ini` 的模板在 `src/font-map.ini`。默认 `--fonts noto` 会把
`NotoSansSC-Regular.ttf`、`NotoSerifSC-Black.ttf`、`NotoSerifSC-Bold.ttf`
（日文对应 JP）平铺到 `PR2Localization\fonts\`，再附带映射文件。
`--fonts config` 只带映射文件，不含字体；使用这种包时必须自己把映射里写明的
实际字体文件放进 `PR2Localization\fonts\`，否则 GUI 会提示字体缺失。
