**自動で変更できない理由**：B ティアはテキストに現れるキーワードで分類しており、`pirate` を含むからといって話者が海賊とは限りません。例えば `On behalf of my nation, I would like to thank you for destroying a convoy of the notorious pirate…` は総督が感謝している台詞です。そのため自動で書き換えると、役人の台詞まで常体に落ちてしまいます。

確認の進め方の提案：**person = 一人称**かつ**カテゴリが海賊/酒場**の項目だけを見てください。実際にその人物自身が自分の言葉で話している可能性があるのは、これらの項目だからです：

```bash
python -c "import csv,io;rows=[r for r in csv.DictReader(io.open('docs/csv/analysis/speaker-audit.csv',encoding='utf-8-sig')) if r['person']=='第1人称' and r['category'] in ('海盗/私掠','酒馆/醉汉')];print(len(rows))"
```

## 次のステップ

1. まず `0x03fb5c6a` の署名の書式を変更すべきか確認する（この 1 件のみ）。
2. 海賊/酒場のカテゴリで **person=一人称** の項目について話者を 1 件ずつ確認し、海賊/酔漢本人だと確認できたものだけ常体に変更する。
3. 残りはそのままにする。エンジンの対話構造が参照できない以上、話題から語調を推測しても、変更するほど話がこじれるだけです。
