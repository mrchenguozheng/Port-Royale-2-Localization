# ビルドとインストール

## エントリーポイント

日常的に使う分には、次の 1 つだけで済みます（Python 3.11 以降が必要）。

```bat
start.bat
```

これは次のことを行います。

1. このマシン上でワークベンチサービスを起動する
2. ブラウザでインストールページ `/install` を開く
3. サービスのログを表示するコンソールウィンドウを開いたままにする

**自動的にビルドされることはありません。** ビルド、デプロイ、起動はすべて、ページ上のボタンをクリックして実行します。
コンソールウィンドウを閉じるか Ctrl+C を押すと、サービスが停止します。

> リリース向けのプレイヤー用 GUI `PR2LauncherGUI.exe` もあります。詳細は
> [リリース](release.md) を参照してください。これは開発用ワークベンチではありません。

## インストールウィザード

ページ上部の「インストールと起動」には 5 ステップのウィザードがあります。まず対象言語を選択してください。

| ステップ | 内容 |
|---|---|
| 1 ゲームディレクトリの準備 | ゲームディレクトリを選択するか、「選択/検出」をクリックしてバージョンを識別します |
| 2 フォントの準備 | 「オリジナルをエクスポート」と「ドナーを確認」。フォントが不足している場合は警告が出ます |
| 3 コンテンツの翻訳 | 翻訳の編集に移動し、対象言語で未翻訳のエントリがいくつ残っているかを確認します |
| 4 言語パック + フォントの生成 | `compile_pack` とフォントビルドを呼び出します |
| 5 インストールと起動 | ゲームディレクトリにデプロイしてから起動します |

ウィザードはあくまで案内役です。以下のカードは個別に操作することもできます。

## インストールページのカード

### 1 ゲームディレクトリ

- パスを入力するか、「参照…」をクリックします。
- 「検出して記憶」は `PR2.exe` の SHA-256 で既知のバージョンを識別し、結果を設定に書き込みます。
- 記憶済みのディレクトリは下に一覧表示され、切り替えや削除ができます。
- ステータスにはバージョン、インストール済みの言語パック、`locale.ini` が表示されます。

設定は既定では次の場所に保存されます。

```
%LOCALAPPDATA%\PR2Localization\settings.json
```

`PR2_SETTINGS` 環境変数を設定すると保存場所を変更できます。保存されるのはパスとバージョンだけで、翻訳は保存されません。

### 2 ビルドとデプロイ

| ボタン | 動作 |
|---|---|
| インジェクターをコンパイル（DLL + ランチャー） | MSVC を呼び出して `PR2TextSource.dll`、`PR2Launcher.exe`、`PR2LauncherGUI.exe` を生成します |
| 言語パックをコンパイル | チェックした言語をコンパイルし、フォントの確認と再結合を行います |
| ゲームディレクトリへデプロイ | ランタイム、言語パック、`ui/`、`fonts/<language>/` をコピーします |

デプロイの特徴：

- ファイルをコピーするだけで、`PR2.exe` は変更しません。
- 内容が同一のファイルは SHA-256 でスキップされるため、何度も書き直されることはありません。
- この実行でチェックされなかった言語パックは、ゲームディレクトリから削除されます。
- フォントは `fonts/<language>/` に配置され、**ルートディレクトリのオリジナルは上書きしません**。
- 言語パックの `locale.ini` がデプロイによって勝手に変更されることはありません。

### 3 起動

| ボタン | 動作 |
|---|---|
| 言語ドロップダウン | `PR2Packs/*.txt` から現在使用可能な言語を読み取ります |
| ゲーム言語に設定 | `PR2Packs/locale.ini` の `language=` を書き込みます |
| ゲームを起動（インジェクションあり） | 現在選択されている言語で `PR2Launcher.exe` 経由で起動します |
| 比較用にオリジナルを起動 | `PR2.exe` を直接起動します。インジェクションは行いません |
| 翻訳エディターを開く | 翻訳の編集ページに切り替わります |

注意：**「ゲームを起動」は `locale.ini` を自動的に書き込みません。** 選択を永続化したい場合は「ゲーム言語に設定」をクリックしてください。
一方、リリース版 GUI は起動成功後に自動的に書き戻します。

## 言語の決定方法

実行時に有効になる言語は 1 つだけです。

| 優先度 | 取得元 | 適用範囲 |
|---|---|---|
| 1 | `PR2_PACK_LANG` 環境変数 | 今回の起動のみ。`PR2Launcher.exe --lang=xx` が設定します |
| 2 | `PR2Packs/locale.ini` の `language=` | 永続的な既定値 |
| 3 | DLL 内蔵のフォールバック `zh` | ini がまったく存在しない場合 |

したがって：

- インストールページの「ゲーム言語に設定」= 2 番目を書き込みます。
- インストールページの「ゲームを起動」= 今回の起動にだけ言語を渡し、ファイルは書き込みません。
- リリース版の `PR2LauncherGUI.exe` は起動成功後に 2 番目を書き込みます。
- `PR2Launcher.exe` を直接ダブルクリックした場合は 2 番目だけを読みます。
- `PR2.exe` を直接実行した場合はランチャーを経由せず、バージョン確認も行いません。

## バージョンの識別

ワークベンチは `PR2.exe` の SHA-256 によって既知のビルドを識別します。

| バージョン | 備考 |
|---|---|
| GOG 英語版 1.1.2.3 | ✅ 唯一サポートされるビルド。テスト済み |
| GOG フランス語版 1.1.2.42 | ❌ 非サポート。翻訳の参照用のみ |
| Steam 英語版 1.1.2.3 | ❌ 非サポート。CEG 環境ではインジェクションが機能しなかった |

非サポートのビルドは識別のためだけに検出されます。そこへデプロイしないでください。

未知のバージョンも記憶できますが、名前は付きません。バージョン名とハッシュ定数は
`src/tools/install/pr2ctl/base.py` にあります。

## フォント

ローカル開発では **fontstitch による結合（スティッチ）** を使用します。

- `assets/fonts/original/` のオリジナルのラテンフォントをベースにします。
- 現在の翻訳で使われている文字をドナーから追加します。
- 言語ごとに 1 セットで、`build/fonts/<language>/` に出力します。
- 新しい文字が現れると自動的に再結合します。キャッシュの目印は `.stitch.json` です。
- フォントの失敗が言語パックのビルド失敗になることはありません。

リリース版では結合を行わず、**完全な Noto** フォントを使用します。詳細は [リリース](release.md) を参照してください。

```bat
python src\tools\font\subset_fonts.py --lang zh
python src\tools\font\make_noto_fonts.py --lang zh --out <dir>
```

結合したフォントはローカルでの利用に限られます。アップロードや同梱はしないでください。詳細は [フォントと配布](fonts-and-distribution.md) を参照してください。

## 翻訳の編集

インストールページと同じワークベンチにあり、上部のタブで切り替えます。

- ページ単位の編集で、既定では 1 ページ 100 エントリです。
- 編集内容はページをまたいで保持され、「保存」をクリックするとまとめて送信されます。
- 右側の参照列には「このバージョンには該当するエントリがない」と表示されます。
- ＋ 言語を追加：コードを入力してテンプレートを選ぶと、`src/live/<code>.toml`、
  `src/seed/<code>.toml`、`presets/<code>.toml` が生成されます。
- 新しい言語をインストールページに表示するには、ワークベンチを再読み込みしてください。

言語パックのメタデータ（表示名、GUI 言語、最低ランタイム）は次の場所にあります。

```
src/packs/<code>.toml
```

これはコンパイル時に言語パックのヘッダーへ書き込まれます。古い言語パックには互換性がありません。詳細は
[リリース](release.md) を参照してください。

## 開発者向けコマンド

翻訳を変更した後、ページをいちいち操作したくない場合：

```bat
apply_patch.bat                 :: ja + zh をビルドし、最後に使ったゲームディレクトリへデプロイ
apply_patch.bat --langs ja      :: 日本語のみ
apply_patch.bat --launch        :: デプロイ後すぐに起動
apply_patch.bat --dry-run       :: 計画の表示のみ
```

これは次の順に実行します。

1. 翻訳を正規化する（任意の `--dep` で不足しているスペースを補う）
2. `check_breaks --strict` で改行とプレースホルダーを検証する
3. 言語パックをコンパイルする（既定でフォント結合を含む）
4. ゲームディレクトリへデプロイする
5. SHA-256 でファイルを 1 つずつ比較する

個別にビルドする場合：

```bat
src\build_injector.bat
src\build_translation.bat
```

言語パック/フォントの統合ビルド入口はライブラリです。

```python
from build_artifacts import compile_pack, build_fonts
```

日常的には `compile_pack.py` または `apply_patch.py` を使い続けてください。直接 import する必要はありません。

## ビルドディレクトリ

```
build\
├─ PR2TextSource.dll
├─ PR2Launcher.exe
├─ PR2LauncherGUI.exe
├─ PR2Packs\        蓄積された言語パック
├─ fonts\<language>\   結合フォント
└─ font-cache\      Noto フォントキャッシュ
```

`build\` 以下のすべては生成物です。丸ごと削除して再ビルドできます。

`build\PR2Packs\locale.ini` は存在しない場合にのみテンプレートから作成され、ユーザーが選択した言語を上書きすることはありません。

## よく使うスクリプト

| スクリプト | 役割 |
|---|---|
| `start.bat` | ローカルのワークベンチサービスを起動する |
| `apply_patch.bat` | ビルド + デプロイ + 検証 |
| `src\build_injector.bat` | DLL/ランチャーをコンパイルする |
| `src\build_translation.bat` | 言語パックをコンパイルする |
| `src\find_python.bat` | Python を特定する |

`src\tools\` 内の Python エントリーポイント：

| スクリプト | 用途 |
|---|---|
| `pack/compile_pack.py` | 言語パックをコンパイルし、プレースホルダーを検証する |
| `pack/build_artifacts.py` | 言語パック/フォントの統合ビルドライブラリ |
| `pack/apply_patch.py` | コマンド 1 つでビルドとデプロイを行う |
| `pack/new_lang.py` | 新しい言語を作成する |
| `font/subset_fonts.py` | フォントを結合する |
| `font/make_noto_fonts.py` | リリース用 Noto フォント |
| `text/space_words.py` | 中国語のスペースを補う |

## サービス状態

インストールページ下部の「サービス状態」セクションには次の内容が表示されます。

- 現在のサービスの pid、ポート、稼働時間、Python バージョン
- 8777～8800 の範囲にある他のインスタンス。ワンクリックで停止できます
- エンドポイント：`/api/health`、`/api/server/instances`、`/api/server/stop`

コマンドラインでは：

```bat
start.bat --status
python src\tools\install\server_status.py --stop 8779
```
