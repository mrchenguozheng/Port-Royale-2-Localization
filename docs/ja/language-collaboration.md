# 言語追加の協力フロー

翻訳と校正だけを担当し、コードは書かない翻訳者と、ビルドとリリースを担当する
メンテナー向けの文書です。例として韓国語 `ko` を使用しますが、他の言語でも同じ手順に
なります。

> 対応しているのは GOG 英語版 `1.1.2.3` のみです。新しい言語もこのバージョンで検証する
> 必要があります。

## 役割分担

| 作業 | 翻訳者 | メンテナー |
|---|---|---|
| 翻訳、校正、用語、トーン | ✅ | 協力可 |
| ゲーム内での検証 | ✅ | ✅ |
| `src/live/<code>.toml` | ✅ | 代行可 |
| `src/packs/<code>.toml` | 不要 | ✅ |
| `ui/<code>.ini` | ✅ | 代行可 |
| フォントマッピング / Noto KR | 不要 | ✅ |
| 言語パックのコンパイル | 任意 | ✅ |
| ビルド／リリース zip | ❌ | ✅ |
| 対応ビルド / 互換性 | ❌ | ✅ |

原則：**翻訳者が担当するのは翻訳と UI 文字列だけであり、それ以外はすべてメンテナーが
対応します。**

## 翻訳者：2 つの作業方法

### A. ワークベンチを使う

Python 3.11+ が必要ですが、Visual Studio は不要です（インジェクタのビルド成果物が既に
ある場合）。

```bat
start.bat
```

**翻訳エディタ**で：

1. 言語ドロップダウンで `ko` を作成または選択します（メンテナーが用意した言語を使っても
   かまいません）。
2. 翻訳して保存します（`src/live/ko.toml` に書き込まれます）。
3. 未翻訳の項目は英語で表示されるため、ファイル全体を一度に仕上げる必要はありません。

### B. ファイルを交換する

メンテナーが次を用意します：

```
src/live/ko.toml
ui/ko.ini
```

翻訳者は任意の UTF-8 エディタで編集して返送します。検証、ビルド、パッケージング、テストは
メンテナーが実行します。

## 翻訳者が変更してはいけないもの

- `hash =` の左側の id；
- `%1`、`%2` などのプレースホルダー；
- `@D$...$` のようなスクリプト変数；
- `<n>`、`<c>`、`<f:...>` などのタグ；
- `build/` 以下のもの（再生成されて上書きされます）。

## メンテナー：言語の雛形を作る

### 1. 翻訳ファイルを作成する

```bat
python src\tools\pack\new_lang.py --new-lang ko --from en
```

次のファイルが生成されます：

```
src/live/ko.toml
src/tools/font/fontstitch/presets/ko.toml
```

`ko.toml` は英語からコピーされるため、未変更の項目は英語のまま表示され、1 つずつ置き換えて
いけます。

### 2. 言語パックのメタデータを追加する

`src/packs/ko.toml`：

```toml
alias = "한국어"
gui = "ko"
min_runtime = 1
```

これがないと、GUI には `ko` と表示され、UI は英語にフォールバックします。

### 3. ランチャー UI を追加する

`ui/en.ini` を `ui/ko.ini` にコピーして翻訳者に渡します。GUI は言語パックのメタデータが
`gui = "ko"` のときにこれを読み込みます。

### 4. 韓国語のフォントマッピングを追加する

`src/tools/font/make_noto_fonts.py` の `LANGS` に追加します：

```python
"ko": {
    "sans": ("NotoSansKR", 400),
    "serif": ("NotoSerifKR", (700, 900)),
    "label": "Korean",
},
```

ビルドマシンに Noto Sans KR / Noto Serif KR をインストールしてください。

### 5. 言語パックとフォントをビルドする

```bat
python src\tools\pack\compile_pack.py --lang ko
python src\tools\font\make_noto_fonts.py --lang ko --out <dir>
```

### 6. リリースをビルドする

```bat
python src\tools\pack\make_release.py --lang ko --version v1.1.0
```

新しい言語の追加は機能追加にあたるため、通常は `v1.1.0` を使用します。

## 検証

クリーンな GOG 英語版のコピーで：

1. `PR2-ko-*.zip` を展開する；
2. `PR2LauncherGUI.exe` を実行する；
3. `한국어` を選択する；
4. 次を確認する：
   - 韓国語のテキストが表示される；
   - 欠字がない（特にタイトルフォント）；
   - 長いテキストやボタンが切れていない；
   - プレースホルダーと改行が保たれている；
   - 言語の切り替えと元のバージョンの起動が引き続き動作する。

問題を報告するときは、次を含めてください：

- エントリのハッシュ；
- UI の位置；
- スクリーンショット；
- 欠字、切れ、翻訳のいずれの問題か。

## 引き渡し前のチェックリスト

- 言語コードが確定している（例：`ko`）；
- `ko.toml` が 3548 件のエントリで生成されている；
- `ui/ko.ini` が存在する；
- フォントの方針が決まっている；
- 対応するゲームビルドが GOG 英語版であることが明記されている。
