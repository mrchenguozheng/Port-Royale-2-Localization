# プレイヤーガイド: 展開してプレイする

このドキュメントでは、**リリースパッケージをインストールして起動する方法**だけを説明します。
ソースからのビルドや翻訳作業については扱いません。

## 1. ゲームのビルドを確認する

現在サポートしているのは次のとおりです。

```
GOG English Port Royale 2 1.1.2.3
```

Steam 版、GOG フランス語版、その他のビルドはサポートしていません。これらのビルドに
リリースパッケージを配備しないでください。

## 2. 対応する言語の zip をダウンロードする

プロジェクトの Releases ページから必要な言語をダウンロードします。例えば次のとおりです。

```
PR2-zh-v0.5.0.zip
PR2-ja-v0.5.0.zip
```

zip 1 つにつき言語 1 つです。複数の言語が必要な場合は、それぞれダウンロードしてください。

## 3. ゲームのルートに展開する

zip 内の**すべてのファイル**を `PR2.exe` と同じ階層に展開します。

```
<game directory>\
├─ PR2.exe
├─ PR2Launcher.exe
├─ PR2LauncherGUI.exe
├─ PR2TextSource.dll
├─ PR2Packs\
├─ fonts\
├─ ui\
└─ ...
```

注意:

- `PR2Launcher\` のようなサブフォルダに展開しないでください。
- ルートの `fonts\` にある元の 4 つのフォントを削除しないでください。
- パッケージが `fonts\` を上書きすることはありません。ローカライズ版のフォントは
  `fonts\<lang>\` に配置されます。

## 4. PR2LauncherGUI.exe を実行する

1. 対象の言語を選択します。
2. **Launch selected language** をクリックします。

起動に成功すると、GUI は選択した内容を次の場所に書き込みます。

```
PR2Packs\locale.ini
```

次回の起動では、その言語が既定になります。

**`PR2.exe` を直接実行しないでください**。言語パックが読み込まれません。

## 5. 初回起動時に元のフォントがバックアップされる

初めてフォントを置き換える前に、ランチャーは元の 4 つの TTF を次の場所にバックアップ
します。

```
fonts\_original\
```

以降の動作は次のとおりです。

- ローカライズ起動では `fonts\<lang>\` を使用し、ルートの元フォントには触れません。
- `PR2Launcher.exe --vanilla` はルートの元フォントを使用します。

ルートのフォントが既知の元フォントでない場合、ランチャーはバックアップをスキップします。

## 6. フォントが見つからない場合

GUI に次のように表示された場合は、パッケージが完全に展開されていません。

```
fonts\zh\ has no TTF fonts
```

対処:

1. `fonts\<lang>\` フォルダ全体を展開し直します。
2. 4 つのファイルがすべて存在することを確認します。

   ```
   ARIAL.TTF
   ELGRECO_.TTF
   Tiepolo_black.ttf
   Tiepolo_bold.ttf
   ```

3. フォントをルートの `fonts\` に置かないでください。
4. ウイルス対策ソフトによって隔離されていないか確認してください。

そのまま起動することもできますが、元のラテン系フォントにフォールバックし、CJK 文字が
空白になる場合があります。

## 7. 言語の切り替え

- 現在の言語: `PR2Packs\locale.ini` の `language=`。
- GUI で別の言語を選択し、もう一度起動します。
- または、1 回だけ上書きすることもできます。

  ```bat
  PR2Launcher.exe --lang=ja
  ```

  これは `locale.ini` を書き込みません。

## 8. アンインストール

パッケージによって追加されたファイルを削除します。

```
PR2Launcher.exe
PR2LauncherGUI.exe
PR2TextSource.dll
PR2Packs\<lang>.txt
fonts\<lang>\
ui\
README.txt / OFL.txt / NOTO-SOURCES.txt / RUNTIME-VERSION
```

削除しないでください。

- `PR2.exe`、`.cpr`、マップ、音楽などその他のゲームファイル。
- ルートの `fonts\` にある元のフォント。

セーブデータには影響しません。

## トラブルシューティング

| 症状 | 原因 | 対処 |
|---|---|---|
| インターフェースが英語のまま | `PR2.exe` を直接実行した、または `locale.ini` が正しくない | GUI から起動する。`PR2Packs\locale.ini` を確認する |
| CJK 文字が空白になる | フォントの欠落または不完全 | `fonts\<lang>\` の 4 つの TTF を確認する |
| GUI に言語が表示されない | `PR2Packs\<lang>.txt` がルートにない | 言語パックを展開し直す |
| ランチャーのウィンドウが一瞬で消える | コンソールプログラムのためエラーが見えない | ターミナルから `PR2Launcher.exe` を実行する |
| Steam 版で動作しない | Steam は未サポート | GOG 英語版を使用するか、今後のサポートを待つ |

技術的な詳細については、[ビルドとインストール](build-and-install.md) と
[リリース](release.md) を参照してください。
