## 残留 242 条的分类

- 111 条剥掉标签后没有字母：纯标签串（`<gs:TEXTFLUSS_KEINEHOEHE><g:INTEXT_…>`）、
  纯占位（`@d$Pos$<n>`、`%s%s`、`%1x`）、`+++EMPTY+++`。
- 131 条是标识符与专名：
  - 开发与发行人员名单 44 条（`Tim Plöger`、`Matthias Süß`、`Jörg Beilschmidt` 一类）；
  - `IDM_CONTEST_01_2004_LOG_*` 13 条、`scenario000`–`scenario006` 7 条（零售同样保留英文）；
  - `Dummy` 9 条、`dummy` 2 条；
  - 键位与键名 20 条（`ESC`、`Enter`、`Insert`、`Delete`、`Pause`、`Page Up`、`Tab key`、
    `Shift`、`CTRL`、`Backspace`、`F1`–`F12`），俄语键盘上印的就是这些英文键名；
  - `OK`/`Ok` 4 条、公司名 5 条（`M&S Music`、`MBA Studios`、`Sassenbach Advertising`、
    `Yanco`、`Take2`）、字体文件名 2 条（`Tiepolo_black14x14aaFHk.res` 等，不可改名）、
    `QA`、`PR2-Contest-01-2004`、`Between Us!`、`Ätschi Ü Ötzi`、`x 10`、`Port Royale 2`
    标题本体。
- 版权声明 `0xfc512ea5` 由 `compile_pack` 强制回退英文原文，`ru.toml` 同步保留英文，
  否则 `--strict` 报一条警告。

## 口径（与西语不同的地方）

- 人称：全库正式 `вы`；零售里混用的 `ты`（`0xd99427aa`、`0x12b72f2f`）已统一为
  `Вы выиграли…`。
- 专名：与西语“保留源名”不同，俄语按零售对同一批人名做**音译**，并纠正零售的转写
  （`Корпус-Кристи` 而非 “Корпус Христи”、`Веракрус`、`Вильяэрмоса`、`Сент-Огастин`、
  `Нассау`、`Чарлстон`）。带前置词的姓氏同样音译：`de Vega`→`де Вега`、
  `van der Felde`→`Ван дер Фельд`、`le Brun`→`ле Бран`。
- 月份：全称用俄语正名（`Январь`…`Декабрь`），缩写三字母不带点
  （`Янв`/`Фев`/`Мар`/`Апр`/`Май`/`Июн`/`Июл`/`Авг`/`Сен`/`Окт`/`Ноя`/`Дек`）。
- 引号与状态词：UI 名称用 «»，状态词 `«слабая»`、`«бум»`、`«Спад»`、`«дружественная»`。
- 术语：`Tools`（货物）→`Инструменты`，职员表分区标题 `0x37329032 Tools` 保留英文；
  `Market stall`→`Прилавок`，与 `Marketplace`→`Рынок` 区分。
- 世纪数字按俄语习惯改罗马数字（`XVI`、`XVII`、`XVIII`），千位用不占位写法
  （`1 500`、`2 000`）或直接连写（`1500`、`2200`），与英文 `1,500` 等同义。

## 验收

```powershell
# 占位符与标签
python -c "import sys,tomllib;sys.path.insert(0,'shared/core');import validate as v;en=tomllib.load(open('src/orig/en.gog_1.1.2.3.toml','rb'));ru=tomllib.load(open('src/translations/ru.toml','rb'));print([(k,r) for k,v in ru.items() for r in v.check_text(v,en.get(k),'ru')])"

# 术语
python src/tools/terms_check.py --lang ru

# 整包
python src/tools/pack/compile_pack.py --lang ru --strict --no-fonts
```

| 检查 | 结果 |
|---|---|
| `check_text(..., lang="ru")` | 3548 条，0 error / 0 warn |
| `compile_pack --lang ru --strict --no-fonts` | 通过，3548 条，占位未翻译 0 |
| pack 与 TOML 逐条一致 | 3548 条，键缺失 0、值不一致 0 |
| pack 编码 | UTF-8 无 BOM，无 `\u` 转义 |
| 拉丁残留（西里尔句中的拉丁词） | 10 条，全为产品名、键名与引文原词 |
| `«»` 与 `"` 配对 | 0 条失衡 |
| 数字对照 | 50 处差异，逐条看过：世纪改罗马数字、`1 day`→`в одном дне`、`1,000`→`1000` 一类，无漏译数字 |
| 长度比例（>1.7 或 <0.6，60 字符以上） | 10 条，均为藏宝诗谜的韵文改写或精简提示，信息要素未缺 |
| `terms_check --lang ru` | 180 条，形态/大小写/专名误报，与西语同类型 |

`terms_check` 误报类型（俄语）：格变化（`Инструменты`→`инструментов`）、
派生组合（`Плантация сахарного тростника`）、句中首字母小写、月份名小写、
专名撞车（`France` 在借词句里、`Nassau` 与 `Нассау` 同形判定）。
