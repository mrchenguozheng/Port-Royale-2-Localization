## 口径（与西语不同的地方）

- 人称：全库正式 `вы`；零售里混用的 `ты`（`0xd99427aa`、`0x12b72f2f`）已统一为
  `Вы выиграли…`。
- 专名：与西语“保留源名”不同，俄语按零售对同一批人名做**音译**，并纠正零售的转写
  （`Корпус-Кристи` 而非 “Корпус Христи”、`Веракрус`、`Вильяэрмоса`、`Сент-Огастин`、
  `Нассау`、`Чарлстон`）。带前置词的姓氏同样音译：`de Vega`→`де Вега`、
  `van der Felde`→`Ван дер Фельд`、`le Brun`→`ле Бран`。
- 月份：全称用俄语正名（`Январь`…`Декабрь`），缩写三字母不带点
  （`Янв`/`Фев`/`Мар`/`Апр`/`Май`/`Июн`/`Июл`/`Авг`/`Сен`/`Окт`/`Ноя`/`Дек`）。
- 引号与状态词：UI 名称用 «»，状态词 `«слабая»`、`«бум»`、`«Спад»`、`«дружественная»`。
- 术语：`Tools`（货物）→`Инструменты`，职员表分区标题 `0x37329032 Tools` 保留英文；
  `Market stall`→`Прилавок`，与 `Marketplace`→`Рынок` 区分。
- 世纪数字按俄语习惯改罗马数字（`XVI`、`XVII`、`XVIII`），千位用不占位写法
  （`1 500`、`2 000`）或直接连写（`1500`、`2200`），与英文 `1,500` 等同义。

## 字体与实机

俄语不走字体缝合（原版四个拉丁字体没有西里尔字形，缝合要 donor 与原版 UPM 一致，
而 Noto 是 1000 UPM），改用按原版度量自建的四个字体，由 `font-map` 与游戏请求的
四个逻辑名一一对应：

```ini
[ru]
ARIAL.TTF=PR2CyrBody-Regular.ttf
ELGRECO_.TTF=PR2CyrDisplay-Head.ttf
Tiepolo_black.ttf=PR2CyrDisplay-Black.ttf
Tiepolo_bold.ttf=PR2CyrDisplay-Bold.ttf
```

- 正文 `PR2CyrBody-Regular.ttf` 是 Liberation Sans：与 Arial 的 advance 逐字相同
  （西里尔 64 字实测差 0 em），自带西里尔，OFL 可分发；正文不再因字体变宽而变长。
- 标题三档各出一份（`build_cyr_fonts.py`）：Noto Serif 轮廓按原版度量缩放，
  纵向对齐 cap height，横向压到原版平均 advance，纵向度量也写回原版数值，行盒
  高度与原版一致；去掉 hinting，族名改为 `PR2 Cyrillic Display *`。
  - Black / Bold：cap 0.614、sy=0.860；横向在原版 0.517 / 0.496 上**再乘 0.88**
    （sx≈0.685 / 0.683），hhea 0.791/-0.292、win 0.869/0.856 与 0.295；
  - Head（ELGRECO 槽位，原版是窄而高的花体）：cap 0.724、sy=1.014，横向压到
    原版 avg 0.343（sx≈0.516），hhea 0.833/-0.250、win 0.928/0.308。
- 0.88 是有意的偏差，不是测量误差：俄语 UI 串比英文长，按原版宽度实测会撑出
  木板挂牌，所以牺牲 12% 字宽换取文案不用缩写。
- 四个文件平铺在 `PR2Localization\fonts\`，不按语言开子目录，也不改名成
  `ARIAL.TTF` 一类的游戏逻辑名；译文用到的 170 个字符在四个字体里全部覆盖。
- 来源仍是 Noto 静态 TTF（不是 VF、不是 TTC），允许修改再分发；Liberation Sans
  同为 SIL OFL 1.1。
- `make_noto_fonts.py` 不再负责俄语，`LANGS` 里没有 `ru`。

同一次构建会平铺进 `fonts\` 的还有中文的 Noto SC，这是部署脚本“复制整个字体目录”
的行为，不影响俄语映射。

实机部署记录（GOG 法语 1.1.2.42）：`PR2Localization.exe`、`PR2LocalizationCore.dll`、
`PR2LocalizationGUI.exe`、`packs\ru.txt`（3548 条）、`fonts\` 四个 PR2Cyr 文件与
`font-map.default.ini` 已复制；`locale.ini` 指向 `ru`。该版本比英文基准多 42 条，
逐条看过全是 `+++EMPTY+++` 占位，没有需要补译的内容。

（`fonts/Tiepolo_black13x13aaFHk.res`、`Tiepolo_bold14x14aaFH.res`、
`ELGRECO_26x26aaFHk.res`），文件名里的字号没变，只有 `0xe1cdc367` 那处已知的
整段替换错误把引用丢了。合理的解释是：零售在**同尺寸**字体里塞进了西里尔字形，
其字宽比 Noto Serif 窄，所以 28 个字符的标题能进同一块木板。

这个推断后来按“改字体而不是改文案”实现了：见上两节的 `PR2Cyr*`。第一轮缩短的
11 个键已改回长写法，等截图验证。

零售的 PR2.exe 与 `pr2_loca.cpr` 不在本机（只保留了 `ru.retail-1.0.0.toml`），
无法比对二进制，所以“零售是否改过 exe 或绘制字号”只能停在推断：从文本侧看不到
字号变化，但零售 RU 是 1.0.0、基准是 1.1.2.3，布局本身可能有差异，不能排除。

### 长写法试验（第三轮，已截图为证）

字体换窄后，把第一轮为了避让裁切而缩短的 11 个键改回长写法试排版，截图结果：

| 位置 | 长写法 | 结果 |
| --- | --- | --- |
| 场景列表 `0x0a635027` / `0x01d937d3` / `0x123eae2f` / `0x1ab9b63f` / `0x356e884e` | `Перевозка товаров и торговля`、`Строительство и производство`、`По следу Черной Бороды!` | **放得下**，两端有余量，保留长写法 |
| 主菜单 `0xf67158d8` / `0xffaac4a3` | `Режим свободной игры` | 两端被切（只剩「ежим свободной игр」），退回 `Свободная игра` |
| 欢迎弹窗标题 `0x087151cf` | `Добро пожаловать в Port Royale 2` | 首字母与末尾数字被切，退回 `Добро пожаловать!` |
| Esc 菜单 `0xd0d692a5` / `0x391f78da` | `Быстрое сохранение` | 左右越出木板，退回 `Быстрое сохр.` |
| Esc 菜单 `0xf24b293b` | `Загрузить/сохранить` | 左侧越出木板，退回 `Загрузка/сохр.` |

结论：木板挂牌这类窄控件容不下长写法，场景列表这种整行控件可以。最终状态是
场景名用长写法、按钮挂牌用短写法，与零售的取舍不同（零售全用长写法，靠更窄的
字形塞进去）。
