# 新语言完整流程（从零到进游戏）

按顺序做，每步都有验收点。以新增 `de`（德语）为例，中文换成 `zh` 即可。

> 只想改现有中文翻译：跳过第 3、4 步的 presets 配置；字体仍需要第 2 步的
> 原版字体和第 3 步的 donor。

---

## 0. 准备环境

需要：

- Windows + 已安装的游戏；
- Python 3.11+；
- 项目源码；
- 第 2、3 步要用的字体文件。

```bash
cd pr2-localization
```

---

## 1. 启动工作台

双击 `start.bat`，浏览器打开安装页（默认 `http://127.0.0.1:8777/install`）。
安装页顶部有「第一次用？按这个顺序」卡片，会实时显示原版字体、donor、
fontTools 和字体生成状态，并可直接点「导出 / 检查 / 缝合」。

**验收**：页面能打开，顶部有「译文编辑 / 安装与启动」两个标签。

---

## 2. 导出游戏原版字体

`assets/fonts/original/` 不在仓库里，先导出：

```bash
python src/tools/font/extract_fonts.py --game-dir "C:\Games\Port Royale 2 GOG" --out assets/fonts/original
```

**验收**：目录里出现四个文件：

```
ARIAL.TTF  ELGRECO_.TTF  Tiepolo_black.ttf  Tiepolo_bold.ttf
```

---

## 3. 准备 donor 字体

字体缝合是“原版拉丁字体 + donor 中/日文字体”。

- 安装中/日文字体（微软雅黑、华文中宋、思源宋体、Noto Serif JP 等）；
- 新语言创建后会自动生成 `presets/<代码>.toml`，再按语种改 `donor_file`；
- 每个语言一份配置，互不影响。

检查缺什么：

```bash
python src/tools/font/subset_fonts.py --check
```

**验收**：输出「字体缝合前置条件齐全」。

如果报缺 fontTools：

```bash
python -m pip install fonttools
```

---

## 4. 新建语言

在「译文编辑」页：

1. 语言下拉旁点「＋」；
2. 输入语言代码（如 `de`）；
3. 选一个现成语言当模板；
4. 点「创建」。

会生成：

```
src/live/de.toml
```

（新语言目前只自动创建 `live` 文件；`seed` 初版不会自动生成，需要时可以从
模板语言手工复制一份到 `src/seed/de.toml`。）

**验收**：语言下拉里出现 `de`，列表能翻页。

---

## 5. 检查新语言的 donor（字体）

创建语言时，会自动生成 `src/tools/font/fontstitch/presets/de.toml`：

- 内容以**模板语言**的 presets 文件为模板；模板没有 presets 时用 `zh`；
- 如果 presets 目录不存在，先从 `presets.example.toml` 复制；
- 每个语言一个文件，互不影响；已有 `de.toml` 时不会覆盖。

统一结构：

```toml
[[pair]]
game_file = "ARIAL.TTF"
donor_file = "%WINDIR%\\Fonts\\msyh.ttc"
donor_index = 0

[[supplement]]
game_file = "ELGRECO_.TTF"
donor_file = "%WINDIR%\\Fonts\\STZHONGS.TTF"

[fallback]
donor_file = "%WINDIR%\\Fonts\\NotoSansJP-VF.ttf"
```

要点：

- **每个语言一份 `presets/<语言>.toml`**；
- donor 必须是 TrueType（`glyf`）；
- donor 的 UPM 必须和游戏字体一致：Arial 2048，ElGreco/Tiepolo 1000；
- 做中文以外的语言时，自动复制的中文 donor 可能不覆盖新语言字符集，
  需要换成该语言的 donor。

**验收**：`python src/tools/font/subset_fonts.py --check` 不再报缺 donor。

---

## 6. 翻译

在编辑器里逐条改，`Ctrl+S` 或「保存」。保存直接写 `src/live/de.toml`。

**验收**：刷新页面后译文还在；底部计数正常。

---

## 7. 缝合字体

```bash
python src/tools/font/subset_fonts.py --lang de --force
```

**验收**：日志里出现

```
de：N 个用字
   ARIAL.TTF
   ...
字体已处理：de
```

并且 `build/fonts/de/` 下四个 TTF 都更新了。

有缺字时日志会列 `U+XXXX`：换 donor 或加 supplement 后重跑。

---

## 8. 构建语言包并部署

安装页「安装与启动」：

1. 勾选 `de`；
2. 点「编译语言包」；
3. 点「部署到游戏目录」。

或命令行：

```bash
python src/tools/pack/apply_patch.py --langs de --game-dir "C:\Games\Port Royale 2 GOG"
```

**验收**：日志显示 `PR2Packs\de.txt` 已复制，并复制了
`build/fonts/de/` 那一套字体，`locale.ini` 指向 `de`。

---

## 9. 启动验证

安装页点「启动游戏（已注入）」，或运行游戏目录的 `PR2Launcher.exe`。

检查：

- 主菜单文字；
- 设置菜单；
- 标题字体有没有字形；
- 长文本有没有缺字空白。

**验收**：界面文字可读、无空白方块、标题字体正常。

---

## 10. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 新语言全是空白 | 没有配 `[语言]` presets，字体没缝；加段后重跑第 7 步 |
| 个别字空白 | donor 缺字；加 `supplement` 或换覆盖更全的 donor |
| 字体报 UPM 不一致 | donor 与游戏字体 UPM 不同；换 donor 或先缩放 |
| 中文正常、标题字体缺字 | 标题字体没配 donor / 缺 supplement |
| 双击字体在 Windows 预览里打不开 | 老底字体的历史问题，不影响游戏；用 `fontverify.py info` 检查 |
| 字体很大 | 只缝当前译文用字；字符增加会自动重缝 |

---
