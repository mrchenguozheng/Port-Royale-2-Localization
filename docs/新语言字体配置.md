# 新语言与字体缝合：需要准备什么

这份仓库**不包含任何字体二进制**。别人克隆后要做自己的语言包并缝字体，
需要自己准备下面这些东西。

## 1. 游戏原版拉丁字体（必需）

`assets/fonts/original/` 在 `.gitignore` 里，克隆后是空的。从自己的游戏导出：

```bash
python src/tools/font/extract_fonts.py --game-dir "<游戏目录>" --out assets/fonts/original
```

得到：

```
ARIAL.TTF  ELGRECO_.TTF  Tiepolo_black.ttf  Tiepolo_bold.ttf
```

也可以用 `PR2_ORIG_FONTS` 或 `subset_fonts.py --src` 指向别处的原版字体目录。

## 2. donor 字体（必需，且不在仓库里）

每个语言一份配置：

```
src/tools/font/fontstitch/presets/<语言>.toml
```

结构统一，不再有 `[zh]` 这种外层段：

```toml
# presets/zh.toml
[[pair]]
game_file = "ARIAL.TTF"
donor_file = "%WINDIR%\\Fonts\\msyh.ttc"
donor_index = 0

[[supplement]]
game_file = "ELGRECO_.TTF"
donor_file = "%WINDIR%\\Fonts\\STZHONGS.TTF"

[fallback]
donor_file = "%WINDIR%\\Fonts\\NotoSansJP-VF.ttf"
```

- `[[pair]]`：每个游戏字体一条主 donor；
- `[[supplement]]`：主 donor 缺字时补；
- `[fallback]`：最后兜底。

`presets/` 整个目录不进仓库（路径可能含本机信息）；仓库只提交
`presets.example.toml`。新语言会自动复制模板语言的配置成
`presets/<语言>.toml`，然后按语种改 donor。

## 3. fontTools（必需）

```bash
python -m pip install fonttools
```

或设置 `PR2_FONTTOOLS_SITE` 指向已装好 fontTools 的 site-packages。

## 4. 字体约束

- donor 必须是 TrueType `glyf` 轮廓；
- donor 的 UPM 必须和对应游戏字体一致：Arial 2048，ElGreco/Tiepolo 1000；
- 主 donor 覆盖不到的字用 `[[supplement]]` 补；
- 每个语言分别生成到 `build/fonts/<语言>/`，互不影响。

## 5. 生成与部署

```bash
# 检查原版字体、donor、fontTools
python src/tools/font/subset_fonts.py --check

# 只缝一个语言
python src/tools/font/subset_fonts.py --lang zh --force

# 缝全部已配置语言
python src/tools/font/subset_fonts.py --all --force
```

输出：

```
build/fonts/zh/ARIAL.TTF ...
build/fonts/ja/ARIAL.TTF ...
```

部署时只复制**目标语言**那一套字体到游戏 `fonts\`。

## 6. 分发限制

缝合字体是「游戏原版字体 + 商业 donor」的衍生作品，**只允许本机自用**，
不要上传、打包或提交进仓库。详见 `docs/字体与分发.md`。
