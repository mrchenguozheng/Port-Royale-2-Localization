# 新语言与字体缝合：别人需要准备什么

这份仓库**不包含任何字体二进制**。别人克隆后要做自己的语言包并缝字体，
需要自己准备下面这些东西。

## 1. 游戏原版拉丁字体（必需）

`assets/fonts/original/` 在 `.gitignore` 里，克隆后是空的。从自己的游戏导出：

```bash
python src/tools/extract_fonts.py --game-dir "C:\Games\Port Royale 2 GOG" --out assets/fonts/original
```

会得到：

```
ARIAL.TTF  ELGRECO_.TTF  Tiepolo_black.ttf  Tiepolo_bold.ttf
```

也可以用 `PR2_ORIG_FONTS` 或 `subset_fonts.py --src` 指向别处的原版字体目录。

## 2. donor 字体（必需，且不在仓库里）

`src/tools/fontstitch/presets.toml` 里目前只配了中文：

| 用途 | donor | 默认路径 |
|---|---|---|
| 正文/UI | 微软雅黑 | `%WINDIR%\Fonts\msyh.ttc` |
| 标题 ElGreco | 钟齐志莽行书 | `%LOCALAPPDATA%\Microsoft\Windows\Fonts\ZhiMangXing-Regular.ttf` |
| 标题 Tiepolo Black | 思源宋体 Heavy | `%WINDIR%\Fonts\Source Han Serif SC Heavy (TrueType).ttf` |
| 标题 Tiepolo Bold | 华文中宋 | `%WINDIR%\Fonts\STZHONGS.TTF` |
| 兜底 | Noto Sans JP | `%WINDIR%\Fonts\NotoSansJP-VF.ttf` |

这些是系统/商业字体，仓库不能分发。别人需要：

- 自己安装同款字体；或
- 改 `presets.toml`，换成自己机器上有的 donor（路径支持 `%WINDIR%`、
  `%LOCALAPPDATA%`、`${VAR}`、`~`）。

## 3. fontTools（必需）

```bash
python -m pip install fonttools
```

或设置 `PR2_FONTTOOLS_SITE` 指向已装好 fontTools 的 site-packages。

## 4. 新语言的 presets 段（必需）

如果要做中文以外的语言，需要在 `presets.toml` 里加对应语言的段：

```toml
[ja]

[[ja.pair]]
game_file = "ARIAL.TTF"
donor_file = "%WINDIR%\\Fonts\\NotoSansJP-VF.ttf"
```

规则：

- **只有写了 `[语言]` 段的语言才会被缝进字体**；
- 没有配置的语言（当前 `ja` 就是这种情况）直接跳过，游戏里会缺字；
- donor 必须是 TrueType `glyf` 轮廓；
- donor 的 UPM 必须和对应游戏字体一致（Arial 2048，ElGreco/Tiepolo 1000）；
- 主 donor 覆盖不到的字符可以再加 `[[<lang>.supplement]]`。

## 5. 语言本身

新语言要先有：

```
src/live/<语言>.toml
src/seed/<语言>.toml
```

编辑器里的「添加语言」会以某个现成语言为模板复制一份；字体字符只从
`src/live/<语言>.toml` 收集。

## 6. 检查与生成

```bash
# 检查原版字体、donor、fontTools 是否齐全
python src/tools/subset_fonts.py --check

# 缝合（按 presets 里配置的语言）
python src/tools/subset_fonts.py --force
```

输出在 `build/fonts/`；之后用安装页的「部署到游戏目录」复制进游戏。

## 7. 分发限制

缝合字体是「游戏原版字体 + 商业 donor」的衍生作品，**只允许本机自用**，
不要上传、打包或提交进仓库。详见 `docs/字体与分发.md`。
