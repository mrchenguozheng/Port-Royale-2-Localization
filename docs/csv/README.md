# CSV Data Index

CSV files are analysis and review artifacts, not runtime game data.
`docs/` root contains documentation only; data is grouped by purpose here.

[中文索引](README.zh-CN.md) · [Documentation index](../README.md)

## analysis/

| File | Generated by | Purpose |
|---|---|---|
| `analysis/宽度粗查-zh.csv` / `-ja.csv` | `python src/tools/analysis/width_check.py --lang zh` | Estimated translated-vs-English width; used by [Translation limits](../en/translation-limits.md) |
| `analysis/speaker-audit.csv` | `python src/tools/analysis/speaker_audit.py` | Per-line speaker/tone classification; used by [Speaker tiers](../en/speaker-tiers.md) |
| `analysis/tone-proposal.csv` | `python src/tools/analysis/tone_proposal.py` | Tone proposals; used by [Tone proposals](../en/tone-proposal.md) |
| `analysis/占位符语义.zh.csv` / `.ja.csv` | `python src/tools/placeholder_roles.py --report --lang zh` | Connector suggestions for adjacent `%N %N`; used by [Translations & packs](../en/translation-and-packs.md) |

## voice/

| File | Generated by | Purpose |
|---|---|---|
| `voice/voice-inventory.csv` | `ffprobe` over voice files | Voice file inventory |
| `voice/voice-hash-map.csv` | `python src/tools/voice_match.py` | Voice-to-text hash mapping |

## review/

| File | Purpose |
|---|---|
| `review/人工修订.csv` | Human-confirmed Chinese revisions (hash / original / changed / date) |
| `review/zh-text-edits.csv` | Historical Chinese text edit comparisons |

## generated/

| File | Generated by | Notes |
|---|---|---|
| `generated/space-words-zh.csv` | `python src/tools/text/space_words.py --lang zh --dry-run` | Chinese spacing before/after |
| `generated/zh-dep-space.csv` | `python src/tools/text/zh_dep_space.py` (optional) | Dependency-based spacing experiment |
| `generated/space-conj-dryrun.csv` | historical dry-run | Early dependency experiment, kept for reference |
| `generated/space-name-dryrun.csv` | historical dry-run | Early proper-name experiment, kept for reference |

## CSV files elsewhere

- `build/glossary/zh.csv`: glossary build artifact, regenerable;
- `build/hash-index.csv`, `archive/hash-index/hash-index.csv`: generated/archived indexes;
- `src/**/*.csv`: test or third-party data.

New analysis scripts should write to `docs/csv/<category>/`, not the `docs/` root.
