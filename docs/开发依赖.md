# 开发依赖

这份清单记录**做本地化、编译语言包、生成/调整字体**各需要什么。
核心流程只依赖 Python 标准库，其它都是可选的，缺了会降级而不是报错。

## 必需

| 依赖 | 版本（本机实测） | 用途 |
|---|---|---|
| **Python** | 3.13.18（≥3.10 即可；CI 用 3.12） | 所有脚本；只用标准库 |
| **PowerShell** | 7.x（`pwsh`） | 根目录与 `src` 下的 `.ps1` 入口 |
| **Git** | — | 版本管理、分批提交 |

Python 路径（本机）：

```
python.exe（Python 3.13 的安装位置，按你的环境）
```

所有工具都是命令行脚本，**不需要 venv、不需要任何 Web 框架**。
仓库里的 `.venv` 是历史遗留，可以删。

## 可选（Python）

| 包 | 版本 | 谁在用 | 没有时怎么办 |
|---|---|---|---|
| `janome` | 0.5.2 | 构建期助词空格（`lang_rules/ja.py` 的 `JaSegmenter`）判助詞 | 自动退到 `fugashi`，再退到正则 |
| `spylls` | 0.1.7 | hunspell 词典查询：`lang_check.py` 的 `proper_names` 抽专名、`retail_import` 判「参照行不是目标语言」；词典 `.dic/.aff` 已在 `src/data/qa/dict` 入库 | 这两处判据失效：抽专名报 `ModuleNotFoundError`，语种识别拦不住外文行 |
| `fugashi` + `unidic-lite` | 1.5.2 / 1.0.8 | 同上（后备分析器） | 同上 |
| `kiwipiepy` | 0.25.1 | `text_lint.py --lang ko` 的助词收音检查（按世宗标签判 JKS/JKO/JX） | 跳过该条检查；占位符后接助词的规则不依赖它 |
| `fonttools` | 4.68.0 | 字体生成与调整（`make_noto_fonts.py` / `build_cyr_fonts.py` / `squeeze_fonts.py`） | 字体步骤跳过，沿用现有字体 |

安装（按 CI 钉死的版本一次装齐）：

```bat
python -m pip install -r requirements-ci.txt
```

CI 装的就是这一份（`spylls` `janome` `kiwipiepy` `fonttools` 四个版本锁死），
再加一份 `.venv-spacy`（spaCy + `zh_core_web_sm`），与开发机同路径。
`fugashi` / `unidic-lite` 不装：janome 在场时日语分词永远走 janome，这两个
不参与判定；`unidic-lite` 在 PyPI 只有源码包（47 MB），装上还要现构建。

**版本为什么写死**：原先 `requirements-ci.txt` 写的是 `>=`，CI 实装漂到
spylls 0.1.7 / kiwipiepy 0.25.1，而开发机停在 0.1.0 / 0.24.1 —— 两边跑的
根本不是同一套判据。要升版本就改 `requirements-ci.txt`，再在本机重装、重跑
`check.ps1`。

### fonttools 的特殊情况

本机的 `fonttools` **不在**上面那个 Python 里，而是装在 WorkBuddy 的 Python 环境：

```
<某个已装 fonttools 的环境>\Lib\site-packages
```

`make_noto_fonts.py`、`build_cyr_fonts.py`、`squeeze_fonts.py` 会用 glob 自动找到它，
找到就直接用，不会污染主环境。
如果想统一，把 `fonttools` 也装进主 Python 即可（脚本优先用当前环境）。

## 一键自检

```bat
python -c "import janome, fugashi; print('analyzer ok')"
python -c "import fontTools; print('fontTools ok')"
```

`normalize_text.py`、`squeeze_fonts.py` 在缺包时都会提示并降级，
不会让整条构建链失败。

### 提交前自查：跨模块引用

模块拆开后，函数里调用别的模块的函数而本文件没导入，运行时才会 `NameError`。
提交前跑一次：

```powershell
python src\tools\lint_imports.py
```

它扫描 `src/tools/install/pr2ctl/*.py`，列出「用了但没定义/导入」的全局名；退出码 1 表示有可疑引用。
