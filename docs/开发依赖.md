# 开发依赖

这份清单记录**做本地化、编译语言包、裁剪字体、开编辑器**各需要什么。
核心流程只依赖 Python 标准库，其它都是可选的，缺了会降级而不是报错。

## 必需

| 依赖 | 版本（本机实测） | 用途 |
|---|---|---|
| **Python** | 3.14.3（≥3.10 即可） | 所有脚本；只用标准库 |
| **Git** | — | 版本管理、分批提交 |

Python 路径（本机）：

```
python.exe
```

编辑器后端是纯标准库的 `http.server`，**不需要 venv、不需要 fastapi/uvicorn**。
仓库里的 `.venv` 是历史遗留，可以删。

## 可选（Python）

| 包 | 版本 | 谁在用 | 没有时怎么办 |
|---|---|---|---|
| `janome` | 0.5.0 | `normalize_text.py --particles` 判定助詞 | 自动退到 `fugashi`，再退到正则 |
| `fugashi` + `unidic-lite` | 1.5.2 / 1.0.8 | 同上（后备分析器） | 同上 |
| `fonttools` | 4.x | `subset_fonts.py` 裁剪字体 | 字体重裁步骤跳过，沿用现有字体 |

安装：

```bat
python -m pip install janome
python -m pip install fugashi unidic-lite
python -m pip install fonttools
```

### fonttools 的特殊情况

本机的 `fonttools` **不在**上面那个 Python 里，而是装在 WorkBuddy 的 Python 环境：

```
<已装 fonttools 的环境>\Lib\site-packages
```

`subset_fonts.py` 会用 glob 自动找到它，找到就直接用，不会污染主环境。
如果想统一，把 `fonttools` 也装进主 Python 即可（脚本优先用当前环境）。

## 可选（前端）

编辑器前端是 Astro，构建产出到 `src\editor\dist\`，后端直接托管静态文件。

| 依赖 | 版本（本机实测） |
|---|---|
| Node.js | v24.14.0 |
| pnpm | 10.6.1 |
| astro | ^7.4.1（`src\editor\package.json`） |

```bat
cd src\editor
pnpm install
pnpm run build      :: 产出 dist/，编辑器才会用上新前端
```

改前端源码后必须重新 build，否则 `dist/` 还是旧页面。

## 一键自检

```bat
python -c "import janome, fugashi; print('analyzer ok')"
python -c "import fontTools; print('fontTools ok')"
node -v & pnpm -v
```

`normalize_text.py`、`subset_fonts.py` 在缺包时都会提示并降级，
不会让整条构建链失败。
