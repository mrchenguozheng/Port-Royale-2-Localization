# 译者工作台

译者只需要翻译和校对，不需要 Visual Studio、Node.js、fontTools，也不需要
游戏注入器。工作台由一个小型 Python 服务提供，只开放翻译页。

## 生成

维护者在仓库根执行：

```bat
python src\tools\pack\make_translator.py --lang ja --out dist\PR2Translator-ja
```

默认会复制当前 Python 运行时，译者**不需要安装 Python**。

用自定义 Python：

```bat
python src\tools\pack\make_translator.py --lang ja --out dist\PR2Translator-ja ^
    --python-dir C:\Python311
```

不内置 Python：

```bat
python src\tools\pack\make_translator.py --lang ja --out dist\PR2Translator-ja ^
    --system-python
```

`--python-dir` 目录里需要有 `python.exe`。

## 内容

```
PR2Translator-ja/
├─ start.bat
├─ README.txt
├─ editor/
│  ├─ server.py           独立翻译服务，只用标准库
│  └─ web/                英文界面
├─ shared/core/           共用存储与校验
├─ data/
│  ├─ live/ja.toml        当前语言
│  └─ orig/               英文参考
└─ python/                默认内置，无需安装
```

没有 `build/`、注入器、字体、`PR2Packs/`、术语表或安装页面。

源码在仓库的 `editor/`，可以单独启动：

```bat
editor\start.bat
```

## 译者使用

1. 解压；
2. 双击 `start.bat`；
3. 浏览器打开 `/translate/ja`；
4. 翻译并保存；
5. 关闭控制台窗口即停止服务。

工作台只有翻译页，没有安装、构建或启动入口。

> 工作台界面当前为**英文**；它和「翻译目标语言」是两件事。
> 目标语言只决定加载哪份 `live/<lang>.toml`。

## 多语言

一个编辑器实例可以同时打开 `data/live/` 下的多种语言：

- 顶部 `Translation language` 切换要编辑的语言；
- 切换后 URL 变成 `/translate/<lang>`；
- 不用为每种语言重新启动编辑器；
- 启动时默认打开上次选择的语言；
- 只有第一次没有记录时才用默认语言，不再固定 `ja`。

参考列显示：

```text
English
French reference
```

法语在英语下方显示，只作参考，不会被编辑。

## 编辑器界面文字

顶部的 **Editor UI text** 只改这个编辑器自己的按钮、标签和提示，不改游戏译文。

- 选 `Interface language` 切换界面语言；
- 可新建如 `ko`；
- key 只读，空值回退英文；
- 游戏译文仍然在 **Game translation**。

## 交回

译者把修改后的文件交回维护者：

```
data/live/ja.toml
```

维护者再负责：

- 校验占位符/换行；
- 编译语言包；
- 生成字体；
- 构建发行包；
- 在 GOG 英文版验收。

## 注意

- 工作台只监听 `127.0.0.1`；
- 默认已内置 Python；只有 `--system-python` 才需要系统 Python 3.11+；
- 不包含 Git，也不需要译者使用 Git；
- 不复制其他语言的译文。
