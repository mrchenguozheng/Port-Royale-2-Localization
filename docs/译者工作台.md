# 译者工作台

译者只需要翻译和校对，不需要 Visual Studio、Node.js、fontTools，也不需要
游戏注入器。工作台由一个小型 Python 服务提供，只开放翻译页。

## 生成

维护者在仓库根执行：

```bat
python src\tools\pack\make_translator.py --lang ja --out dist\PR2Translator-ja
```

默认会复制当前 Python 运行时，译者**不需要安装 Python**。

用自定义 Python：

```bat
python src\tools\pack\make_translator.py --lang ja --out dist\PR2Translator-ja ^
    --python-dir C:\Python311
```

不内置 Python：

```bat
python src\tools\pack\make_translator.py --lang ja --out dist\PR2Translator-ja ^
    --system-python
```

`--python-dir` 目录里需要有 `python.exe`。

## 内容

```
PR2Translator-ja/
├─ start.bat
├─ README.txt
├─ src/
│  ├─ editor/
│  │  ├─ server.py
│  │  └─ dist/             已构建前端
│  ├─ tools/               翻译、校验、术语逻辑
│  ├─ live/ja.toml         当前语言
│  ├─ orig/                英文参考
│  ├─ seed/                初版文本
│  └─ find_python.bat
└─ glossary/               术语表
```

没有 `build/`、注入器、字体、`PR2Packs/` 或安装页面。

## 译者使用

1. 解压；
2. 双击 `start.bat`；
3. 浏览器打开 `/translate/ja`；
4. 翻译并保存；
5. 关闭控制台窗口即停止服务。

工作台只显示「译文编辑」，构建/部署/启动接口返回 403。

> 当前工作台自身的界面文字仍是中文；它和「翻译目标语言」是两件事。
> 目标语言只决定加载哪份 `live/<lang>.toml`。

## 交回

译者把修改后的文件交回维护者：

```
src/live/ja.toml
```

维护者再负责：

- 校验占位符/换行；
- 编译语言包；
- 生成字体；
- 构建发行包；
- 在 GOG 英文版验收。

## 注意

- 工作台只监听 `127.0.0.1`；
- 默认已内置 Python；只有 `--system-python` 才需要系统 Python 3.11+；
- 不包含 Git，也不需要译者使用 Git；
- 不复制其他语言的译文。
