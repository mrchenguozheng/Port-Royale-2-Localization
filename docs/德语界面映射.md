## 主菜单（2026-11-15 实机确认）

六个按钮在竖排木牌上，标记与文本同行显示，字体正常、无替字、无截断。

| 标记 | 键 | 英文 | 德语 |
|---|---|---|---|
| `[58D8]` | `0xf67158d8` | Free-play mode | Freies Spiel |
| `[52EB]` | `0x044e52eb` | Scenarios | Szenarien |
| `[6C7E]` | `0xf5496c7e` | Load | Laden |
| `[5DEC]` | `0xff075dec` | Options | Optionen |
| `[B565]` | `0x30a8b565` | Credits | Danksagungen |
| `[12C8]` | `0xf4b112c8` | Quit Game | Spiel beenden |

备注：`0xf5496c7e` 的德语原文带尾部空格（`"Laden   "`），是原有写法，与界面显示无关；
六个键的德语在实机上均按整串显示，未被控件截断。
