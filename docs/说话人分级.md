# 说话人分级（只依据英/法原文）

> 自动生成：`python src/tools/speaker_audit.py`。逐条明细：[speaker-audit.csv](speaker-audit.csv)。
> 判定只使用**英语**和**法语**原文。日语是我们自己译的，用它反推说话人是循环论证，所以不参与。

## 分级定义

| 级别 | 含义 | 条数 |
|---|---|---|
| **A 确定** | 文本直接写明身份：落款、自称、头衔标签 | 6 |
| **B 可推断** | 由内容可推断说话人的角色或与玩家的关系 | 668 |
| **C 通用** | 只有第一人称/祈使，没有角色线索 | 2284 |
| **N 无说话人** | 系统界面、第三人称事件旁白 | 401 |
| **非文本** | 标签/符号、调试串、保留项，不参与说话人判定 | 189 |
| 合计 | | 3548 |

> 说话人判定只在 **3359 条对白**上做；剩下 189 条是非文本，单独列在下面。

## 上一版为什么显得乱

| 问题 | 旧规则 | 现规则 |
|---|---|---|
| 把「提到亲属」当成「说话人是亲属」 | 出现 `my wife` / `my daughter` 就判 A 级，于是旁白 `While you are looting the town, a young woman comes running up…` 也被算成亲属 | 改为 B 级「亲属/恋人关系」，只表示**可推断**关系，且另设 `person` 列标明是第几人称 |
| 落款规则匹配到正文 | 全文搜索 `viceroy of %1`，事件通报 `The viceroy of %1 has moved to %2. Governor…` 被判成「信件署名」 | 只在**结尾 90 字**内找落款，且要求文本足够长 |
| CSV 带过期日语列 | 混入 `ja` 列，且换词后未同步（还显示 `総督代理`） | 删掉日语列，改成英语 + 法语两列（法语是另一份权威文本） |
| 没有可核查的依据 | 只有一句中文说明 | 新增 `rule`（A1/A2/A3/N1/N2/B/C）与 `person`（第1/第3人称/祈使/无） |

## 局限

- 规则是启发式的：一条文本可能命中多个类别，取优先级最高者；
- B 级只表示「能推断角色」，不等于确定是哪位 NPC；
- 通用委托/感谢/奖励文案被多个角色复用，无法确定说话人；
- 要拿到真正的说话人，需要解析引擎的对话结构（语言包里没有）。
