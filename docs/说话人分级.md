# 说话人 / 语气 分级清单

> 自动生成：`python src/tools/speaker_audit.py`。逐条明细：[speaker-audit.csv](speaker-audit.csv)。

这个清单回答一个问题：**从文本本身，能不能判断这句话是谁说的？**

语言包里只有 `hash = 文本`，没有 speaker 字段；同一个 hash 由哪个 NPC 调用，在包文件里看不出来。所以按「文本能否自证身份」分成四级。

> 判定只依据**英语**与**法语**原文——这两个版本是权威文本。荷兰语/西班牙语语音只用于核对同一句的发音，德语旁白没有权威文本，都不作为判定依据。

**日语不参与对照**：日语是我们自己译的，用它反推说话人等于循环论证；本清单的示例一律用英语原文。

## 怎么用

1. 调语气先看 **A 级**：身份明确，按身份定敬体/常体；
2. **B 级**按类别定基调：公务=です・ます，海盗/酒馆=常体，财政官=公文化；
3. **N 级**一律中性，不出现对玩家的直接请求；
4. **C 级**保持通用与克制，别加原文没有的敬语修饰。

## 局限

- 规则是启发式的，一条文本可能命中多个类别，取优先级最高者；
- 「亲属/恋人称呼」能确定说话人与玩家的关系，确定不了具体是哪位 NPC；
- 通用奖励/感谢文案被多个角色复用，任何「确定说话人」的判断都不成立；
- 要从资源层面拿到真正的说话人，需要解析引擎的对话结构（不在语言包里）。
