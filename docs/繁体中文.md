# 繁体中文（台湾 / 香港）

繁体不是第三套译文，而是从简体 `src/translations/zh.toml` 派生出来的**底稿 + 地区差异表**。
两份发行语言（`zh-TW`、`zh-HK`）各自生成完整译文并提交，既有校验、编译、出包链路不用改。

## 派生链

出包与简体一致走并集键集（3590 条），一份包同时用于 GOG EN / GOG FR / Steam EN。
派生脚本是 `src/tools/pack/derive_variant.py`。

排版也走简体那套：`lang_rules` 把 `zh-TW`、`zh-HK`、`zh-Hant` 别名到 `zh`，
所以繁体同样只做紧凑断行（`MAX_CHARS=13`、`MIN_RUN=6`、标点不插空格），
不再另写一份繁体规则。分词前会先用 OpenCC `t2s` 转成简体送 spaCy，再按字数
把词界切回繁体原字形——直接喂繁体，模型会把「製圖師」切成「製圖 / 師為」。

```
src/translations/zh.toml            简体（唯一手改层）
        │  OpenCC s2tw（只转字形，不转词汇）
        ▼
src/translations/zh-Hant.toml       繁体底稿（台湾标准字形：裡／著／群／眾／秘／為／臺）
        │  + src/data/variants/zh-TW.toml（炮→砲，1 条规则）
        │  + src/data/variants/zh-HK.toml（裡→裏、臺→台，2 条规则）
        ▼
src/translations/zh-TW.toml / zh-HK.toml    生成物，一并提交
```

为什么用 `s2tw` 而不是 `s2t`：`s2t` 输出偏港式/旧字形（`爲` `衆` `羣` `祕` `裏` `着`），
`zh-TW` 还要再补一轮；`s2tw` 直接把字形归一到台湾标准，`s2t` 与 `s2tw` 都不做词汇转换
（不会把「軟件」改成「軟體」），地区词汇完全由差异表显式控制，便于审查。

重跑：

```powershell
python src/tools/pack/derive_variant.py --all
python src/tools/pack/derive_variant.py --variant zh-TW
```

派生脚本同时生成 `src/data/names/<locale>.toml`、`src/data/terms/<locale>.toml`
（译名与术语表），并断言：键集与底稿一致、每条标记数量不变、`·` / `‧` 为 0、规则已收敛。

## 实际差异量（2026-11-23）

| 项目 | zh-TW | zh-HK |
|---|---|---|
| 条目 | 3548 | 3548 |
| 与对方不同的字符串 | 350（9.9%） | 同左 |
| `裡` / `裏` | 392 / 0 | 0 / 392 |
| `砲` / `炮` | 54 / 0 | 0 / 54 |
| `臺` / `台` | 1 / 0 | 0 / 1 |

差异集中在火砲用字与「裡」；`許可證`、`稅款`、`軟件/軟體` 这些常见港台差异在本作正文里
不命中或不宜替换（私掠許可證是历史文书，改成「牌照」失真），已在差异表注释里写明不收的理由。

刻意不收的一条：`著`。底稿的「著」有两个来源（简体「着」与简体「著」），香港写「着」，
但全局替换会把「著名」「著作」误伤，因此香港版保留「著」，只在差异表里注明。

## 字体与发行

- 字体：`NotoSansTC-Regular.ttf`、`NotoSerifTC-Black/Bold.ttf`，由
  `src/tools/font/make_noto_fonts.py --lang zh-hant`（或 `--lang zh-TW`）从 Noto TC 可变字体实例化；
  源地址写在 `src/fonts-sources.toml`（`langs = ["zh-hant"]`）。
- 映射：`src/font-map.ini` 的 `[zh-TW]`、`[zh-HK]` 四项都指向同一组 TC 文件；
  简体 SC 不含 `裡` `砲` `著` 等繁体专用字形，不能共用。
- 发行：两个语言进同一个 bundle `zh-hant`（`src/release-bundles.toml`，默认 `zh-TW`），
  共用一份字体，`release-languages.txt` 已登记 `zh-TW`、`zh-HK`。
- 启动器界面另有 `src/injector-rs/ui/ui.zh-TW.ini`、`ui.zh-HK.ini`，由 `ui.zh.ini` 同样规则派生。

## 维护约定

- **只改 `zh.toml` 与差异表，不改生成物**；`zh-Hant.toml`、`zh-TW.toml`、`zh-HK.toml`
  由脚本重写。
- 新增地区用词差异：优先写 `[[replace]]`（必须全局安全），有反例的写 `[keys]` 逐条覆盖。
- 底稿改动（如简体修一条译文）要重跑 `derive_variant.py --all`，两份繁体自动跟上。
