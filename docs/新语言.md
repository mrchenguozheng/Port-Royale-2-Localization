# 新语言：从准备到发行

面向“新增一种语言”的完整流程，合并了原来的完整流程、协作分工和字体准备三份文档。
以 `ko`（韩语）为例；中文把代码换成 `zh` 即可。

> 当前支持 **GOG 英文版 `1.1.2.3`** 和 **Steam 英文版 `1.1.2.3`**（宿主 DLL 代理）。
> 新语言两版都要验收；其他游戏版本不在支持范围内。

## 1. 分工

| 事情 | 译者 | 维护者 |
|---|---|---|
| 翻译、校对、术语、语气 | ✅ | 可参与 |
| 游戏内验收 | ✅ | ✅ |
| `src/translations/<代码>.toml` | ✅ | 可代做 |
| `src/packs/<代码>.toml` | 不需要 | ✅ |
| 启动器 UI | 不需要 | 固定默认 UI；用户自行覆盖 |
| 字体映射 / Noto 字体 | 不需要 | ✅ |
| 编译语言包 | 可选 | ✅ |
| 构建/发行 zip、版本与兼容性 | ❌ | ✅ |

原则：**译者只对译文和界面文本负责，构建、字体和发行由维护者收口。**

## 2. 准备环境

- Windows，已安装 GOG 或 Steam 英文版；
- Python 3.11+；
- PowerShell 7；
- 项目源码；
- 字体工具按需安装：`python -m pip install fonttools`。

译者只用工作台时不需要 Rust 工具链；维护者构建注入器才需要。

## 3. 字体：只做映射

### 3.1 导出游戏原版字体（测度量用）

`assets/fonts/original/` 不在仓库里，先导出：

```bash
python src/tools/font/extract_fonts.py --game-dir "<游戏目录>" --out assets/fonts/original
```

得到四个文件：

```
ARIAL.TTF  ELGRECO_.TTF  Tiepolo_black.ttf  Tiepolo_bold.ttf
```

它的用途是**测量原版字体度量**（判断断行、裁切，见 §4.5），不再喂任何缝合管线。

### 3.2 字体来源

字体只有一条路：完整 Noto 静态字重（俄语另走 `build_cyr_fonts.py` 的四个自建文件）。
没有 donor、没有 presets、没有缝合步骤；`make_noto_fonts.py` 负责下载并落盘，
`src/font-map.ini` 负责把四个逻辑名映射到这些实际文件。

### 3.3 字体约束与分发

- 直接把完整 Noto 字体以原始文件名放进 `PR2Localization\fonts\`，由
  `font-map.default.ini` 提供逻辑名映射；
- 实际字体必须平铺在 `PR2Localization\fonts\`，不按语言开子目录；
- 不把实际字体改名为 `ARIAL.TTF`、`ELGRECO_.TTF`、`Tiepolo_black.ttf`、
  `Tiepolo_bold.ttf`，由映射指定。详见[字体与分发](字体与分发.md)。

## 4. 创建语言

### 4.1 生成译文骨架

在工作台「译文编辑」页点语言下拉旁的「＋」，输入代码 `ko`，模板选 `en`。工作台会：

- 复制 `src/translations/en.gog_1.1.2.3.toml` 为 `src/translations/ko.toml`，
  未改的条目保留英文。

只创建 `ko.toml` 也可以；条目数和顺序必须与
`en.gog_1.1.2.3.toml` 完全一致，否则合并时 hash 会错位。

**验收**：语言下拉出现 `ko`，列表能翻页。

### 4.2 加语言元数据

`src/packs/ko.toml`：

```toml
alias = "한국어"
min_runtime = 1
```

- `alias`：启动器列表显示名；没有时显示代码；
- `min_runtime`：高于当前运行时会拒绝启动，避免旧 DLL + 新语言包静默不翻译。

### 4.3 启动器界面

启动器不再按语言包做 UI 多语言：固定使用 `src/injector-rs/ui/ui.default.ini`。
新语言只需要游戏内文本，不需要再建 `ui/<code>.ini`，也不需要在 `packs/<code>.toml`
里写 `gui`。用户想改启动器文案时，自己放 `PR2Localization/ui/ui.ini` 按项覆盖。

### 4.4 加 Noto 字体映射

对中文、日文、韩文等 CJK 语言，在
`src/tools/font/make_noto_fonts.py` 的 `LANGS` 里加对应项，例如：

```python
"ko": {
    "sans": ("NotoSansKR", 400),
    "serif": ("NotoSerifKR", (700, 900)),
    "label": "Korean",
},
```

确认本机已安装对应的 Noto Sans / Noto Serif 字体。没安装时也可以把静态 TTF 放在
`build\cache\noto-src\`，`make_noto_fonts.py` 会按同样的文件名在那里找（该目录不进仓库）。

生成字体后，还要在 `src/font-map.ini` 加新语言节，否则运行时找不到映射，会回退到
根目录原版拉丁字体。韩文示例：

```ini
[ko]
ARIAL.TTF=NotoSansKR-Regular.ttf
ELGRECO_.TTF=NotoSerifKR-Black.ttf
Tiepolo_black.ttf=NotoSerifKR-Black.ttf
Tiepolo_bold.ttf=NotoSerifKR-Bold.ttf
```

四个逻辑名必须都指向 `PR2Localization\fonts\` 下实际存在的文件；非拉丁语言默认用
Noto 对应字体，静态字重，不接受 `.ttc` 和 `-VF.ttf`。

### 4.5 度量不匹配时压缩字体

直接挂完整 Noto 只解决“有没有字形”，不解决“字宽是否和原版一致”：Noto Serif 的
平均 advance 与 cap height 都比游戏原版的 Tiepolo 大，长串会在固定宽度的木板里
被裁切。做法是测量原版字体（`extract_fonts.py` 导出 `pr2_loca.cpr` 里的四个字体），
按它的 cap height 与平均 advance 缩放 Noto 轮廓，生成独立文件再由 `font-map` 映射。
俄语现成实现见 `src/tools/font/build_cyr_fonts.py`：正文换用与 Arial 度量逐字相同
的 Liberation Sans，标题用压缩后的 Noto Serif。

### 4.6 术语表与译名表

译文里有两类标注要查表，两张表必须**每门语言都有同样的键**，否则一门语言引用了、
另一门没有这一行，构建时只能靠人肉发现：

| 表 | 位置 | 形状 | 基准 |
|---|---|---|---|
| 术语表 | `src/data/terms/<语言>.toml` | `<参考语言>_<原词> = "译词"` | 所有语言表的并集 |
| 译名表 | `src/data/names/<语言>.toml` | `["原词"]` + `default = "译名"` | `names/entities.toml` |

一条命令生成骨架（值留空，注释与行尾说明从 zh 表原样带过来）：

```bash
python src/tools/text/table_sync.py --init ko
```

之后 zh（或任何一门语言）加了新词，同步其余语言：

```bash
python src/tools/text/table_sync.py --sync
```

`--sync` 只追加缺的键，不碰已有译文，连跑两次不会再追加（幂等）。
随时看覆盖率与待译清单：

```bash
python src/tools/text/table_sync.py --status
python src/tools/text/table_sync.py --check    # 有空占位就返回非零，给 CI 用
```

空占位（`key = ""` / `default = ""`）的语义是「表里有这一行、还没译」：
译文里 `[term:en_business]` 引用它会报「还是空占位」，而不是「没有这个词条」；
死条目校验也跳过空占位，不会把待译行当成拼错的键。所以新语言可以先建表、分批填，
不必等术语全部定完才能编译。

## 5. 翻译

### 方式 A：工作台

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
```

打开「译文编辑」，逐条翻译并保存，写入 `src/translations/ko.toml`。
没翻译的条目自动显示英文，不必一次完成。

### 方式 B：文件交换

维护者提供：

```
src/translations/ko.toml
ui/ko.ini
```

译者用任意 UTF-8 文本编辑器修改后返回；维护者负责校验、构建、打包和测试。

### 译者不能改的东西

- `hash =` 左边的 id；
- `%1`、`%2` 等占位符；
- `@D$...$` 这类脚本变量；
- `<n>`、`<c>`、`<f:...>` 等标签；
- `build/` 下的产物（会被重新生成覆盖）。

**验收**：刷新页面后译文还在；底部计数正常；占位符数量与原文逐条一致。

## 6. 构建字体和语言包

### 6.1 生成字体（映射）

字体随构建一起生成，不需要单独一步；需要单独跑时：

```bash
python src/tools/font/make_noto_fonts.py --lang ko
```

**验收**：`PR2Localization\fonts\` 里有三个静态 TTF（俄语四个），
`font-map.default.ini` 的 `[ko]` 四条映射都能落到真实文件。Noto 是完整字重，
没有“缺字再补”的步骤。

### 6.2 编译语言包

```powershell
.\build.ps1 -Target Packs -Lang ko
```

或使用安装页「编译语言包」。

**产物**：`build/runtime/PR2Localization/packs/ko.txt`，开头带
`# pack-meta alias=…` / `min_runtime=…`。

### 6.3 部署到游戏

```powershell
python src/tools/pack/apply_patch.py --langs ko --game-dir "<游戏目录>"
```

部署只写：

- `PR2Localization\packs\ko.txt`；
- `PR2Localization\packs\locale.default.ini`；
- `PR2Localization\fonts\` 下的实际字体。

`locale.default.ini` 的内容来自构建目录的默认值，不会自动改成 `ko`。已有活动
`PR2Localization\packs\locale.ini` 不会被覆盖，空值也不动。要立即切到新语言，
在命令后加 `--locale ko`，或在 GUI 里明确选择 `ko` 后启动。测试新语言建议用干净
游戏目录。`packs\overrides\` 是本机临时覆盖，部署/升级始终保留。

**验收**：日志显示 `ko.txt` 已复制、字体已平铺；默认文件存在，活动文件没有被改写。

## 7. 启动验收

GOG：

1. 运行 `PR2LocalizationGUI.exe`；
2. 选 `한국어`；
3. 点「以所选语言启动」。

Steam：

1. 先运行 `PR2HostMount.ps1 -Action Mount`；
2. 从 Steam 正常启动，或用 `PR2LocalizationGUI.exe` 临时选语言。

检查：

- 主菜单、设置菜单、标题字体；
- 长文本/按钮是否截断；
- 占位符、换行、数字和日期格式；
- 切换语言后重新启动是否仍选对；
- 「启动原版」是否仍能进英文。

**验收**：界面文字可读、无空白方块、标题字体正常、原版入口正常。

## 8. 出包

```powershell
.\release.ps1 -Version v1.1.0 -Lang ko
```

新语言属于功能增加，通常用 `v1.1.0`。发行包分成 GOG 和 Steam 两个；
GOG 不带 `VERSION.dll`，Steam 带 `Ascaron.Logging-2.6.dll` 和
`PR2HostMount.ps1`。

包内语言设置：

- `PR2Localization\packs\locale.default.ini`：发行默认；
- 包内**不放**活动 `locale.ini`；
- 解压/升级不覆盖用户已有 `locale.ini`（空值也保留）；
- `packs\overrides\` 不进包，部署/升级不删除。

## 9. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 新语言全是空白 | `src/font-map.ini` 没有 `[语言]` 节，字体没映射；补四条映射后重建 |
| 个别字空白 | 映射到了不含该字符的字体；换覆盖更全的静态字重 |
| 语言下拉没有新语言 | `src/translations/ko.toml` 或 `src/packs/ko.toml` 没生成 / 代码不合法 |
| 启动后仍是旧语言 | 目标目录已有活动 `locale.ini`；GUI 选新语言，或换干净目录测试 |
| 字体很大 | 发行版默认不裁剪，直接用完整 Noto |

## 10. 交付给译者前的检查

- 语言代码已确定（如 `ko`）；
- `src/translations/ko.toml` 已生成，条数 3548；
- `src/packs/ko.toml` 已写 `alias` / `min_runtime`；
- 不需要 `ui/ko.ini`：启动器固定一份默认 UI；
- 字体方案已确定（Noto 静态字重 + `font-map.ini` 映射）；
- 支持版本明确为 GOG / Steam 英文版 `1.1.2.3`。

编辑器只作为维护台，不再另发独立译者包；人工译文和 agent 译文都直接改
`src/translations/<语言>.toml`，或经编辑器 HTTP 接口读写。
