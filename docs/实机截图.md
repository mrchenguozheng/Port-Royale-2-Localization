## 口径

- 游戏：GOG 法语版 `1.1.2.42`，全量并集包，12 个语言各 **3590 条**。
- 截图日期：2026-11-23。
- 每张只裁掉左右黑边，缩放为 `1600×1200`，没有修字或改色。
- 「建号」指**剧本模式建号**（选剧本后的姓名、起始城镇、特长、起始资产），不是自由模式。
- 「剧本 1 欢迎」是进入剧本 1 后的第一屏欢迎与剧本目标。
- 归档图在 `docs/assets/screenshots/`，均为 `1600×1200`；未裁边的 `2560×1440` 原图不入库。清单见 `manifest.json`。
- `zh-HK` 与 `zh-TW` 大部分界面文案相同，未单独拍五屏；视觉检查沿用 `zh-TW` 截图，不把它当成 `zh-HK` 的独立实机验证。

## 日语、韩语、波兰语、葡萄牙语、俄语、简体中文与繁体中文实机注记

- 日语在字体修复后补拍，正文用 Noto Sans JP，标题用 Noto Serif JP，标题按发行包规则压缩到 `0.78`；五屏均未出现缺字方块。断行仍由游戏引擎自动处理：`一般情報` 面板在「目標は」之后把 `、` 折到了行首，说明引擎没有执行日文禁则。没有按 `1600×1200` 截图手插 `<n>` 改断行，避免把截图像素当成控件宽度判据。
- 韩语同样在字体修复后补拍，正文用 Noto Sans KR，标题用 Noto Serif KR，五屏均未出现缺字方块；主菜单 `자유 모드 / 시나리오 / 불러오기 / 옵션 / 제작진 / 게임 종료`、欢迎页 `포트 로열 2 환영합니다`、城镇 `카르타헤나`、总督 `총독 이브라힘 가르시아` 全部可读。建号页第一栏为 `이름`、第二栏为 `성`；第二栏的键是 `0xc4f9393f`，已从 `이름` 改为 `성`，归档建号图已替换为修复后画面；城镇信息的关系标题显示 `스페인와(과)의 관계`，这是模板 `%1와(과)` 的占位粒子兜底，不是译文里手写了两种助词。
- 波兰语在字体修复后补拍，正文槽位 `ARIAL.TTF=none` 沿用游戏根目录原版 Arial，标题用 `PR2PlDisplay-Head/Black/Bold`，五屏均未出现缺字方块，`Imię`、`Doświadczenie`、`Wyjście`、`Żadnych`、`Pałac` 等含 `ą ć ę ł ń ś ź ż` 的词均可读。主菜单 `Tryb wolnej gry / Scenariusze / Wczytaj / Opcje / Autorzy gry / Wyjście z gry`，建号 `Imię / Nazwisko / Miasto startowe / Cecha`，欢迎页 `Witaj w grze Port Royale 2`，城镇 `Status miasta / Rozmiar / Produkcja`，总督 `Gubernator Ibrahim Garcia / Dalej`。
- 葡萄牙语（巴西）在现行并集包下补拍，正文与标题均回落原版 Arial，五屏未出现缺字方块；主菜单 `Modo livre / Cenários / Carregar / Opções / Créditos / Sair do jogo`、欢迎页 `Bem-vindo ao Port Royale 2`、城镇 `Cidade do governador espanhol / Status da cidade / Tamanho`、总督 `Governador Ibrahim Garcia / Grumete Manuel Arragon / Continuar` 均可读。建号页第一栏为 `Nome`、第二栏为 `Sobrenome`；法语同屏为 `Prénom / Nom`。该第二栏的键是 `0xc4f9393f`，不是通用 `0x0059b428`；译文已从 `Nome` 改为 `Sobrenome`，归档建号图已替换为修复后画面。
- 俄语在现行并集包下补拍，原版拉丁字体没有西里尔字形，正文用 `PR2CyrBody-Regular`，标题用 `PR2CyrDisplay-Head/Black/Bold`，五屏未出现缺字方块；主菜单 `Режим свободной игры / Сценарии / Загрузить / Настройки / Создатели / Выйти из игры`、欢迎页 `Добро пожаловать в Порт-Рояль 2`、城镇 `Испанский административный центр / Статус города / Размер`、总督 `Губернатор Франко Санчес / Далее` 均可读。
- 简体中文在现行并集包下补拍，正文用 `NotoSansSC-Regular`，标题用 `NotoSerifSC-Black/Bold`，五屏未出现缺字方块；主菜单 `自由模式 / 剧本 / 载入 / 选项 / 制作人员 / 退出游戏`、建号 `名 / 姓 / 起始城镇 / 特长 / 贸易经验`、欢迎页 `欢迎来到 Port Royale 2 / 剧本目标 / 关闭`、城镇 `西班牙总督城 / 城镇的状态 / 规模 / 你与西班牙的关系 / 生产`、总督 `总督易卜拉欣 加西亚 / 见习水手 汉斯 洛兰 / 继续` 均可读。建号页第一栏为 `名`、第二栏为 `姓`，实际值是姓 `洛兰`；该栏实为姓输入框，键是 `0xc4f9393f`（法语同键 `Nom`、日语 `姓`、俄语 `Фамилия`），已从 `姓名` 改为 `姓`，并同步繁体中文（台湾）、`zh-HK` 与 `zh-Hant` 底稿；归档建号图已替换为修复后画面。通用整名标签 `0x0059b428` 保持 `姓名` 不动。
- 繁体中文（台湾）在现行并集包下补拍，正文用 `NotoSansTC-Regular`，标题用 `NotoSerifTC-Black/Bold`，五屏未出现缺字方块；主菜单 `自由模式 / 劇本 / 載入 / 選項 / 製作人員 / 退出遊戲`、欢迎页 `歡迎來到 Port Royale 2`、城镇 `西班牙總督城 / 城鎮的狀態 / 規模`、总督 `總督易卜拉欣 加西亞 / 繼續` 均可读。建号页第一栏为 `名`、第二栏为 `姓`；该栏同样使用 `0xc4f9393f`，已从 `姓名` 改为 `姓`，与简体、`zh-HK` 同步；归档建号图已替换为修复后画面。通用整名标签 `0x0059b428` 未动。
