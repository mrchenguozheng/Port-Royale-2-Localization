# 架构与文件契约

> 本文只记录当前分层、文件契约、当前边界和已知问题。
> 已完成的阶段重构过程、旧路由变化和 C++ 迁移对照见[历史重构记录](历史重构记录.md)。
> 原则：不引入中央语言清单、不拆微服务、不做插件系统。

## 当前分层

```
GOG：PR2LocalizationGUI.exe → PR2Localization.exe → 挂起启动 + 注入 PR2.exe
                                                         │
                                                         ▼
                                              PR2LocalizationCore.dll
                                   hook 游戏取字 + 字体路径重定向 + 读语言包

Steam：PR2.exe → 静态导入 Ascaron.Logging-2.6.dll（宿主代理）
                     → 工作线程加载 PR2LocalizationCore.dll
```

GOG 不能依赖 `PR2.exe` 自然加载 `VERSION.dll`：加载器会优先解析
`C:\Windows\SysWOW64\VERSION.dll`，同目录代理不会进入游戏进程。
Steam 不再使用 `VERSION.dll`；宿主代理由 `PR2HostMount.ps1` 校验原版大小/SHA-256、
备份后替换，还原时从 `Ascaron.Logging-2.6.orig.dll` 写回。

构建侧：

```
compile_pack.py      译文 → PR2Localization/packs/<语言>.txt（含 # pack-meta）
make_noto_fonts.py   Noto 字体 → PR2Localization/fonts/<语言>/*.TTF（带缓存）
make_release.py      组装发行包
apply_patch.py       本机构建 + 部署
pr2ctl               编辑器安装/部署后端
src/editor/server.py 编辑器 HTTP 服务；api/ 下按域分模块
```

## 原生程序与构建布局

五个原生程序在 Rust workspace `src\injector-rs\` 中：

| crate | 产物 | 职责 |
|---|---|---|
| `pr2_common` | 无（静态库） | 字体名与完整性、locale、运行时版本等共享逻辑 |
| `pr2_proxy` | `PR2LocalizationProxy.dll`（旧 `VERSION.dll` 代理，Steam 发行包不再使用） | 转发 version API；工作线程加载 `PR2LocalizationCore.dll` |
| `pr2_text_source` | `PR2LocalizationCore.dll` | 取字 hook、字体路径重定向、语言包与 overrides 读取、A2dLib 延迟重试 |
| `pr2_launcher` | `PR2Localization.exe` | GOG 正式启动器：备份字体、解析字体目录、注入 DLL、启动游戏 |
| `pr2_launcher_gui` | `PR2LocalizationGUI.exe` | 语言选择、状态显示、启动和结束进程 |

Steam 宿主代理 `Ascaron.Logging-2.6.dll` 不在 Rust workspace，源码在 `src\host-proxy\`，
由 `src\host-proxy\build.ps1`（MSVC x86）编译，`build_injector.ps1` 会调用它。

- `VERSION.dll` 旧代理不是系统 DLL 副本；Steam 发行包已改用宿主 `Ascaron.Logging-2.6.dll`；
- `PR2LocalizationCore` 先读包，再起 250ms 重试线程等 `A2dLib`；`g_pStringMgr` 优先取导出；
- Steam 自然启动时没有 `PR2_FONT_DIR`，DLL 会回退到 `PR2Localization\fonts\<locale>\` 存在的那一套；
  GOG 由启动器设置字体目录；

- workspace 的 `.cargo\config.toml` 固定 `i686-pc-windows-msvc`，对应游戏的 32 位进程；
- `build_injector.ps1` 运行 `cargo build --release --locked`，把产物和 `PR2Localization\ui\*.ini` 复制到 `build\runtime\`；
- GUI 用 `#![windows_subsystem = "windows"]` 编译，双击不弹控制台；
- 旧 C++ 实现已移出工作树；当前文档不再保留它的文件级对照，历史信息见归档记录。

## 文件契约

| 路径 | 约定 |
|---|---|
| `PR2Localization/packs/<语言>.txt` | `hash = text`；开头可带 `# pack-meta alias=…` / `gui=…`；游戏忽略 `#` |
| `PR2Localization/packs/locale.ini` | `language=<代码>`；游戏默认语言，也是 GUI 的唯一语言状态 |
| `PR2Localization/fonts/<语言>/` | 四个 TTF，文件名固定；只有字体，不放说明文件 |
| `PR2Localization/ui/<语言>.ini` | GUI 界面翻译；由语言包的 `gui` 元数据选择 |
| `PR2_PACK_LANG` | 本次进程的语言覆盖；`--lang` 设置，不写文件 |
| `PR2_FONT_DIR` | 本次进程的字体子目录；字体完整时设置 |

## 当前边界

| 风险 | 处理 | 剩余边界 |
|---|---|---|
| 字体名/完整性检查分散 | `pr2_common` 统一 launcher/GUI | Python 构建按输出文件名写，未共享同一份常量 |
| locale 语义分叉 | `pr2_common` 统一读；GUI 唯一写者 | Steam 自然启动不经过启动器，字体备份/恢复不执行 |
| 构建入口多 | `build_artifacts.py` 统一语言包和字体 | 运行时复制仍按 release/deploy 各自处理 |
| 文件格式隐式 | `min_runtime` 增加整数版本检查 | 仍是极简格式，没有 schema/校验器 |
| 多语言包覆盖运行时 | `min_runtime` + `RUNTIME-VERSION` | Steam 自然启动绕过启动器侧检查；不做自动更新 |

## 设计原则

- 先消灭“同一规则写两份”，不要先抽象；
- 共享代码优先用一个小头文件/小模块，不建框架；
- 只保留一个语言状态来源：`locale.ini`；
- 语言包继续自描述，不做中央清单；
- 每一步必须能单独构建、测试、回滚。

## 启动器界面

`PR2LocalizationGUI` 的界面为单列分层布局，窗口基准尺寸 `560x400`（96 DPI）：

| 区域 | 基准矩形 | 说明 |
|---|---|---|
| 标题 | `24,16,496,34` | Segoe UI 16pt 粗体，深蓝色 |
| 副标题 | `24,54,496,20` | 9pt 灰色，文案键 `subtitle` |
| 分隔线 | `24,82,496,2` | `SS_ETCHEDHORZ` |
| 语言包标签 | `24,94,496,20` | 10pt |
| 语言包下拉框 | `24,116,496,30` | 实际由系统组合框字体决定高度 |
| 主操作按钮行 | `24,158` | 「以所选语言启动」`220x42`，默认按钮；「启动原版」`160x42`；「刷新」`90x42` |
| 结束进程按钮 | `304,214,216,34` | 右对齐，保留确认框 |
| 状态框 | `24,262,496,52` | `WS_EX_CLIENTEDGE`，白底 |
| 底部提示 | `24,322,496,36` | 文案键 `hint.footer`，可两行 |

- 启动时调用 `SetProcessDpiAwarenessContext(PER_MONITOR_AWARE_V2)`，用系统 DPI 对窗口、控件矩形和字号统一缩放；
- 字体由 `CreateFontW` 创建 Segoe UI，标题 16pt 粗体、普通控件 10pt、状态/提示 9pt；窗口销毁时 `DeleteObject` 释放三个字体句柄；
- `WM_CTLCOLORSTATIC` 设置标题、副标题、提示和状态框颜色；
- `PR2Localization/ui/zh.ini`、`PR2Localization/ui/en.ini`、`PR2Localization/ui/ja.ini` 增加 `subtitle` 与 `hint.footer`，缺键时回退到 `strings.rs` 的 `BUILTIN`。

验证记录：在游戏目录实测窗口 `560x400`，全部子控件落在客户区内且互不重叠；中文和日文界面切换正常，最长提示文本均在控件内完整显示。

## 已知问题记录：退出黑屏/白屏

状态：**未修复**，仅记录现象；`PR2LocalizationGUI` 的「结束游戏进程」只是兜底，不视为修复。

现象：

- 完成第一个教程战役后点击「退出游戏」，`PR2.exe` 进程不退出，窗口黑屏或白屏残留；
- 有时同时弹出 MSVC Runtime Error 对话框，Program 指向 `PR2.exe`；
- 多次运行中，直接启动原版英文、用 `PR2LocalizationGUI` 启动原版、启动中文版都出现过；单次「原版正常」不能作为根因结论；
- 当前没有该退出路径的崩溃 dump，根因未定位。

## 验证门槛

每一步至少：

1. `src\build_injector.ps1` 成功；
2. `python src\tools\check.py` 通过；
3. 启动 GUI 能看到语言列表；
4. 直接运行 `PR2Localization.exe` 能按 `locale.ini` 启动；
5. 缺字体时能回退根目录原版字体，不崩溃。
