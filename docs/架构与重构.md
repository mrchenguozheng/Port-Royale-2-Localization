# 架构与文件契约

> 本文只记录当前分层、文件契约、当前边界和已知问题。
> 已完成的阶段重构过程、旧路由变化和 C++ 迁移对照见[历史重构记录](历史重构记录.md)。
> 原则：不引入中央语言清单、不拆微服务、不做插件系统。

## 当前分层

```
PR2LocalizationGUI.exe → PR2Localization.exe → 确保宿主 DLL 已挂载（pr2_common::host）
                                                         │
                                                         ▼
                                   直启 PR2.exe（GOG 版） / steam://rungameid/12470（Steam 版）
                                    └ PR2.exe 静态导入 Ascaron.Logging-2.6.dll（宿主代理）
                                         → 工作线程加载 PR2LocalizationCore.dll
                                   hook 游戏取字 + 字体路径重定向 + 读语言包

回退（根目录没有宿主 DLL，或 --inject）：挂起启动 PR2.exe → 远程注入 PR2LocalizationCore.dll
```

两个入口都是 `PR2Localization.exe`：它先看根目录有没有宿主 DLL（`pr2_common::has_host_dll`），
有就挂载再启动、没有就退回注入；`detect_edition`（`goggame-*` 标记优先，其次 Steam 库路径
`...\steamapps\common\...` 与 `steam_appid.txt`，最后宿主 DLL）只决定**由谁拉起 `PR2.exe`**：
GOG 直启，Steam 交给客户端（`steam://rungameid/12470`）。本地化能力与版别无关；
`--lang` 只在 GOG 版可用——Steam 拉起的进程不是启动器的子进程，
`PR2_PACK_LANG` / `PR2_FONT_DIR` 传不过去，换语言要改 `locale.ini`。
`--restore` 只做还原、不启动游戏；GUI 上的「还原原版」两版都调它，不按版别早退。

不要再用 `VERSION.dll`：它属于 Windows 的 KnownDLLs，加载器会先解析
`C:\Windows\SysWOW64\VERSION.dll`，同目录代理永远不进游戏进程。
宿主代理由 `pr2_common::host` 在启动器进程内校验原版大小/SHA-256、
备份后以临时文件换名替换（`Ascaron.Logging-2.6.dll.new` → 校验 → 换名），还原时把
`Ascaron.Logging-2.6.orig.dll` 用同一套动作写回。启动器在启动前直接调用，玩家不需要先
手工跑任何脚本；运行期不依赖 PowerShell。包内代理放在 `PR2Localization\host\`，
解压不会覆盖根目录原版。

构建侧：

```
compile_pack.py      译文 → PR2Localization/packs/<语言>.txt（含 # pack-meta 与条目数/摘要）
pack_delta.py        相对上一次 release-v* 统计译文条目增改删（出包时调用）
make_noto_fonts.py   Noto 字体 → 暂存目录；make_release 平铺到 PR2Localization/fonts/
make_release.py      组装发行包
apply_patch.py       本机构建 + 部署
pr2ctl               安装/部署/启动后端
```

## 原生程序与构建布局

六个原生程序在 Rust workspace `src\injector-rs\` 中：

| crate | 产物 | 职责 |
|---|---|---|
| `pr2_common` | 无（静态库） | 字体名与完整性、locale、运行时版本、日志体积上限（`log_util`）等共享逻辑 |
| `pr2_proxy` | `PR2LocalizationProxy.dll`（旧 `VERSION.dll` 代理，发行包不再使用） | 转发 version API；工作线程加载 `PR2LocalizationCore.dll` |
| `pr2_text_source` | `PR2LocalizationCore.dll` | 取字 hook、字体路径重定向、语言包与 overrides 读取、A2dLib 延迟重试 |
| `pr2_launcher` | `PR2Localization.exe` | 统一启动器：备份字体、解析字体目录、挂载宿主代理后按版别拉起游戏（GOG 直启 / Steam `steam://`），回退注入 |
| `pr2_launcher_gui` | `PR2LocalizationGUI.exe` | 语言选择、状态显示、启动和结束进程 |
| `pr2_host_proxy` | `Ascaron.Logging-2.6.dll`（部署名；Cargo 产物为 `pr2_host_proxy.dll`） | 宿主代理：转发 `Log`，等待 `A2dLib` 后加载 Core；两版一致使用 |

`build_injector.ps1` 用 `cargo build --release --locked` 一次构建全部 Rust 产物，再按部署名复制到 `build\runtime\`。

- `VERSION.dll` 旧代理不是系统 DLL 副本；发行包已改用宿主 `Ascaron.Logging-2.6.dll`；
- `PR2LocalizationCore` 先读包，再起 250ms 重试线程等 `A2dLib`；`g_pStringMgr` 优先取导出；
- 绕过启动器直接双击 `PR2.exe` 时没有 `PR2_FONT_DIR`，DLL 会回退到 `PR2Localization\fonts\`
  的四份平铺字体，两版一致；

- workspace 的 `.cargo\config.toml` 固定 `i686-pc-windows-msvc`，对应游戏的 32 位进程；
- `build_injector.ps1` 运行 `cargo build --release --locked`，把产物和 `PR2Localization\ui\*.ini` 复制到 `build\runtime\`；
- GUI 用 `#![windows_subsystem = "windows"]` 编译，双击不弹控制台；
- 旧 C++ 实现已移出工作树；当前文档不再保留它的文件级对照，历史信息见归档记录。

## 文件契约

| 路径 | 约定 |
|---|---|
| `PR2Localization/packs/<语言>.txt` | `hash = text`；开头可带 `# pack-meta alias=` / `min_runtime=` / `version=` / `entries=` / `untranslated=` / `scope=` / `digest=`；游戏忽略 `#` |
| `PR2Localization/packs/locale.default.ini` | 发行默认 `language=<代码>`；活动文件不存在时生效 |
| `PR2Localization/packs/locale.ini` | 用户选择 `language=<代码>`；存在即优先（空值也保留），GUI 写这里，部署不覆盖 |
| `PR2Localization/packs/overrides/<语言>.txt` | 玩家自己的本机覆盖位（发行包里只有空目录）；同 hash 覆盖主包，不进包、不改包头、界面不统计 |
| `manifest.json` | 仅发行包根目录；目标 exe、参考原文、翻译方式、逐文件 SHA-256；运行时忽略 |
| `src/packs/<语言>.toml` | 构建元数据；`alias` / `min_runtime` 进语言包，`tags` / `review_status` / `source_lang` 只进清单 |
| `PR2Localization/fonts/` | 实际字体文件和默认映射 `font-map.default.ini`；用户 `font-map.ini` 按项覆盖默认，四个游戏逻辑名由映射指定，不按语言子目录，不放说明文件 |
| `PR2Localization/ui/ui.default.ini` | 启动器默认界面；固定一份，不再跟语言包切换 |
| `PR2_PACK_LANG` | 本次进程的语言覆盖；`--lang` 设置，不写文件 |
| `PR2_FONT_DIR` | 本次进程的字体子目录；字体完整时设置 |

## 当前边界

| 风险 | 处理 | 剩余边界 |
|---|---|---|
| 字体名/完整性检查分散 | `pr2_common` 统一 launcher/GUI | Python 构建按输出文件名写，未共享同一份常量 |
| locale 语义分叉 | `pr2_common` 统一读；GUI 唯一写者 | 绕过启动器直接双击 `PR2.exe` 时字体备份/恢复不执行；部署只写默认文件 |
| 构建入口多 | `build_artifacts.py` 统一语言包和字体 | 运行时复制仍按 release/deploy 各自处理 |
| 文件格式隐式 | `min_runtime` 增加整数版本检查 | 仍是极简格式，没有 schema/校验器 |
| 多语言包覆盖运行时 | `min_runtime` + `RUNTIME-VERSION` | 绕过启动器直接双击 `PR2.exe` 会跳过启动器侧检查；不做自动更新 |

## 设计原则

- 先消灭“同一规则写两份”，不要先抽象；
- 共享代码优先用一个小头文件/小模块，不建框架；
- 只保留一个语言状态来源：用户活动 `locale.ini`，缺失时才读发行默认 `locale.default.ini`；
- 语言包继续自描述，不做中央清单；
- 每一步必须能单独构建、测试、回滚。

## 启动器界面

`PR2LocalizationGUI` 的界面为单列分层布局，窗口基准尺寸 `560x400`（96 DPI）：

| 区域 | 基准矩形 | 说明 |
|---|---|---|
| 标题 | `24,16,496,34` | Segoe UI 16pt 粗体，深蓝色 |
| 副标题 | `24,54,496,20` | 9pt 灰色，文案键 `subtitle` |
| 分隔线 | `24,82,496,2` | `SS_ETCHEDHORZ` |
| 语言包标签 | `24,94,496,20` | 10pt |
| 语言包下拉框 | `24,116,496,30` | 实际由系统组合框字体决定高度 |
| 主操作按钮行 | `24,158` | 「以所选语言启动」`220x42`，默认按钮；「启动原版」`160x42`；「刷新」`90x42` |
| 结束进程按钮 | `304,214,216,34` | 右对齐，保留确认框 |
| 状态框 | `24,262,496,52` | `WS_EX_CLIENTEDGE`，白底 |
| 底部提示 | `24,322,496,36` | 文案键 `hint.footer`，可两行 |

- 启动时调用 `SetProcessDpiAwarenessContext(PER_MONITOR_AWARE_V2)`，用系统 DPI 对窗口、控件矩形和字号统一缩放；
- 字体由 `CreateFontW` 创建 Segoe UI，标题 16pt 粗体、普通控件 10pt、状态/提示 9pt；窗口销毁时 `DeleteObject` 释放三个字体句柄；
- `WM_CTLCOLORSTATIC` 设置标题、副标题、提示和状态框颜色；
- 启动器只读 `PR2Localization/ui/ui.default.ini`，再叠加可选 `ui.ini`；缺键回退 `strings.rs` 的 `BUILTIN`。不再按语言包或 Windows UI 语言切 UI。

验证记录：在游戏目录实测窗口 `560x400`，全部子控件落在客户区内且互不重叠；最长提示文本均在控件内完整显示。启动器界面现固定为默认 UI，不再验证语言切换。

## 已知问题记录：退出黑屏/白屏

状态：**根因已定位在显卡驱动层，本地化侧不修也修不了**，仅记录现象与结论；`PR2LocalizationGUI` 的「结束游戏进程」只是兜底，不视为修复。

现象：

- 完成第一个教程战役后点击「退出游戏」，`PR2.exe` 进程不退出，窗口黑屏或白屏残留；
- 有时同时弹出 MSVC Runtime Error 对话框，Program 指向 `PR2.exe`；
- 多次运行中，直接启动原版英文、用 `PR2LocalizationGUI` 启动原版、启动中文版都出现过。

定位结论（2026-11-22，32 位 PowerShell 只读探针，未挂调试器）：

- 卡住时 `PR2.exe` 停在 `igd9trinity32.dll`（Intel 核显 UMD）内部的设备销毁等待，服从 `ddraw.dll` 的全屏设备销毁路径；
- 纯原版英文（游戏目录没有任何本地化文件）同样复现，说明与本地化 DLL、语言包、字体都无关；
- GOG 官方支持页也把 Intel HD 全屏退出卡死单列为已知问题。

因此这条不是本仓库能修的问题：本地化侧不改引擎退出流程，也不接管 DDraw 设备销毁。文档与发行说明只如实记录现象和兜底入口，不写成「已修复」。

## 验证门槛

每一步至少：

1. `src\build_injector.ps1` 成功；
2. `python src\tools\check.py` 通过；
3. 启动 GUI 能看到语言列表；
4. 直接运行 `PR2Localization.exe` 能按 `locale.ini`（缺失时按 `locale.default.ini`）启动；
5. 缺字体时能回退根目录原版字体，不崩溃。
