# 架构与重构计划

> 这份文档记录当前分层、已知风险，以及只做必要改动的重构顺序。
> 原则：不引入中央语言清单、不拆微服务、不做插件系统。

## 当前分层

```
PR2LauncherGUI.exe   选语言、显示别名、检查字体、写回 locale.ini
        │
        ▼
PR2Launcher.exe      备份字体、判断字体目录、注入 DLL、启动 PR2.exe
        │
        ▼
PR2TextSource.dll    hook 游戏取字 + 字体路径重定向 + 读语言包
```

构建侧：

```
compile_pack.py      译文 → PR2Packs/<语言>.txt（含 # pack-meta）
make_noto_fonts.py   Noto 字体 → fonts/<语言>/*.TTF（带缓存）
make_release.py      组装发行包
apply_patch.py       本机构建 + 部署
pr2ctl               编辑器安装/部署后端
```

## 文件契约

| 路径 | 约定 |
|---|---|
| `PR2Packs/<语言>.txt` | `hash = text`；开头可带 `# pack-meta alias=…` / `gui=…`；游戏忽略 `#` |
| `PR2Packs/locale.ini` | `language=<代码>`；游戏默认语言，也是 GUI 的唯一语言状态 |
| `fonts/<语言>/` | 四个 TTF，文件名固定；只有字体，不放说明文件 |
| `ui/<语言>.ini` | GUI 界面翻译；由语言包的 `gui` 元数据选择 |
| `PR2_PACK_LANG` | 本次进程的语言覆盖；`--lang` 设置，不写文件 |
| `PR2_FONT_DIR` | 本次进程的字体子目录；字体完整时设置 |

## 已知风险

1. **字体规则重复**
   - 四个字体名、完整性检查分散在 launcher、GUI、Python 构建脚本；
   - 改字体或目录结构时容易漏一处。

2. **locale 语义分叉**
   - GUI 启动成功后写 `locale.ini`；
   - CLI `--lang` 只覆盖本次；
   - 直接启动 CLI 读 `locale.ini`；
   - 这些规则目前只存在于代码和口头约定里。

3. **构建入口多**
   - `compile_pack`、`make_noto_fonts`、`subset_fonts`、`make_release`、
     `apply_patch`、`pr2ctl`、editor server 各自拼步骤；
   - 缓存和产物判断容易不一致。

4. **隐式文件格式**
   - `# pack-meta`、`ui/*.ini`、`locale.ini` 都是极简格式；
   - 没有 schema、版本号、统一解析器。

5. **多语言包覆盖运行时**
   - 每个语言 zip 都带 exe/dll/ui；
   - 先装中文再装日文可能把运行时换成旧版本；
   - 目前没有版本检查。

## 重构原则

- 先消灭“同一规则写两份”，不要先抽象；
- 共享代码优先用一个小头文件/小模块，不建框架；
- 只保留一个语言状态来源：`locale.ini`；
- 语言包继续自描述，不做中央清单；
- 每一步必须能单独构建、测试、回滚。

## 分步计划

### 第 1 步：共享字体契约

- 新增 `src/injector/pr2_fonts.h`：
  - 四个字体名；
  - `fonts/<语言>/` 完整性检查。
- launcher、GUI 改为调用同一实现；
- launcher 的原版字体备份也复用字体名；
- 构建 + 字体缺失/完整路径验证。

状态：完成。`pr2_fonts.h` 统一字体名和完整性检查；构建、缺字体回退验证通过。

### 第 2 步：locale 统一

- 抽一个最小的 locale 读取/写回函数；
- 明确：只有 GUI 在启动成功后写；CLI 只读；
- GUI 不再维护第二份语言状态。

状态：待开始

### 第 3 步：构建产物入口统一

- 让 `make_release`、`apply_patch`、`pr2ctl` 共用同一个
  “构建语言包 + 字体 + 运行时”的函数；
- 不重写现有工具，只把重复的编排收口。

状态：待开始

### 第 4 步：运行时版本检查

- 发行包写入运行时版本；
- DLL/启动器发现语言包要求的最低版本不匹配时明确报错；
- 不做自动更新。

状态：待开始

## 验证门槛

每一步至少：

1. `src\build_injector.bat` 成功；
2. `python src\tools\check.py` 通过；
3. 启动 GUI 能看到语言列表；
4. 直接运行 `PR2Launcher.exe` 能按 `locale.ini` 启动；
5. 缺字体时能回退根目录原版字体，不崩溃。
