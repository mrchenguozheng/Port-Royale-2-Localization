# 架构与重构计划

> 这份文档记录当前分层、已知风险，以及只做必要改动的重构顺序。
> 原则：不引入中央语言清单、不拆微服务、不做插件系统。

## 当前分层

```
PR2LauncherGUI.exe   选语言、显示别名、检查字体、写回 locale.ini
        │
        ▼
PR2Launcher.exe      备份字体、判断字体目录、注入 DLL、启动 PR2.exe
        │
        ▼
PR2TextSource.dll    hook 游戏取字 + 字体路径重定向 + 读语言包
```

构建侧：

```
compile_pack.py      译文 → PR2Packs/<语言>.txt（含 # pack-meta）
make_noto_fonts.py   Noto 字体 → fonts/<语言>/*.TTF（带缓存）
make_release.py      组装发行包
apply_patch.py       本机构建 + 部署
pr2ctl               编辑器安装/部署后端
src/editor/server.py 编辑器 HTTP 服务；api/ 下按域分模块
```

## 文件契约

| 路径 | 约定 |
|---|---|
| `PR2Packs/<语言>.txt` | `hash = text`；开头可带 `# pack-meta alias=…` / `gui=…`；游戏忽略 `#` |
| `PR2Packs/locale.ini` | `language=<代码>`；游戏默认语言，也是 GUI 的唯一语言状态 |
| `fonts/<语言>/` | 四个 TTF，文件名固定；只有字体，不放说明文件 |
| `ui/<语言>.ini` | GUI 界面翻译；由语言包的 `gui` 元数据选择 |
| `PR2_PACK_LANG` | 本次进程的语言覆盖；`--lang` 设置，不写文件 |
| `PR2_FONT_DIR` | 本次进程的字体子目录；字体完整时设置 |

## 重构前风险与处理

| 重构前风险 | 处理 | 剩余边界 |
|---|---|---|
| 字体名/完整性检查分散 | `pr2_fonts.h` 统一 launcher/GUI | Python 构建按输出文件名写，未共享 C 头 |
| locale 语义分叉 | `pr2_locale.h` 统一读；GUI 唯一写者 | 直接运行 `PR2.exe` 不经过启动器 |
| 构建入口多 | `build_artifacts.py` 统一语言包和字体 | 运行时复制仍按 release/deploy 各自处理 |
| 文件格式隐式 | `min_runtime` 增加整数版本检查 | 仍是极简格式，没有 schema/校验器 |
| 多语言包覆盖运行时 | `min_runtime` + `RUNTIME-VERSION` | 直接 `PR2.exe` 绕过检查；不做自动更新 |

## 重构原则

- 先消灭“同一规则写两份”，不要先抽象；
- 共享代码优先用一个小头文件/小模块，不建框架；
- 只保留一个语言状态来源：`locale.ini`；
- 语言包继续自描述，不做中央清单；
- 每一步必须能单独构建、测试、回滚。

## 分步计划

### 第 1 步：共享字体契约

- 新增 `src/injector/pr2_fonts.h`：
  - 四个字体名；
  - `fonts/<语言>/` 完整性检查。
- launcher、GUI 改为调用同一实现；
- launcher 的原版字体备份也复用字体名；
- 构建 + 字体缺失/完整路径验证。

状态：完成。`pr2_fonts.h` 统一字体名和完整性检查；构建、缺字体回退验证通过。

### 第 2 步：locale 统一

- 抽一个最小的 locale 读取/写回函数；
- 明确：只有 GUI 在启动成功后写；CLI 只读；
- GUI 不再维护第二份语言状态。

状态：完成。`pr2_locale.h` 统一读取/写回；GUI 仍保持唯一写者；直接启动 CLI 和 GUI 启动后写回均验证通过。

### 第 3 步：构建产物入口统一

- 让 `make_release`、`apply_patch`、`pr2ctl` 共用同一个
  “构建语言包 + 字体 + 运行时”的函数；
- 不重写现有工具，只把重复的编排收口。

状态：完成。`pack/build_artifacts.py` 统一语言包编译和字体生成：
- 发行：`noto`，输出 `stage/fonts/<语言>/`；
- 本机：`stitch`，输出 `build/runtime/fonts/<语言>/`。
运行时文件复制仍由 `make_release` / `pr2ctl` 按各自目标处理，不强行合并。

### 第 4 步：运行时版本检查

- 发行包写入运行时版本；
- DLL/启动器发现语言包要求的最低版本不匹配时明确报错；
- 不做自动更新。

状态：完成。语言包写入 `min_runtime`，GUI/启动器版本不足时拒绝启动；
发行包写 `RUNTIME-VERSION`。只做整数版本，不做自动更新。

### 第 5 步：编辑器服务分域

原 `src/editor/server.py` 一个文件 1424 行，同时装数据读写、校验、语境推断、
语言管理、构建/字体/启动任务和 HTTP 分发。按域拆开后：

| 文件 | 行数 | 职责 |
|---|---|---|
| `src/editor/server.py` | 509 | 常量、`health_info`/`server_instances`、4 条元路由、`Handler`、启动与 CLI |
| `src/editor/api/store.py` | 116 | 条目读取/写回与按 mtime 的缓存 |
| `src/editor/api/request.py` | 25 | `Req`：一次请求的 query/body 与两个发送出口 |
| `src/editor/api/translate.py` | 540 | 译文域：校验、语境、规则轨迹、占位符、筛选、单条写回/补丁（14 条路由） |
| `src/editor/api/langs.py` | 334 | 语言域：语言列表/进度/新建语言、占位符含义、术语例外（7 条路由） |
| `src/editor/api/install.py` | 366 | 安装域：游戏目录、构建/部署/启动任务、字体（16 条路由） |

- 路由改成表驱动：各模块导出 `ROUTES = {(方法, 路径): 函数}`，server 合并成
  `ROUTER`；`get_api`/`post_api` 只查表、构造 `Req` 后调用，分支逻辑不再写在
  Handler 里；
- 换数据根只有一条路径：`set_data_root` 调 `T.set_src`（译文/原文）、
  `ST._ALL_CACHE`（条目缓存）、`LG.set_root`（两份 glossary 与缓存）、
  `IN.set_presets_dir`（字体 presets）；server 不再持有第二份路径表；
- 契约不变：路径、查询参数、请求体、返回 JSON、状态码、访问日志都保持原样；
- 已知死路由：`GET /api/rule-hits` 分支调用的 `rule_hits()` 在仓库里从未定义
  （请求必 500，前端 `app.ts` 也从不调用），随拆分删除，路由总数 47→46；
- 同类清理：前端「语境推断」弹窗（`openCtx`）从未接线，行内语境只用
  `/api/context-batch`；弹窗与 `GET /api/context` 一并删除，路由 46→45；
- 再按前端调用面核对：前端只用单条 `POST /api/placeholder-meaning` 和
  `/api/entry-info`，复数的 `GET`/`POST /api/placeholder-meanings` 没有调用方；
  `POST /api/font/stitch` 对应的字体缝合实际走 CLI `subset_fonts.py`，安装页只用
  `font-status` / `font/export`。这三条删除，路由 45→42；
- 单产品之后 `POST /api/save` 也没有用户：前端只走 `/api/patch`（多行、按现有
  文件顺序写、逐条校验占位符），`save_all` 的整表顺序核对只对“持有完整 3548
  条”的调用方有意义。接口与 `save_all` 一起删除，路由 42→41；
- 独立译者包删除后，`server.py` 的 `TRANSLATOR`/`TRANSLATOR_LANG` 常量、
  三处 `if TRANSLATOR` 分支、`--translator`/`--translator-lang` 与对应 `global`
  赋值已无消费方，一并删除（server 539→509）；
- 清理时补回 `api/translate.py` 的 `_ATTN_CACHE = {}`：上一轮删 server 常量时
  漏了定义，`filter=attention` 会直接 500；同时删掉无人使用的 `PH_MEAN`；
- agent 侧的 41 条路由契约单独成文：[编辑器接口契约](agent-api.md)；
- 阶段 1 的 `--data` / `--presets-dir` 保留，测试用临时数据根跑 POST。

状态：完成。`tests/test_server_api.py` 5 项（21 条 GET 全 200、POST 写临时根、
真实仓库文件 SHA 不变）；`check.py` 46 项；`engine_text --check` zh/ja 均「一致」；
编译包 SHA 与重构前一致（zh `2B209420…920F`、ja `17517FB6…FAB`）。

## 验证门槛

每一步至少：

1. `src\build_injector.bat` 成功；
2. `python src\tools\check.py` 通过；
3. 启动 GUI 能看到语言列表；
4. 直接运行 `PR2Launcher.exe` 能按 `locale.ini` 启动；
5. 缺字体时能回退根目录原版字体，不崩溃。
