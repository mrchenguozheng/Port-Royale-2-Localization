# 文本变量码表（`@码$变量名$`）

引擎文本里的动态值都写成 `@格式码$变量名$`，例如 `@A$USER$`（玩家名）、`@a$Amount$`（数量）、`@T$Town$`（城镇名）。这一份是从 `en.gog_1.1.2.3` 的 **770 处引用**（67 个变量名、19 个码）反推的表。

结构：`@` + 单字母格式码 + `$` + 变量名 + `$`，尾 `$` 必需（770 处零例外）。**码是类型标签，不是文本变换**——同字母的大小写对应不同类型（`G` 货物 / `g` 金币、`N` 人名 / `n` 国家），详见 09 卷 67.9。

> 本文件由 `src/tools/text/var_codes.py --sync` 生成，**不要手改**；改含义改 `glossary/variable_codes.toml` 后重跑。`src/tools/docs_check.py` 会比对本文件与重新生成的结果，不一致即红。

## 已知例外（提示，不是豁免）

- `0xca4930dc` 的 `@A$Amount$`：英文原文起、六语照抄；A 与 a 对数字是空操作（67.9），但引擎是否区分这个字母仍无证据，等实机对照这一行显示数字还是字面量（67.8）

`--check` 每次都会把这几处打印成提示，不计违规；只有登记的键里真的找不到这一处时才算「例外过期」。这样它不会像静默豁免那样烂在代码里。

## 怎么用

```
python src/tools/text/var_codes.py --table            # 码表
python src/tools/text/var_codes.py --vars --code g     # 某码的变量
python src/tools/text/var_codes.py --token "@A$USER$"  # 解释单个引用
python src/tools/text/var_codes.py --check            # 校验全库引用
python src/tools/text/var_codes.py --sync             # 重算统计、重写本文件
```

`--check` 扫 `src/orig/en.gog_1.1.2.3.toml` 加六语译文，共 5396 处引用；判据是「码与变量名的配对」，码或名未登记、或该名没登记这个码都算违规。

译文里只照抄原文的 `@码$名$`（大小写不动）；要判断「这个码配这个名对不对」，用 `--check`，别用肉眼。`PirateGold` 在英文原文里没有引用，只在六语译文里出现（2004 竞赛文本的标识符行补译），所以它的原文次数是 0。
