# 文本变量码表（`@码$变量名$`）

引擎文本里的动态值都写成 `@格式码$变量名$`，例如 `@A$USER$`（玩家名）、`@a$Amount$`（数量）、`@T$Town$`（城镇名）。这一份是从 `en.gog_1.1.2.3` 的 **770 处引用**（67 个变量名、19 个码）反推的表，机器可读版在 `glossary/variable_codes.toml`。

结构：`@` + 单字母格式码 + `$` + 变量名 + `$`，尾 `$` 必需（770 处零例外）。**码是类型标签，不是文本变换**——同字母的大小写对应不同类型（`G` 货物 / `g` 金币、`N` 人名 / `n` 国家），详见 09 卷 67.9。

## 怎么用

```
python src/tools/text/var_codes.py --table            # 码表
python src/tools/text/var_codes.py --vars             # 变量清单
python src/tools/text/var_codes.py --token "@A$USER$" # 解释单个引用
python src/tools/text/var_codes.py --check            # 校验全库引用是否都在表里
```

`--check` 扫 `src/orig/en.gog_1.1.2.3.toml` 加六语译文，共 5396 处引用；判据是「码与变量名的配对」，码或名未登记、或该名没登记这个码都算违规。

译文里只照抄原文的 `@码$名$`（大小写不动）；要判断「这个码配这个名对不对」，用 `--check`，别用肉眼。已知例外：`0xca4930dc` 的 `@A$Amount$` 是全库唯一一处 `A` 配非 `USER` 变量，原文如此、暂随原文（09 卷 67.8）。

`PirateGold` 在英文原文里没有引用，只在六语译文里出现（2004 竞赛文本的标识符行补译），所以它的原文次数是 0。
