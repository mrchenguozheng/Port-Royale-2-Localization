# 中文补空格：做法与边界

给中文按词插空格，是为了让**只按空格断行**的引擎能在词边界换行；
不插空格时，一长串汉字会被当成一个超宽 token，超出控件就**整条丢弃**
（不是截断），屏幕上是一片空白。

这份文档讲现在的实现，以及**不做**什么。

## 分层

```
src/translations/zh.toml        干净译文：不带任何补空格，唯一手改层，入库
        │  src/tools/text/engine_text.py（排版规则总入口）
        ▼
build/preview/engine_text/zh.toml       引擎文本：构建产物，不进仓库，可随时重建
        │  src/tools/pack/compile_pack.py（占位符校验）
        ▼
build/runtime/PR2Packs/zh.txt           语言包
```

补空格是**构建期**的一步，走 `lang_rules` 的三段式接口：语言声明 `spec()`
（标点 `Punctuation` / 分词器 `Segmenter` / 补空格策略 `Spacing`，见
`lang_rules/spec.py`），执行器是 `spec.build_texts()`，中文的三段分别落在：

1. `lang_rules/zh.normalize()`（`Punctuation`）：半角标点全角化、标点后空格；
2. `zh_pipeline.pre_space()`（`Spacing.before`）：连词 `fix_conj()` →
   人名 `find_names()/pad_names()`（引号里的船名、书名不动）→
   `space_tokens()`：数字、破折号、省略号、`<n><n>` 两侧补空格
   （以前 `space_years` / `space_dash` / `space_ellipsis` / `space_before_double_break`
   四个名字其实是同一件事，已合并成这一个函数）；
3. `zh_space.spaced()`（`Spacing(mode="group")`）：按词成组补空格，最后连续空格归一。

中文特有的三步之所以留在 `zh_pipeline.py` 而不是 `base.py`：它们靠「旁边是不是汉字」
判断，日文/其它语言用不上，放共用层只会让共用层长出一堆 CJK 判断。

## 成组标准：字数，不是像素

**每组最多 10 个汉字**（`zh_space.MAX_CHARS`）。组内不加空格，组间加一个。

为什么不用像素：控件到底多宽**没有在游戏里实测过**。早先用字体度量推出来的
「120px 目标」「最宽 token ≥180px 才处理」这些数字，只是推测；
照着它做出来的判断不可信，相关工具（`space_words.py --target` / `width_check.py`）
和「宽度粗查」CSV 都已删除。字数预算的好处是确定、可复现，
换机器、换字体文件都不会让结果分叉。

## 分词器优先，兜底才机械切

- **首选** spaCy + `zh_core_web_sm`：OOV 比 jieba 好（「私掠者」「总督府」「胡安·贝尔穆德斯」不会碎），
  需要 Python 3.11，用 `PR2_SPACY_PYTHON` 指向那个解释器（或用仓库里的 `.venv-spacy`）；
- **次选** jieba（`pip install jieba`），可用 `src/tools/data/zh_userdict.txt` 补专名；
- **都没有**才用 `zh_space.fallback_wrap()`：按字数机械切，**会切在词中间**
  （「因 而」「进口货 物」这类）。这是降级路径，会在终端打印提示。

超过 10 字、会被切成两组的片段必须进分词器，否则只能按单字成组。
`zh_space.segment()` 返回的 lookup 上挂着 `missing` 列表，有内容就说明
发生了这种情况，生成脚本会打印条数。

## 不做的两件事

- **不按像素/字体宽度做判断**：没有实测控件宽度，px 只会误导；
- **不做从右往左书写的语言**（阿拉伯语、希伯来语等）：没有游戏源代码，
  引擎的绘制方向无法修改，补空格也解决不了。

## 怎么验证「只是加了空格」

补空格必须**不改字**。验收口径：把新旧语言包都去掉空格后逐字节比较，
应当 0 条内容差异（只允许空格不同）。2026-11 的改造实测：3,548 条中
内容差异 0 条、仅空格不同 967 条（旧成品按像素目标成组，新规则按字数成组）。

单测见 `tests/test_rules.py`（`pack / bind / spaced / fallback_wrap / collect_runs`）。
