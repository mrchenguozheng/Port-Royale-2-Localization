# 构建与安装

## 入口

日常只需要（Python 3.11+）：

```bat
start.bat
```

它会：

1. 在本机启动工作台服务；
2. 打开浏览器到安装页 `/install`；
3. 保留一个控制台窗口显示服务日志。

**不会自动编译。** 构建、部署、启动都在页面里点按钮触发。
关掉控制台窗口或 Ctrl+C 就停止服务。

> 另有一个发行版用的玩家界面 `PR2LauncherGUI.exe`，见
> [发行版](发行版.md)。它不是这个开发工作台。

## 安装向导

页面顶部是「安装与启动」里的五步向导，目标语言先选好：

| 步骤 | 做什么 |
|---|---|
| 1 准备游戏目录 | 选择游戏目录，或点「选择/检测」识别版本 |
| 2 准备字体 | 「导出原版」「检查 donor」；缺字体时给出提示 |
| 3 翻译内容 | 跳到译文编辑，检查目标语言还有多少未译 |
| 4 生成语言包 + 字体 | 调 `compile_pack` + 字体构建 |
| 5 安装并启动 | 部署到游戏目录，然后启动 |

向导只负责引导，下面的卡片仍然可以单独操作。

## 安装页的卡片

### 1 游戏目录

- 输入路径或「浏览…」；
- 「检测并记住」按 `PR2.exe` 的 SHA-256 识别已知版本，写进设置；
- 已记住的目录列在下方，可切换或移除；
- 状态显示版本、已装语言包、`locale.ini`。

设置默认在：

```
%LOCALAPPDATA%\PR2Localization\settings.json
```

可用环境变量 `PR2_SETTINGS` 改位置。里面只存路径和版本，不存译文。

### 2 构建与部署

| 按钮 | 作用 |
|---|---|
| 编译注入器（DLL + 启动器） | 调 MSVC，生成 `PR2TextSource.dll`、`PR2Launcher.exe`、`PR2LauncherGUI.exe` |
| 编译语言包 | 编译勾选的语言，并检查/重缝字体 |
| 部署到游戏目录 | 复制运行时、语言包、`ui/`、`fonts/<语言>/` |

部署特点：

- 只复制文件，不改 `PR2.exe`；
- 内容相同的文件按 SHA-256 跳过，不反复重写；
- 本次没勾选的语言包会从游戏目录移除；
- 字体放到 `fonts/<语言>/`，**不覆盖根目录原版**；
- 语言包 `locale.ini` 不会被部署偷偷改掉。

### 3 启动

| 按钮 | 作用 |
|---|---|
| 语言下拉 | 从 `PR2Packs/*.txt` 读取当前可用语言 |
| 设为游戏语言 | 写 `PR2Packs/locale.ini` 的 `language=` |
| 启动游戏（已注入） | 用 `PR2Launcher.exe` 按当前下拉语言启动 |
| 启动原版对比 | 直接启动 `PR2.exe`，不注入 |
| 打开译文编辑 | 切到译文编辑页 |

注意：**「启动游戏」不会自动写 `locale.ini`**，要持久保存请点「设为游戏语言」。
发行版 GUI 则是启动成功后自动写回。

## 语言怎么定的

运行时只有一种语言生效：

| 优先级 | 来源 | 范围 |
|---|---|---|
| 1 | 环境变量 `PR2_PACK_LANG` | 本次启动；`PR2Launcher.exe --lang=xx` 设置 |
| 2 | `PR2Packs/locale.ini` 的 `language=` | 持久默认 |
| 3 | DLL 内置兜底 `zh` | 连 ini 都没有时 |

因此：

- 安装页「设为游戏语言」= 写第 2 条；
- 安装页「启动游戏」= 只给本次传语言，不写文件；
- 发行版 `PR2LauncherGUI.exe` 启动成功后写第 2 条；
- 直接双击 `PR2Launcher.exe` 只读第 2 条；
- 直接运行 `PR2.exe` 不经过启动器，也不做版本检查。

## 版本识别

工作台用 `PR2.exe` 的 SHA-256 认出已知构建：

| 版本 | 说明 |
|---|---|
| GOG 英文 1.1.2.3 | ✅ 唯一支持，已实测 |
| GOG 法文 1.1.2.42 | ❌ 不支持，只用作翻译参照 |
| Steam 英文 1.1.2.3 | ❌ 不支持，CEG 下注入未生效 |

未支持的版本只用于识别/提示，不要部署，也不属于支持范围。

未知版本也可以记住，只是没有名字。版本名和哈希常量在
`src/tools/install/pr2ctl/base.py`。

## 字体

本机开发使用 **fontstitch 缝合**：

- 以 `assets/fonts/original/` 的原版拉丁字体为 base；
- 把当前译文用到的字从 donor 追加进去；
- 每个语言一套，输出 `build/fonts/<语言>/`；
- 新字出现时自动重缝，缓存标记 `.stitch.json`；
- 字体失败不会让语言包构建失败。

发行版使用 **完整 Noto**，不缝合；详见 [发行版](发行版.md)。

```bat
python src\tools\font\subset_fonts.py --lang zh
python src\tools\font\make_noto_fonts.py --lang zh --out <目录>
```

缝合字体只允许本机自用，不要上传或打包。详见 [字体与分发](字体与分发.md)。

## 译文编辑

和安装页在同一个工作台，顶部页签切换。

- 分页编辑，默认每页 100 条；
- 改过的条目跨页保留，点「保存」一起提交；
- 右侧参照列会标出「该版本无此条」；
- ＋ 添加语言：填代码、选模板，会生成 `src/live/<代码>.toml`、
  `src/seed/<代码>.toml` 和 `presets/<代码>.toml`；
- 新语言要出现在安装页，需要重新加载工作台。

语言包元数据（显示名、GUI 语言、最低运行时）在：

```
src/packs/<代码>.toml
```

编译时写入语言包头部。旧语言包不再兼容，详见
[发行版](发行版.md)。

## 开发者命令

改完译文不想点页面：

```bat
apply_patch.bat                 :: 构建 ja + zh，部署到上次的游戏目录
apply_patch.bat --langs ja      :: 只弄日语
apply_patch.bat --launch        :: 部署完直接启动
apply_patch.bat --dry-run       :: 只打印计划
```

它按顺序做：

1. 归一化译文（可选 `--dep` 补空格）；
2. `check_breaks --strict` 校验换行/占位符；
3. 编译语言包（默认含字体缝合）；
4. 部署到游戏目录；
5. 逐个文件比对 SHA-256。

单独构建：

```bat
src\build_injector.bat
src\build_translation.bat
```

语言包/字体的统一构建入口是库：

```python
from build_artifacts import compile_pack, build_fonts
```

日常仍然用 `compile_pack.py` 或 `apply_patch.py`，不需要直接 import。

## build 目录

```
build\
├─ PR2TextSource.dll
├─ PR2Launcher.exe
├─ PR2LauncherGUI.exe
├─ PR2Packs\       累积的语言包
├─ fonts\<语言>\   缝合字体
└─ font-cache\     Noto 字体缓存
```

`build\` 全部是产物，可以整个删掉重建。

`build\PR2Packs\locale.ini` 只在不存在时从模板创建，不会覆盖用户已选语言。

## 常用脚本

| 脚本 | 职责 |
|---|---|
| `start.bat` | 启动本地工作台服务 |
| `apply_patch.bat` | 构建 + 部署 + 核对 |
| `src\build_injector.bat` | 编译 DLL/启动器 |
| `src\build_translation.bat` | 编译语言包 |
| `src\find_python.bat` | 定位 Python |

`src\tools\` 里的 Python 入口：

| 脚本 | 作用 |
|---|---|
| `pack/compile_pack.py` | 编译语言包、校验占位符 |
| `pack/build_artifacts.py` | 语言包/字体统一构建库 |
| `pack/apply_patch.py` | 一条命令构建并部署 |
| `pack/new_lang.py` | 新建语言 |
| `font/subset_fonts.py` | 缝合字体 |
| `font/make_noto_fonts.py` | 发行版 Noto 字体 |
| `text/space_words.py` | 中文补空格 |

## 服务状态

安装页底部「服务状态」显示：

- 当前服务 pid、端口、运行时长、Python 版本；
- 8777–8800 范围内的其它实例，可一键停止；
- 接口：`/api/health`、`/api/server/instances`、`/api/server/stop`。

命令行：

```bat
start.bat --status
python src\tools\install\server_status.py --stop 8779
```
