# 构建与安装

## 入口

日常只需要 Python 3.11+（构建脚本全 Python，不需要 PowerShell）。译文直接编辑
`src\translations\<语言>.toml`，构建与部署走命令行：

```powershell
python apply_patch.py             # 归一化 → 校验 → 编译 → 部署 → 核对
python build.py                   # 注入器 + 语言包
python src\tools\pack\compile_pack.py --lang zh --strict   # 只出语言包
```

部署完成后用发行版 `PR2LocalizationGUI.exe` 选语言、启动游戏，
入口与语言规则见 [运行契约](运行契约.md)。

## 单条快路径（agent / 手工反馈用）

日常修正一条译文时，不必走完整构建链。`quick.py` 只做：

1. 按截图里的文本，在中文/英文/法文里找候选 hash；
2. 或按已知 hash 直接改 `src/translations/<lang>.toml` 的一条；
3. 调用 `compile_pack --no-fonts` 生成新的 `build/runtime/PR2Localization/packs/<lang>.txt`；
4. 只把这个 `.txt` 复制进游戏目录，不动 DLL、启动器和字体。

```powershell
# 先查候选，不改文件
python src\tools\pack\quick.py --lang zh --find "截图里看到的一句"

# 确认 hash 后改一条并部署
python src\tools\pack\quick.py --lang zh --id 0xc4bde7d1 --text "修正后的译文"

# 只改文件并生成 pack，不复制到游戏
python src\tools\pack\quick.py --lang zh --id 0xc4bde7d1 --text "修正后的译文" --no-deploy
```

`--find` 同时搜中文、英文、法文；带 `--text` 时只有唯一候选才允许自动写入，
否则必须显式给 `--id`。占位符/标签校验仍走 `shared\core\validate.py`：
错误始终拒绝；警告默认拒绝，确认无误可加 `--force`。

它**不做**全量 `check_breaks`、字体检查、运行时复制和全文件 SHA 核对。
这些仍属于发布前的完整构建。游戏启动时读取语言包，所以改完要重启游戏。

agent 需要结构化结果时加 `--json`；查找返回 `candidates`，写入返回
`id/pack/pack_sha256/deployed`。

## 部署

`apply_patch.py`（或 `python src\tools\pack\apply_patch.py --langs zh`）把
`build\runtime\` 复制进游戏目录：

- 只复制文件，不改 `PR2.exe`；
- 内容相同的文件按 SHA-256 跳过，不反复重写；
- 本次没选的语言包会从游戏目录移除；`packs\overrides\` 是本机临时覆盖，整目录保留；
- 字体放到 `PR2Localization/fonts/`，不按语言单开子目录，**不覆盖根目录原版**；
- 根下只放 `PR2Localization\host\Ascaron.Logging-2.6.dll` 这一份宿主代理；
  **不放任何 `.ps1`**——挂载/还原都在启动器进程里做（`pr2_common::host`）。
  代理只放 `host\`、不直接铺到根目录：根目录那份同名文件是原版，铺过去既会覆盖原版，
  也让挂载找不到可校验的原版——那样不报错，但游戏里一条译文都不生效。
- 根目录有宿主 DLL 时，**复制完全部文件后最后一步**以游戏目录为 cwd 调
  `PR2Localization.exe --mount`（`pr2ctl/host_action.py`），不复制第二套替换算法：
  启动器会先校验原版、写两份备份，再原子换入代理。
  失败时根目录 DLL 未改动，但本地化文件已经落盘；部署文案会如实说明。
  根目录没有这个 DLL 的版本跳过这一步。
- 只写 `locale.default.ini`，其 `language=` 跟本次安装的语言走（游戏已选的语言在本次包里就保留，
  否则用第一个语言，与 `make_release --default-lang` 同口径）；已有用户 `locale.ini`
  不会被部署改掉（空值也不动），它非空时运行时仍优先用它。

记住的游戏目录和版本在：

```
%LOCALAPPDATA%\PR2Localization\settings.json
```

可用环境变量 `PR2_SETTINGS` 改位置。里面只存路径和版本，不存译文。
第一次用 `--game-dir <路径>` 认定目录，之后会被记住。

## 启动与语言

启动入口、挂载、`locale.ini` 优先级与界面语言以[运行契约](运行契约.md)为唯一口径；
这里只留部署后的自检：

- `runtime.log` 首行应有 `pack '<语言>' ... N entries, M overrides`；
- `host.log` 应有挂载/还原记录；
- 直接双击 `PR2.exe` 不经过启动器，不注入、也不做版本检查。

## 版本识别

部署链与发行版 GUI 用 `PR2.exe` 的 SHA-256 认出已知构建：

| 版本 | 说明 |
|---|---|
| GOG 英文 1.1.2.3 | ✅ 已实测（宿主 DLL 代理，中文界面） |
| GOG 法文 1.1.2.42 | ✅ 已实测（2026-11-22，pl 包；宿主代理生效；多 42 条空占位、少 19 条，按原样保留） |
| Steam 英文 1.1.2.3 | ✅ 已实测（同上，两版导入表一致、原版宿主 DLL 同字节） |

未验收的版本只用于识别/提示，不要部署，也不属于支持范围。

未知版本也可以记住，只是没有名字。版本名和哈希常量在
`src/tools/install/pr2ctl/base.py`。

## 字体

字体的来源、映射、合包与缺字体处理见[字体与分发](字体与分发.md)和
[玩家指南 §6](玩家指南.md#6-字体缺失怎么办)。构建侧只需知道：

```powershell
python src\tools\font\make_noto_fonts.py --lang zh --out <目录>
```

部署侧三个容易“映射看着配好、游戏里却没生效”的坑，统一记在
[字体与分发 · 部署侧](字体与分发.md#部署侧三个坑)，不要在部署代码里另写规则。

## 译文文件

译文只改 `src\translations\<代码>.toml`，一条一行 `"0xhash" = "译文"`；没写的条目回退英文。
格式、占位符、排版和检查流程见[译文与语言包](译文与语言包.md)与
[译文检查](译文检查.md)；新建语言见[新语言](新语言.md)。语言包元数据在
`src/packs/<代码>.toml`，编译时写进包头。

## 开发者命令

改完译文，一条命令跑完：

```powershell
python apply_patch.py                 # 构建全部可构建语言，部署到上次的游戏目录
python apply_patch.py --lang ja       # 只弄日语（可重复，避免 PowerShell 拆逗号）
python apply_patch.py --lang ko --lang pt-BR
python apply_patch.py --langs ja,zh   # 逗号写法也行；PowerShell 里建议整体加引号
python apply_patch.py --prune         # 显式删掉本次未列出的语言包；默认保留
python apply_patch.py --launch        # 部署完直接启动
python apply_patch.py --dry-run       # 只打印计划
```

部署默认增量：`--lang`/`--langs` 只覆盖列出的语言，未列出的包留在游戏目录；
只有显式 `--prune` 才清理。

提交前跑轻量闸门（不依赖 Rust）：

```powershell
python precommit.py
git config core.hooksPath .githooks   # 可选：让 git commit 自动跑
```

`precommit.py` 调 `src/tools/precommit.py`，只跑配置对账、文档索引/语言矩阵和
截图画廊生成物检查；完整构建与实机验收仍走 `check.py` / CI。

`apply_patch.py` 按顺序做：归一化标点 → `check_breaks --strict` 校验换行/占位符 →
编译语言包（默认含字体生成）→ 部署 → 逐文件比对 SHA-256。

### 一键构建

```powershell
python build.py                         # 注入器 + 全部语言包
python build.py --target packs           # 只编语言包
python build.py --target packs --lang zh  # 只编中文
python build.py --target injector        # 只编 Rust 注入器
```

默认从 `src\translations\*.toml` 发现语言，新增语言不用改脚本。低层脚本仍可单独跑：

```powershell
python src\build_injector.py
python src\build_translation.py --lang zh
```

构建时把 `src\injector-rs\ui\ui.*.ini` 全部复制到 `build\runtime\PR2Localization\ui\`，
再用 `ui.zh.ini` 生成 `ui.default.ini`；源码没有默认文件，不要手工补中文副本。

exe 与语言包的版本头、`entries`/`untranslated`/`scope`/`digest` 四行元数据、
`make_release.py` 的增改删统计，统一由[发行规范](发行规范.md)定义，本文不重复。

### 一键发版

```powershell
python release.py --version v1.0.0                 # 每个分组一个 zip（GOG / Steam 通用）
python release.py --version v1.0.0 --bundle zh       # 只出中文分组
python release.py --version v1.0.0 --bundle latin    # 只出 latin 分组
python release.py --version v1.0.0 --tag --push       # 打 tag 并推送
```

分组、`--skip-injector`、`--fonts auto`、脏工作树与产物清单的完整规则见
[发行规范](发行规范.md)；发版前验证与 GitHub Actions 见[发行版](发行版.md)。

### 检查

```powershell
python check.py            # 全量
python check.py --skip-rust  # 只跑 Python 检查与单测（本机没有 cargo 时）
```

`check.py` 先做脚本语法检查，再跑 Rust 闸门（fmt / clippy / test / 逐 crate check），
任一失败即停；最后跑 `src\tools\check.py`（语言配置、译文规范、断行、不译清单、
文档一致性、脚本地图、单测）。CI 不允许 `--skip-rust`。
## build 目录

```
build\
├─ runtime\                 可直接整体复制到游戏目录
│  ├─ PR2LocalizationCore.dll
│  ├─ PR2Localization.exe
│  ├─ PR2LocalizationGUI.exe
│  ├─ Ascaron.Logging-2.6.dll   ← 宿主代理（打包时从根目录移进 host\，不留在根）
│  └─ PR2Localization\
│     ├─ host\             打包时把上面那份代理复制到这里，避免解压覆盖原版
│     ├─ packs\            累积的语言包
│     ├─ fonts\<语言>\      构建暂存；打包/部署时平铺到 PR2Localization\fonts
│     ├─ ui\               十二份 ui.<lang>.ini + 构建生成的 ui.default.ini（来自 ui.zh.ini）
│     └─ logs\             运行时日志
├─ preview\                 给人查看，不参与发行
│  ├─ engine_text\<语言>.toml
│  └─ glossary\<语言>.md
└─ cache\                   可丢弃缓存
   └─ noto\                 Noto 字体缓存
```

`build\` 全部是产物，可以整个删掉重建。`runtime\` 是唯一的安装源；`preview\` 和 `cache\` 不进入发行包。

`build\runtime\PR2Localization\packs\locale.ini` 只在不存在时从模板创建，不会覆盖用户已选语言；
`locale.default.ini` 同样只在缺失时生成，作为部署/发行默认值。

## 脚本位置

根目录只留四个日常入口：

| 脚本 | 职责 |
|---|---|
| `build.py` | 一键构建：注入器 + 语言包 |
| `release.py` | 一键发版：构建 + 发行 zip + 可选 tag/push |
| `apply_patch.py` | 构建 + 部署 + 核对 |
| `check.py` | Rust 闸门 + Python 检查 + 单测；`--skip-rust` 跳过 Rust |

`src\` 下是低层实现；完整脚本地图（`src\tools` 各目录、字体、规则、QA 探针）见
[`src/tools/README.md`](../src/tools/README.md)，这里不再维护第二份表。
