# 中文文本改动对比（完成版 → 干净文本源）

目的：看看「翻译完成」之后，除了补空格，**真正改过文字**的地方有哪些。

- 基线：`f0808c5`（`zh.toml` 第一次达到 3,548 条的提交）
- 对照：`src/references/zh.gog_1.1.2.3.toml`（去掉补空格后的干净文本源，tag `zh-source-v1`）
- 比较方式：两边都**去掉标签、占位符和所有空格**，只比剩下的文字，避免把
  `|` → `<n>`、占位符空格这类格式变化算成改字
- 逐条明细：[zh-text-edits.csv](zh-text-edits.csv)

## 汇总

| 类别 | 条数 |
|---|---|
| 标点 / 格式（只差标点或半角全角） | 127 |
| 措辞 / 修正 | 65 |
| 术语：总督 → 副王 | 47 |
| 术语：等级（船上的小伙计 → 见习水手等） | 2 |
| 术语：特典 | 1 |
| **合计** | **242** |

## 例子

**术语统一（总督 → 副王）**

```
0x12ea47c0  英格兰总督的赠礼      → 英格兰副王的赠礼
0x13cd046e  每当你替一位总督攻下… → 每当你替一位副王攻下…
```

**措辞 / 修正**

```
0x103b68ea  期限是 @D$EndDate$.<。  → 期限是 @D$EndDate$.
            （旧版多了一个「<。」的残字）
```

**等级 / 特典**

```
0xE9278A47  船上的小伙计 → 见习水手
0xE9278A4B  事务长       → 水手长
0x04F64E2B  功能         → 特典
```

**标点 / 格式**

```
0x13d92dd7  （） → ()        （文本源用半角，生成时再统一成全角）
0x11a65e61  时分 → h m      （时间格式改成引擎认的写法）
```

## 结论

- 真正**改字**的 242 条里，一半以上只是标点/格式；实质内容变化集中在
  **副王/总督术语统一**和 **65 条措辞修正**；
- 这也说明「补空格」阶段没有偷偷改文案——所有空格变化都在生成规则里可复现，
  改字的部分都在这张表里；
- 以后再有改字，直接改 `src/references/zh.gog_1.1.2.3.toml`，并可以拿这张表当
  「已改过什么」的台账。
