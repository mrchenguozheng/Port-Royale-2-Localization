# 语音 ↔ 文本 hash ↔ NPC 映射

> 英语 `whisper(base)`、法语 `whisper(large-v3)` 转写后分别与英/法原文匹配，再交叉核对。
> 逐条数据（含转写原文）：[voice-hash-map.csv](voice-hash-map.csv)；文件分组：[语音清单](语音清单.md)。

## 处理范围

只有**英语**和**法语**有权威文本，因此只处理这两种语音：`Ho`/`Sp` 共 68 个与英法同基名、文本相同，不处理；德语旁白 170 个没有权威德文文本，不处理。

## 说话人（NPC）归属

**这 34 段全部是「总督代理」（Viceroy）的语音**，分别对应他的各种对话状态（问候、授地、授权攻城镇、征用船队、收尾）。

依据：

1. 文本内容全是总督代理的专属职能——攻占殖民城镇的授权、征用 5 艘/150 门炮的军事船队、授地建镇、以及和平与战况通报；
2. 游戏里这类攻城镇任务只有「大巴哈马的总督代理」能发布（原文见 `0x3353aa4c`）；
3. `PR2.exe` 里这批语音路径是连续的一段：136 条路径一直排到 `0x288564`，紧接其后的 `0x28857C` 起就是 39 个 `ID_NPC_VICEROY_*` 事件名（`ANNEX_TAKEN_ADD`、`CONVOY_REQUEST_00..02`、`NEW_LAND_ALL/PART`、`TOWN_OFFER`、`DIALOG_END_*` 等），与文本逐条对得上（见下表「事件」列）。路径块与 ID 块首尾相接，是这批语音属于总督代理的硬证据。

> 注意：语音本身不分国家——同一个文件会在任意国家的总督代理处播放，国名、城镇名、金额都是运行时用 `%1`/`@T$…$` 代入的。`1a`/`1b` 是对**敌国**总督代理的和平交涉，`1c` 是本国的战况通报。

39 个事件名对应 34 段语音，说明有 5 个状态复用了同一段录音（或没有录音）。

事件名是**推断**：从 `ID_NPC_VICEROY_*` 词表（`ANNEX_TAKEN`、`CONVOY_REQUEST`、`NEW_LAND_PART`、`TOWN_OFFER`、`DIALOG_END_*` 等）按语义对上文本；NPC 归属本身是高置信，具体事件编号属中置信。

## 欢迎语（拼接型，教程旁白）

`Willkommen_<lang>_0X.mp3` 不是一句台词，而是把几句话连读，对应多个 hash：

| 文件 | 组成（按朗读顺序） |
|---|---|
| `Willkommen_00.mp3` | `0x30a45770` + `0x36f0738f` + `0x25476337` + `0x28b1f98d` |
| `Willkommen_01.mp3` | `0x30a45770` + `0x36f0738f` + `0x25476338` + `0x28b1f98d` |
| `Willkommen_02.mp3` | `0x30a45770` + `0x36f0738f` + `0x25476339` + `0x28b1f98d` |

组成说明：

- `0x30a45770` = `Welcome!`
- `0x36f0738f` = `You begin your career in the English town of %1 in the year %2.`
- `0x25476337/38/39` = `Your convoy is in the harbor with an unarmed brig/sloop/pinnace…`（00=brig、01=sloop、02=pinnace）
- `0x28b1f98d` = 许可/等级说明那一段（`%1 %2 You also have a permit…`）

## 核对结果

- 一致：31
- 近似（法语近义句多，排序第 2）：2
- 未判定：1

34 个基名的 hash **以英语为准**（英语转写全部唯一高置信命中）；法语只用于交叉核对。
典型分歧 `2c`：法语念的是「追加土地、占该区一部分」，对应 `0xfbb36ec1`（总面积的 %2%），不是 `0xfdaf6463`（剩余土地、整个区）。

## 复现方式

```bash
py -3.11 .tmp\asr_run.py --langs en --model base        # 英语，约 1 分钟
py -3.11 .tmp\asr_run.py --langs fr --model large-v3    # 法语，约 27 分钟（base 对法语不可用）
python src\tools\voice_match.py --asr .tmp\asr          # 匹配出 hash
```
