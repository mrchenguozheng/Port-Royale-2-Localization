# 玩家指南：解压即用

这份文档只讲**拿到发行包后怎么启动本地化**，不涉及源码、编译和翻译。

## 1. 确认游戏版本

当前支持：

```
GOG 英文版 Port Royale 2 1.1.2.3     已实测（宿主 DLL 代理，中文界面）
Steam 英文版 1.1.2.3                 已实测（同上，启动交给 Steam 客户端）
GOG 法语版 1.1.2.42                  已实测（同一个包，宿主代理，界面显示译文）
```

其他版本（零售版、补丁版）还没有验证，不要在上面部署。同一个包三个已知版本都能解压：
启动器先挂载宿主 DLL，GOG 版直启 `PR2.exe`，Steam 版交给客户端
（`steam://rungameid/12470`）拉起；法语版的版本号在游戏里仍是 `1.1.2.42`
（本地化不改 `PR2.exe`，也不改它的文本键位）。进游戏后文本没有变化时，先看
`PR2Localization\logs\host.log`、`proxy.log` 和 `runtime.log`，不要先删游戏文件。

系统要求：Windows 10 / 11。挂载与还原都在启动器进程里完成，不调用 PowerShell，
也不受「禁止执行脚本」这类组策略影响；不需要 PowerShell 7。

## 2. 下载对应语言的 zip

从项目 Release 页面下载需要的语言，例如：

```
PR2-zh-v1.0.0.zip    ← 中文，GOG 版和 Steam 版通用
PR2-ja-v1.0.0.zip    ← 日语，同样两版通用
PR2-pl-v1.0.0.zip    ← 波兰语，同样两版通用（带三个标题字体）
```

**一个 zip 同时支持 GOG 和 Steam**，不用按入口挑包，也不存在混装问题。入口都是
`PR2LocalizationGUI.exe`：解压后双击它，启动器先把宿主 DLL 代理挂上，再按版别拉起游戏 ——
GOG 版直启 `PR2.exe`，Steam 版交给客户端（`steam://rungameid/12470`）。
每个 zip 同目录还有 `SHA256SUMS.txt`，需要时可用 `sha256sum -c` 核对。

包根 `README.txt` 第 3 行写着这份译文的标记，例如
“标记：同人制作 · 社区协作 · AI 辅助；审阅：预览版”。这批译文不是官方本地化，
由社区制作、AI 辅助起草并人工审校；改自零售版官方文件的旧语言会标 `retail`。

**启动器界面没有母语审校。** 十二种界面文案由 AI 起草，只做了条目与占位符的机械校验。
如果你是其中某门语言的母语玩家，欢迎在项目 Issue 里贴「截图 + 当前文案 + 建议改法」，
游戏内语言包的问题也可以一并提。

## 3. 解压到游戏根目录

把 zip 里的**全部文件**解压到 `PR2.exe` 所在的同一层目录，例如：

```
<游戏目录>\
├─ PR2.exe
├─ PR2Localization.exe
├─ PR2LocalizationGUI.exe
├─ PR2LocalizationCore.dll
├─ Ascaron.Logging-2.6.dll  ← 原版文件，解压不会碰它
├─ PR2Localization\
│  ├─ host\                 ← 代理在这里，不在根目录
│  │  └─ Ascaron.Logging-2.6.dll
│  ├─ packs\
│  ├─ fonts\
│  ├─ ui\
│  └─ logs\
├─ fonts\                 ← 原版字体，保留
└─ ...
```

注意：

- 不要解压到 `PR2Localization` 之类的子文件夹；
- 不要删除 `fonts\` 根目录的四份原版字体；
- 发行包不会覆盖 `fonts\` 根目录，只把本地化字体平铺放进 `PR2Localization\fonts\`；
- 发行包只带 `PR2Localization\packs\locale.default.ini`；已有 `locale.ini` 时不会被解压覆盖；
- `PR2Localization\packs\overrides\` 是你的本机临时译文，安装/升级不会删除。
- 包里不含 `VERSION.dll`（两版都不需要）；如果从旧包升级，根目录残留的 `VERSION.dll` 可以删除。
- 代理始终放在 `PR2Localization\host\Ascaron.Logging-2.6.dll`，解压不会覆盖根目录的原版
  `Ascaron.Logging-2.6.dll`；两版都由启动器把它换进根目录。
- 挂载由启动器自动完成：双击 GUI 点「以所选语言启动」时，它先校验
  原版大小/SHA-256、建立两份备份，再把代理换进根目录，最后拉起游戏
  （GOG 直启，Steam 交给客户端）。
  根目录既不是原版也不是本工具挂上去的代理（比如别的 mod 的 DLL）时会停止，不会覆盖未知文件；
  如果是代理但两份备份都丢了，它会提示先用平台的「验证游戏文件完整性」恢复原版，而不是假装已挂载。
- 想恢复原版：点 GUI 上的「还原原版」，或运行 `PR2Localization.exe --restore`。

## 4. 启动游戏

GOG 和 Steam 都是同一个入口：双击 `PR2LocalizationGUI.exe`，选语言，点「以所选语言启动」。

- 启动器先确认根目录的宿主 DLL 是原版还是已挂载的代理。是原版就校验、备份、
  换名挂载，已经挂载就跳过，然后拉起游戏：GOG 版直接启动 `PR2.exe`，不注入；
  Steam 版交给客户端（`steam://rungameid/12470`），因为 `Program Files` 下直接建进程
  会拿到错误 740。整套动作在启动器进程内完成，不需要先跑任何脚本。
- Steam 版的语言只能写在 `PR2Localization\packs\locale.ini` 的 `language=`；GUI 里
  选语言时会把选择写进这个文件再启动，`--lang` 对 Steam 版无效（会直接报错退出）。
- 挂载之后直接双击 `PR2.exe` 也能进本地化版本；没挂载时双击就是原版英文。
- 包内没有宿主 DLL 时，启动器自动退回远程注入，理由写进 `PR2Localization\logs\host.log`；
  想强制走注入加 `--inject`。

命令行等价写法：

```bat
PR2Localization.exe --lang=zh          :: 一次启动用指定语言
PR2Localization.exe --vanilla          :: 原版：先还原宿主 DLL，再恢复原版字体
PR2Localization.exe --restore          :: 只还原，不启动游戏
PR2Localization.exe --mount            :: 只挂载，不启动游戏
PR2Localization.exe --inject           :: 强制走远程注入，不挂载宿主 DLL
PR2Localization.exe --version          :: 打印版本，不启动游戏
```

**怎么看版本**：

- GUI 副标题写着运行时版本与本程序版本，例如
  `Port Royale 2 本地化运行时 v1 · v1.0.0 (c8aa6e3)`；
- 语言下拉里每项带包版本：`简体中文 · v1.0.0`；状态框也会重复当前选中的那一项；
- 命令行 `PR2Localization.exe --version` 一行打印同样的信息；
- 开发构建（没有编入发行版本）显示 `dev (c8aa6e3+dirty)`；`+dirty` 表示编它的工作树有未提交改动。
- 报问题时把这一行发出来，就能对上具体是哪个包、哪次构建。

**怎么看语言包改了什么**：

- 状态框第二行是包里的内容：`3590 条 · 未译 0 · 摘要 9cfa2931c1c2`。
  `条` 是这个包里共有多少条译文，`未译` 是还挂着占位符的条数（原版本来就空的键不算）；
- `摘要` 是正文内容的指纹：两份包摘要相同 = 译文逐字相同；版本号相同但摘要不同 =
  同一个版本重打过，译文动过；
- 包里自带一个空的 `PR2Localization\packs\overrides\` 目录。你自己往里面放
  `<语言>.txt`（比如 `zh.txt`），同 hash 的句子就会覆盖包里的译文，不改包本身；
  这是本机补丁，界面上不显示它的条数，删掉文件即恢复；
- 包根 `README.txt` 的「语言包变化」段写得更细：相对上一个发行版新增多少条、
  修改多少条、删除多少条，以及对比的是哪个版本；
- 摘要只有 12 位，回答不了「改了哪几句」—— 想看具体条目，去仓库的
  `src/translations/<语言>.toml` 提交记录里查。

如果启动器提示原版 DLL 大小/哈希不对，不要强行替换；先用平台的「验证游戏文件完整性」
（Steam 客户端或 GOG Galaxy 都提供）把原版 DLL 恢复，再重试。挂载每一步都写在
`PR2Localization\logs\host.log`，
GUI 弹出还原失败时，对话框里带的就是这份日志的末尾几行。

需要临时指定语言时，也用 `PR2LocalizationGUI.exe`：

1. 在语言下拉里选择目标语言；
2. 点「以所选语言启动」。

界面上半部分是语言包和启动操作，下面是状态框和操作提示；窗口会按系统
DPI 自动缩放，不需要手动调整大小。

如果游戏退出时卡死，点「结束游戏进程」。它只会结束本目录启动的
`PR2.exe`，并先弹确认；不会误杀 Steam 或其他目录的游戏副本。

启动成功后，GUI 会把这个语言写进用户活动配置：

```
PR2Localization\packs\locale.ini
```

发行包只带 `locale.default.ini`，所以已有 `locale.ini` 的安装升级时不会被覆盖。
下次直接双击 `PR2LocalizationGUI.exe` 会默认选它。

确认是否生效：看 `PR2Localization\logs\runtime.log` 第一行是否有
`pack '<语言>' ... N entries, M overrides`（`M` 是你放的覆盖条数，没有覆盖文件就是 0）；
没有日志或首行是 `NO pack loaded` 时，
再看 `PR2Localization\logs\proxy.log` 是否加载了 `PR2LocalizationCore.dll`。

## 5. 用启动器时第一次会备份原版字体

启动器同时负责挂载宿主 DLL 和字体：宿主 DLL 走替换，字体仍走路径重定向，
不备份、不覆盖根目录字体。

用启动器第一次替换字体会先把原版四个 TTF 备份到：

```
PR2Localization\fonts\_original\
```

之后：

- 默认映射：`PR2Localization\fonts\font-map.default.ini` 把四个逻辑字体名
  映射到 `PR2Localization\fonts\` 内的实际字体文件；实际文件保留 Noto 原始文件名，
  不需要改名为 `ARIAL.TTF` 等；
- 用户配置按项覆盖：要改映射时新建或编辑同目录的 `font-map.ini`，只写需要覆盖的
  逻辑名；运行时先加载默认文件，再叠加用户项，未写的项仍用默认；
  发行包不含这个文件名，所以解压升级不会覆盖手工配置；
- 内置字体：四个逻辑名都能映射到 fonts 内真实文件时，使用这些文件，不覆盖根目录；
- 原版启动：`PR2Localization.exe --vanilla` 使用根目录原版。

如果备份失败或根目录已被替换过，启动器会提示并跳过。

## 5a. 字体文件名与逻辑名映射

发行包只带 `PR2Localization\fonts\font-map.default.ini`。要自定义时，新建
`PR2Localization\fonts\font-map.ini`，只写需要覆盖的逻辑名；运行时以默认文件为基础
叠加用户项，不用复制整份默认文件。要显式禁用某一项，写 `ARIAL.TTF=none` 或
`ARIAL.TTF=-`：

```ini
[fonts]
; 全局默认，可留空

[zh]
ARIAL.TTF=NotoSansSC-Regular.ttf
ELGRECO_.TTF=NotoSerifSC-Black.ttf
Tiepolo_black.ttf=NotoSerifSC-Black.ttf
Tiepolo_bold.ttf=NotoSerifSC-Bold.ttf
```

`[fonts]` 是全局默认，`[zh]` / `[ja]` 覆盖它。值只写文件名，实际文件必须位于
`PR2Localization\fonts\`；不会读取系统字体目录，也不接受字体目录之外的路径。
多个候选用 `|` 分隔，取第一个存在的文件。两个逻辑名可以指向同一个实际文件。
四个逻辑名都要有可用映射，GUI 才会认为字体完整；映射失败时回退根目录原版。
不使用 `.ttc` 集合，也不接受 `-VF.ttf` 可变字体，配置里的这两类都会被跳过。

## 6. 字体缺失怎么办

如果 GUI 提示：

```
PR2Localization\fonts\ 缺少字体 TTF
```

先检查当前映射（`font-map.default.ini` 为默认，`font-map.ini` 存在时按项覆盖）
是否为 `zh` 节配置了全部四个逻辑字体名，并且这些名字指向
`PR2Localization\fonts\` 下真实存在的文件。两个文件都没有时，说明发行包没有解压完整，处理：

1. 重新从 zip 解压整个 `PR2Localization\fonts\` 目录；
2. 确认实际字体文件和映射都在：

   ```
   font-map.default.ini
   NotoSansSC-Regular.ttf
   NotoSerifSC-Black.ttf
   NotoSerifSC-Bold.ttf
   ```

3. 不要把字体放到游戏根目录 `fonts\`；原版字体保持不动；
4. 检查杀毒软件是否隔离了字体。

仍然启动也可以，但会回退原版拉丁字体，中文可能空白。

## 7. 切换语言

- 当前语言：`PR2Localization\packs\locale.ini` 的 `language=`；没有这个文件时读
  `locale.default.ini`；
- 在 GUI 里选另一语言，再点「以所选语言启动」；下拉框一换，启动器界面文案也跟着换；
- 或启动器临时指定：

  ```bat
  PR2Localization.exe --lang=ja
  ```

  这个只影响本次，不写 `locale.ini`。
- 把 `locale.ini` 的 `language=` 清空不会切回原版英文：运行时仍会落到内置 `zh`；
  要原版请用 GUI「启动原版」或 `PR2Localization.exe --vanilla`。

## 8. 卸载

先还原宿主：点 GUI 上的「还原原版」按钮（两版相同），或

```powershell
PR2Localization.exe --restore
```

还原会把根目录的 `Ascaron.Logging-2.6.dll` 换回原版、恢复原版字体、删掉
`PR2Localization\host-mount.json`；已经还原过再点一次不会有副作用。

然后删除发行包新增的内容：

```
PR2Localization.exe
PR2LocalizationGUI.exe
PR2LocalizationCore.dll
Ascaron.Logging-2.6.orig.dll ← 还原后可保留，也可删除
PR2Localization\host\        ← 包内代理，删除不影响游戏
PR2Localization\host-backup\ ← 第二份原版备份
PR2Localization\packs\<语言>.txt
PR2Localization\packs\locale.default.ini
PR2Localization\fonts\     ← 字体与 font-map.default.ini
PR2Localization\docs\      ← 字体许可 OFL.txt、来源说明
PR2Localization\ui\
PR2Localization\logs\
README.txt / RUNTIME-VERSION
```

不要删除：

- `PR2.exe`、`.cpr`、地图、音乐等游戏文件；
- `fonts\` 根目录的原版字体；
- 如果自己做过临时译文，保留 `PR2Localization\packs\overrides\`。

存档不受影响。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 界面还是英文 | `locale.ini`（或默认文件）指向的语言没有包，或代理没加载 | 看 `PR2Localization\logs\runtime.log` 首行；没有日志时看 `PR2Localization\logs\proxy.log` |
| 中文显示空白 | 字体缺失或映射不完整 | 检查当前映射（默认文件为基础，用户 `font-map.ini` 按项覆盖）的四个逻辑名和实际文件 |
| GUI 列表没有语言 | `PR2Localization\packs\<语言>.txt` 没解压到根目录 | 重新解压语言包 |
| 启动器闪一下就没了 | 控制台程序，双击看不到错误 | 从命令行运行 `PR2Localization.exe` 看日志 |
| 进游戏还是英文 | 宿主 DLL 未挂载、被平台校验恢复，或代理加载失败 | 先点 GUI「还原原版」再重新启动一次；仍不生效则看 `PR2Localization\logs\host.log`，并附 `PR2Localization\logs\proxy.log`、`PR2Localization\logs\runtime.log` 排查 |
| 提示「已是代理，但找不到有效的原版备份」 | 根目录是代理，`.orig.dll` 与 `host-backup\` 都没了 | 用平台的「验证游戏文件完整性」恢复原版 DLL，再重新启动 |

更多技术细节见[构建与安装](构建与安装.md)和[发行版](发行版.md)。
