# 玩家指南：解压即用

这份文档只讲**拿到发行包后怎么启动本地化**，不涉及源码、编译和翻译。

## 1. 确认游戏版本

当前支持：

```
GOG 英文版 Port Royale 2 1.1.2.3     已实测
Steam 英文版 1.1.2.3                 已实测（宿主 DLL 代理，中文界面）
```

GOG 法语版和其他版本暂不支持。Steam 版如果进游戏后文本没有变化，
先看 `PR2Localization\logs\proxy.log` 和 `PR2Localization\logs\runtime.log`，不要先删游戏文件。

## 2. 下载对应语言和入口的 zip

从项目 Release 页面下载需要的语言和游戏入口，例如：

```
PR2-zh-gog-v1.0.0.zip      ← GOG 版，不带宿主 DLL
PR2-zh-steam-v1.0.0.zip    ← Steam 版，带 Ascaron.Logging-2.6.dll + PR2HostMount.ps1
PR2-ja-gog-v1.0.0.zip
PR2-ja-steam-v1.0.0.zip
```

一个 zip 就是一种语言的一个入口；GOG 和 Steam 各下载自己需要的那个，不要混装。

## 3. 解压到游戏根目录

把 zip 里的**全部文件**解压到 `PR2.exe` 所在的同一层目录，例如：

```
<游戏目录>\
├─ PR2.exe
├─ PR2Localization.exe
├─ PR2LocalizationGUI.exe
├─ PR2LocalizationCore.dll
├─ Ascaron.Logging-2.6.dll  ← 只有 Steam 包有；GOG 包没有这个文件
├─ PR2HostMount.ps1         ← 只有 Steam 包有
├─ PR2Localization\
│  ├─ packs\
│  ├─ fonts\
│  ├─ ui\
│  └─ logs\
├─ fonts\                 ← 原版字体，保留
└─ ...
```

注意：

- 不要解压到 `PR2Localization` 之类的子文件夹；
- 不要删除 `fonts\` 根目录的四份原版字体；
- 发行包不会覆盖 `fonts\` 根目录，只把本地化字体放进 `PR2Localization\fonts\<语言>\`；
- GOG 包不需要 `VERSION.dll`；如果从旧包升级，根目录残留的 `VERSION.dll` 可以删除。
- Steam 包不要手工覆盖 `Ascaron.Logging-2.6.dll`：先在游戏根目录运行
  `powershell -ExecutionPolicy Bypass -File .\PR2HostMount.ps1 -Action Mount`。
  脚本会校验原版大小/SHA-256、建立两份备份，再换代理；校验失败会停止。
- 想恢复原版 Steam，运行同一脚本的 `-Action Restore`。

## 4. 启动游戏

GOG 双击 `PR2LocalizationGUI.exe`，选语言后点「以所选语言启动」；Steam 先运行
`PR2HostMount.ps1 -Action Mount`，再从 Steam 正常启动。
GOG 不要直接双击 `PR2.exe`：加载器会把 `VERSION.dll` 解析到
`C:\Windows\SysWOW64\VERSION.dll`，同目录代理不会进入游戏进程，游戏会是原版英文。

如果 Steam 上挂载脚本报告原版 DLL 大小/哈希不对，不要强行替换；先确认 Steam
文件完整，或把备份的 `Ascaron.Logging-2.6.orig.dll` 恢复后再重试。

需要临时指定语言时，也用 `PR2LocalizationGUI.exe`：

1. 在语言下拉里选择目标语言；
2. 点「以所选语言启动」。

界面上半部分是语言包和启动操作，下面是状态框和操作提示；窗口会按系统
DPI 自动缩放，不需要手动调整大小。

如果游戏退出时卡死，点「结束游戏进程」。它只会结束本目录启动的
`PR2.exe`，并先弹确认；不会误杀 Steam 或其他目录的游戏副本。

启动成功后，GUI 会把这个语言写进：

```
PR2Localization\packs\locale.ini
```

下次直接双击 `PR2LocalizationGUI.exe` 会默认选它。

确认是否生效：看 `PR2Localization\logs\runtime.log` 第一行是否有
`pack '<语言>' ... overrides`；没有日志或首行是 `NO pack loaded` 时，
再看 `PR2Localization\logs\proxy.log` 是否加载了 `PR2LocalizationCore.dll`。

## 5. 用启动器时第一次会备份原版字体

Steam 挂载后从 Steam 启动：DLL 只做路径重定向，不备份、不覆盖根目录字体。

用启动器第一次替换字体会先把原版四个 TTF 备份到：

```
PR2Localization\fonts\_original\
```

之后：

- 配置文件优先：`PR2Localization\fonts\font-map.ini` 可以把四个逻辑字体名
  映射到系统字体（例如 `%WINDIR%\Fonts\simhei.ttf`），不需要复制或改名字；
- 内置字体：没有可用映射时，使用 `PR2Localization\fonts\<语言>\`，不覆盖根目录；
- 原版启动：`PR2Localization.exe --vanilla` 使用根目录原版。

如果备份失败或根目录已被替换过，启动器会提示并跳过。

## 5a. 使用系统字体（font-map.ini）

编辑 `PR2Localization\fonts\font-map.ini`：

```ini
[fonts]
; 全局默认，可留空

[zh]
ARIAL.TTF=%WINDIR%\Fonts\Deng.ttf|%WINDIR%\Fonts\simhei.ttf
ELGRECO_.TTF=%WINDIR%\Fonts\Dengb.ttf|%WINDIR%\Fonts\simhei.ttf
Tiepolo_black.ttf=%WINDIR%\Fonts\Dengb.ttf|%WINDIR%\Fonts\simhei.ttf
Tiepolo_bold.ttf=%WINDIR%\Fonts\Dengb.ttf|%WINDIR%\Fonts\simhei.ttf
```

`[fonts]` 是全局默认，`[zh]` / `[ja]` 覆盖它；值支持绝对路径、相对游戏根目录的
路径、`%WINDIR%` 等环境变量；多个候选用 `|` 分隔，取第一个存在的文件。四个
逻辑字体名都要有可用映射，GUI 才会认为字体完整。映射失败时按“配置 → 内置
字体 → 原版根目录”回退。

## 6. 字体缺失怎么办

如果 GUI 提示：

```
PR2Localization\fonts\zh\ 缺少字体 TTF
```

先检查 `PR2Localization\fonts\font-map.ini` 是否为 `zh` 节配置了全部四个逻辑
字体名，并且路径在 `%WINDIR%\Fonts\` 下真实存在。没有使用配置文件时，说明
发行包没有解压完整，处理：

1. 重新从 zip 解压整个 `PR2Localization\fonts\<语言>\` 目录；
2. 确认四个文件都在：

   ```
   ARIAL.TTF
   ELGRECO_.TTF
   Tiepolo_black.ttf
   Tiepolo_bold.ttf
   ```

3. 不要把字体放到 `fonts\` 根目录；
4. 检查杀毒软件是否隔离了字体。

仍然启动也可以，但会回退原版拉丁字体，中文可能空白。

## 7. 切换语言

- 当前语言：`PR2Localization\packs\locale.ini` 的 `language=`；
- 在 GUI 里选另一语言，再点「以所选语言启动」；
- 或启动器临时指定：

  ```bat
  PR2Localization.exe --lang=ja
  ```

  这个只影响本次，不写 `locale.ini`。

## 8. 卸载

Steam 先还原宿主：

```powershell
powershell -ExecutionPolicy Bypass -File .\PR2HostMount.ps1 -Action Restore
```

然后删除发行包新增的内容：

```
PR2Localization.exe
PR2LocalizationGUI.exe
PR2LocalizationCore.dll
PR2HostMount.ps1             ← Steam 包
Ascaron.Logging-2.6.orig.dll ← Steam 还原后可保留，也可删除
PR2Localization\packs\<语言>.txt
PR2Localization\fonts\<语言>\
PR2Localization\ui\
PR2Localization\logs\
README.txt / OFL.txt / NOTO-SOURCES.txt / RUNTIME-VERSION
```

不要删除：

- `PR2.exe`、`.cpr`、地图、音乐等游戏文件；
- `fonts\` 根目录的原版字体。

存档不受影响。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 界面还是英文 | `locale.ini` 指向的语言没有包，或代理没加载 | 看 `PR2Localization\logs\runtime.log` 首行；没有日志时看 `PR2Localization\logs\proxy.log` |
| 中文显示空白 | 字体缺失或不完整 | 检查 `PR2Localization\fonts\<语言>\` 四个 TTF |
| GUI 列表没有语言 | `PR2Localization\packs\<语言>.txt` 没解压到根目录 | 重新解压语言包 |
| 启动器闪一下就没了 | 控制台程序，双击看不到错误 | 从命令行运行 `PR2Localization.exe` 看日志 |
| Steam 版不生效 | 宿主 DLL 未挂载、被 Steam 校验恢复，或代理加载失败 | 先运行 `PR2HostMount.ps1 -Action Status`；再附 `PR2Localization\logs\proxy.log`、`PR2Localization\logs\runtime.log`、`PR2Localization\logs\resolve.log` 排查 |

更多技术细节见[构建与安装](构建与安装.md)和[发行版](发行版.md)。
