# 玩家指南：解压即用

这份文档只讲**拿到发行包后怎么启动本地化**，不涉及源码、编译和翻译。

## 1. 确认游戏版本

当前只支持：

```
GOG 英文版 Port Royale 2 1.1.2.3
```

Steam 版、GOG 法语版和其他版本暂不支持。不要在这些版本上部署发行包。

## 2. 下载对应语言的 zip

从项目 Release 页面下载需要的语言，例如：

```
PR2-zh-v0.5.0.zip
PR2-ja-v0.5.0.zip
```

一个 zip 就是一种语言；需要几种语言就分别下载。

## 3. 解压到游戏根目录

把 zip 里的**全部文件**解压到 `PR2.exe` 所在的同一层目录，例如：

```
<游戏目录>\
├─ PR2.exe
├─ PR2Launcher.exe
├─ PR2LauncherGUI.exe
├─ PR2TextSource.dll
├─ PR2Packs\
├─ fonts\
├─ ui\
└─ ...
```

注意：

- 不要解压到 `PR2Launcher` 之类的子文件夹；
- 不要删除 `fonts\` 根目录的四份原版字体；
- 发行包不会覆盖 `fonts\` 根目录，只把本地化字体放进 `fonts\<语言>\`。

## 4. 双击 PR2LauncherGUI.exe

打开后：

1. 在语言下拉里选择目标语言；
2. 点「以所选语言启动」。

启动成功后，GUI 会把这个语言写进：

```
PR2Packs\locale.ini
```

下次直接双击 `PR2LauncherGUI.exe` 会默认选它。

**不要直接双击 `PR2.exe`**，那样不会加载语言包。

## 5. 第一次启动会备份原版字体

启动器第一次替换字体会先把原版四个 TTF 备份到：

```
fonts\_original\
```

之后：

- 本地化启动：使用 `fonts\<语言>\`，不覆盖根目录；
- 原版启动：`PR2Launcher.exe --vanilla` 使用根目录原版。

如果备份失败或根目录已被替换过，启动器会提示并跳过。

## 6. 字体缺失怎么办

如果 GUI 提示：

```
fonts\zh\ 缺少字体 TTF
```

说明发行包没有解压完整。处理：

1. 重新从 zip 解压整个 `fonts\<语言>\` 目录；
2. 确认四个文件都在：

   ```
   ARIAL.TTF
   ELGRECO_.TTF
   Tiepolo_black.ttf
   Tiepolo_bold.ttf
   ```

3. 不要把字体放到 `fonts\` 根目录；
4. 检查杀毒软件是否隔离了字体。

仍然启动也可以，但会回退原版拉丁字体，中文可能空白。

## 7. 切换语言

- 当前语言：`PR2Packs\locale.ini` 的 `language=`；
- 在 GUI 里选另一语言，再点「以所选语言启动」；
- 或启动器临时指定：

  ```bat
  PR2Launcher.exe --lang=ja
  ```

  这个只影响本次，不写 `locale.ini`。

## 8. 卸载

删除发行包新增的内容即可：

```
PR2Launcher.exe
PR2LauncherGUI.exe
PR2TextSource.dll
PR2Packs\<语言>.txt
fonts\<语言>\
ui\
README.txt / OFL.txt / NOTO-SOURCES.txt / RUNTIME-VERSION
```

不要删除：

- `PR2.exe`、`.cpr`、地图、音乐等游戏文件；
- `fonts\` 根目录的原版字体。

存档不受影响。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 界面还是英文 | 直接运行了 `PR2.exe`，或 `locale.ini` 不对 | 用 GUI 启动，或检查 `PR2Packs\locale.ini` |
| 中文显示空白 | 字体缺失或不完整 | 检查 `fonts\<语言>\` 四个 TTF |
| GUI 列表没有语言 | `PR2Packs\<语言>.txt` 没解压到根目录 | 重新解压语言包 |
| 启动器闪一下就没了 | 控制台程序，双击看不到错误 | 从命令行运行 `PR2Launcher.exe` 看日志 |
| Steam 版不生效 | 当前不支持 Steam | 换 GOG 英文版，或等以后支持 |

更多技术细节见[构建与安装](构建与安装.md)和[发行版](发行版.md)。
