# Port Royale 2 ローカライズ

**Port Royale 2** のローカライズプロジェクトです。UI テキストは外部の言語パックで
差し替え、オリジナルの `PR2.exe` は一切変更しません。

[中文](README.md) · [English](README.en.md) · [日本語](README.ja.md) · [ドキュメント索引](docs/README.ja.md)

---

## プレイヤー: 展開して起動する

インストーラーも Python もビルドも不要です。

1. Releases から対象言語の zip（例: `PR2-zh-v0.5.0.zip`）をダウンロードします。
2. **`PR2.exe` と同じゲームのルートにすべて展開します**。
3. `PR2LauncherGUI.exe` を実行します。
4. 対象の言語を選択します。
5. **Launch selected language** をクリックします。

起動に成功すると、GUI が `PR2Packs\locale.ini` を書き込み、次回からその言語が
既定になります。

注意:

- **`PR2.exe` を直接実行しないでください** — 言語パックが読み込まれません。
- ルートの `fonts\` にある元の 4 つのフォントは残してください。
- フォントが見つからない場合、GUI が警告を表示します。`fonts\<lang>\` フォルダ全体を
  展開し直してください。

手順の詳細、アンインストール、トラブルシューティングは
[プレイヤーガイド](docs/ja/user-guide.md) を参照してください。

## 開発者: ビルドと翻訳

必要なもの: Visual Studio（C++ によるデスクトップ開発ワークロード）と Python 3.11 以上
（現在は 3.15）。

```bat
start.bat
```

ローカルのワークベンチを起動し、ブラウザで **Install & Launch** ページを開きます。
ビルドを自動で行うことは**ありません**。

ページには 5 ステップのウィザードがあります。

1. ゲームディレクトリを選択します。
2. フォントを準備します。
3. コンテンツを翻訳します。
4. 言語パック + フォントをビルドします。
5. 配備して起動します。

カードから直接操作することもできます。

- **Build & Deploy**: インジェクターをビルドし、言語パックをビルドして、ゲームディレクトリへ配備します。
- **Launch**: **Set as game language** は `locale.ini` を書き込み、**Launch (injected)** は選択中の言語で起動します。
- **Translation editor**: 同じワークベンチで、上部のタブで切り替えます。

開発中は `apply_patch.bat` が一連の処理（正規化 → 検証 → ビルド → 配備 → 確認）を
まとめて実行します。

ボタンの詳細は [ビルドとインストール](docs/ja/build-and-install.md) を参照してください。

### リポジトリ構成

```
pr2-localization/
├─ start.bat                  開発用エントリ: ワークベンチを起動
├─ apply_patch.bat            正規化 → 検証 → ビルド → 配備
├─ src/
│  ├─ live/                   翻訳のソース（エディタが保存）
│  ├─ seed/                   初期テキスト（項目ごとに解放）
│  ├─ orig/                   原版の英語/フランス語（読み取り専用の参照）
│  ├─ editor/                 翻訳エディタ（Astro フロントエンド + server.py）
│  ├─ injector/               インジェクターのソース（C++）
│  └─ tools/
│     ├─ pack/                ビルド、配備、新規言語
│     ├─ text/                正規化、CJK ルール、トークン化
│     ├─ font/                フォントの縫合と書き出し（fontstitch/）
│     ├─ analysis/            話者、トーン、幅の分析
│     ├─ install/             pr2ctl のビルド/配備/起動の実装
│     └─ data/                人名、地名、トークナイザーの辞書
├─ assets/fonts/original/     元のラテン系フォント（gitignore 対象。自分で書き出す）
├─ build/                     成果物: PR2Packs/、fonts/、インジェクター
├─ docs/                      ドキュメント
├─ glossary/                  用語
└─ tests/                     ルールと API のテスト
```

| ファイル | 役割 |
|---|---|
| `PR2Launcher.exe` | ランチャー。`PR2.exe` をサスペンド状態で起動し、DLL を注入してから再開します（ビルド成果物） |
| `PR2TextSource.dll` | 中核ロジック。エンジンのテキスト取得 3 経路をフックし、文字列を差し替えます（ビルド成果物） |
| `PR2Packs\` | 言語パック。`<lang>.txt` + `locale.ini`。プレーンテキストのまま編集できます |
| `fonts\` | ローカライズ版フォント。CJK のグリフが欠けると空白で表示されます |

## 言語の追加

C++ の変更は不要です。

1. `start.bat` を実行し、**Translation editor** を開いて言語ドロップダウン横の **＋** を
   クリックし、既存の言語をテンプレートにします。
2. 翻訳して保存します（`src/live/<code>.toml` に書き込まれます）。
3. テンプレート言語から `presets/<code>.toml` が自動生成されます。新しい言語の donor を
   確認するか、置き換えてください。
4. フォントと言語パックをビルドし、配備します。

各ステップの受け入れ条件を含む手順の詳細: [新言語の追加](docs/ja/new-language.md)。
フォントの前提条件: [新言語のフォント](docs/ja/new-language-fonts.md)。

エントリはすべて埋まっていなくてもかまいません。未入力のエントリは英語に
フォールバックします。

## 既知の制限

- **フック対象はゲームのビルドに紐づきます。** コードは `A2dLib-2.20A.dll` の関数を固定
  オフセットで呼び出しています。別のビルド（GOG フランス語版 `1.1.2.42` を含む）では
  新しいオフセットが必要になる可能性が高く、そのままでは何も効きません。
- **中国語エントリが丸ごと消えるのはタグの問題ではなくトークン化の問題です。**
  エンジンはスペースでテキストを分割するため、スペースを含まない CJK 文字列が幅を取り
  すぎると、その文字列ごと破棄されます。ゲーム内で 1 件ずつ確認してください。
- **フォントは言語ごとに異なります。** 開発時は `build\fonts\<lang>\` の縫合フォントを
  使い、リリースでは完全な Noto を使います。配備時はゲームディレクトリの
  `fonts\<lang>\` にコピーし、元のフォントは決して上書きしません。新しい難読文字が
  入ると再縫合が必要になり、グリフが欠けると空白で描画されます。

## 言語の状況

| 言語 | エントリ数 | 状態 |
|---|---|---|
| 中国語 `zh` | 3548 | ✅ 完了（レイアウトとプレースホルダーの検証を含む） |
| 日本語 `ja` | 3548 | ✅ 完了（翻訳 3370 件 + 原文維持 178 件） |
| 英語/フランス語 | 3548 | 参照用の原文（`src/orig/`）。言語パックは生成しません |

日本語の「原文維持」とは、翻訳すべきでない 178 件のことです。記号/数字、エンジン ID
（`IDM_CONTEST_…`）、キー名（`ESC`/`CTRL`/`F10`）、著作権表記、開発者名が該当します。
一覧は `src/live/keep_original.toml` にあり、コンパイラーが英語の原文を強制的に
書き戻します。

## パスの規約

ドキュメントとスクリプトにマシン固有の絶対パスは含まれていません。ゲームディレクトリは
`<game directory>` と表記し、ユーザーディレクトリは `%USERPROFILE%` のような変数で
表します。`subset_fonts.py` は既定で `assets/fonts/original/`（gitignore 対象）から
元のフォントを読み込み、特定のマシンには依存しません。
